# 8.1 tar（tape archive） <a id="cmd-tar"></a> <a id="archive"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 打包和解压文件，是 Linux 中最常用的归档工具。

**用法**

```bash
# 打包文件（只打包，不压缩）
tar -cvf 打包名.tar 文件或目录
```

例如：

```bash
# 将 project 文件夹打包成 project.tar
tar -cvf project.tar project
```

```bash
# 解包文件
tar -xvf 打包名.tar
```

```bash
# 打包并使用 gzip 压缩
tar -czvf 压缩包名.tar.gz 文件或目录
```

例如：

```bash
# 将 project 压缩为 project.tar.gz
tar -czvf project.tar.gz project
```

```bash
# 解压 tar.gz 文件
tar -xzvf 压缩包名.tar.gz
```

```bash
# 查看压缩包内容（不解压）
tar -tvf 压缩包名.tar.gz
```

**tar 常用选项**

| 选项 | 作用 |
|---|---|
| `-c` | create，创建打包文件（归档） |
| `-x` | extract，解压文件 |
| `-v` | verbose，显示过程 |
| `-f` | file，指定文件名 |
| `-z` | gzip，使用 gzip 压缩 |
| `-t` | list，查看内容（不解压） |

**解释**

- `tar` = tape archive
- `.tar` = 只打包，不压缩
- `.tar.gz` = 打包并使用 gzip 压缩
- 解压 tar.gz 也可以用 `tar -xf`（新版 tar 会自动识别压缩格式）
