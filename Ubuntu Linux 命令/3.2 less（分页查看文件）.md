# 3.2 less（分页查看文件） <a id="cmd-less"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 分页查看文件内容，适合查看较大的文本文件。

**用法**

```bash
# 查看文件内容
less 文件名
```

例如：

```bash
# 查看 log.txt 文件
less log.txt
```

**less 中常用操作**

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 上下滚动 |
| `Space` | 向下翻页 |
| `b` | 向上翻页 |
| `/关键词` | 向下搜索 |
| `n` / `N` | 下一个 / 上一个搜索结果 |
| `q` | 退出 less |

例如：

```text
/error
```

搜索 error。

**解释**

- `less` = 分页查看文件内容
- 适合查看日志、大型文本文件
- 不会一次性加载全部内容，比 cat 更适合查看大文件
