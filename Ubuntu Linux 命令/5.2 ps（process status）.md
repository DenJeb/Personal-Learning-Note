# 5.2 ps（process status） <a id="cmd-ps"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看进程信息。与 top 的动态监控不同，ps 是一次性快照。

**用法**

```bash
# 查看当前终端启动的进程
ps
```

```bash
# 查看系统中所有进程（最常用）
ps aux
```

```bash
# 查找指定进程
ps aux | grep python
```

**解释**

- `ps` = process status
- `a` = 显示所有用户的进程
- `u` = 以用户友好的格式显示（含 CPU / 内存占用）
- `x` = 包含没有终端的后台进程
- 常用列：
  - `PID` = 进程编号（配合 kill 使用）
  - `%CPU` / `%MEM` = CPU / 内存占用率
  - `STAT` = 进程状态（S 睡眠、R 运行、Z 僵尸等）
  - `COMMAND` = 启动进程的命令
- 另一种写法 `ps -ef` 效果类似
