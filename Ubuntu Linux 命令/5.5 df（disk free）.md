# 5.5 df（disk free） <a id="cmd-df"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看磁盘空间使用情况。

**用法**

```bash
# 查看磁盘空间
df
```

```bash
# 以易读方式显示
df -h
```

输出示例：

```text
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       100G   50G   50G  50% /
```

**解释**

- `df` = disk free
- `-h` = human readable
- 查看文件系统（磁盘分区）的剩余空间，常用于检查磁盘是否不足
- 查看某个目录占用多少空间用 du
