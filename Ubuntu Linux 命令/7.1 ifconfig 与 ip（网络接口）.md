# 7.1 ifconfig 与 ip（网络接口） <a id="cmd-ifconfig"></a> <a id="network"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看和配置网络接口。ifconfig 已过时，新版 Ubuntu 推荐使用 ip 命令。

**用法**

```bash
# 查看所有网络接口及 IP（新版推荐）
ip addr
```

```bash
# 查看指定网络接口
ip addr show 接口名
```

```bash
# 查看接口启用状态
ip link show
```

旧命令（未安装时需 `sudo apt install net-tools`，不建议新学）：

```bash
# 查看网络接口信息（旧）
ifconfig
```

```bash
# 启用 / 关闭网络接口
sudo ifconfig 接口名 up
sudo ifconfig 接口名 down
```

**解释**

- `ip addr` 等价于旧命令 `ifconfig`
- `ifconfig` = interface configuration
- 常见网络接口：
  - `lo`：本地回环接口（127.0.0.1）
  - `enp3s0` / `eth0`：有线网络（新版使用可预测命名，如 enp3s0）
  - `wlp2s0` / `wlan0`：无线网络
- 用 `ip addr` 查看本机实际接口名，再操作对应接口

> 💡 IP 与 DNS 的关系见[网络基础 4](<../网络基础/4. 域名系统（DNS）.md>)。
