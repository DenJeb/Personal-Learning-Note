# 5.1 top（实时进程监控） <a id="cmd-top"></a> <a id="system"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 实时查看系统中的进程状态和资源占用情况。

**用法**

```bash
# 查看系统进程
top
```

**修改刷新频率**

默认每 3 秒刷新一次。按 `s` 后输入秒数即可修改：

```text
s
1
```

表示每 1 秒刷新一次。

**top 常用操作**

| 按键 | 作用 |
|---|---|
| `q` | 退出 top |
| `P` | 按 CPU 使用率排序 |
| `M` | 按内存使用率排序 |
| `s` | 修改刷新间隔 |
| `k` | 输入 PID 后结束进程 |
| `1` | 显示每个 CPU 核心状态 |
| `h` | 查看帮助 |

**解释**

- `top` 并没有官方全称，"table of processes" 是常见的流传说法
- `PID` = Process ID，进程编号
- `%CPU` = CPU 使用率
- `%MEM` = 内存使用率
- 动态实时监控用 top，一次性查看快照用 ps
