# 3.4 tail（查看文件末尾） <a id="cmd-tail"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看文件末尾部分内容。

**用法**

```bash
# 查看文件最后 10 行（默认）
tail 文件名
```

```bash
# 指定查看行数
tail -n 行数 文件名
```

例如：

```bash
# 查看最后 20 行
tail -n 20 test.txt
```

```bash
# 实时跟踪文件变化
tail -f 文件名
```

例如：

```bash
# 实时查看日志文件
tail -f app.log
```

按 `Ctrl + C` 退出跟踪。

**解释**

- `tail` = 查看尾部
- 默认显示最后 10 行
- `-n` = number，指定显示行数
- `-f` = follow，持续跟踪文件新增内容，常用于查看日志
