# 9.1 echo（输出内容） <a id="cmd-echo"></a> <a id="shell"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 输出指定内容，也可以查看环境变量。

**用法**

```bash
# 输出文本
echo "Hello Linux"
```

输出：

```text
Hello Linux
```

```bash
# 输出变量内容
echo "$变量名"
```

例如：

```bash
# 查看 PATH 环境变量
echo "$PATH"
```

```bash
# 输出后不换行
echo -n "Hello"
```

```bash
# 解析转义字符（\n 换行、\t 制表符）
echo -e "第一行\n第二行"
```

```bash
# 将内容写入文件（覆盖）
echo "Hello" > test.txt
```

```bash
# 追加内容到文件
echo "Linux" >> test.txt
```

**解释**

- `echo` = 回显、输出
- `$` 用于引用变量
- 内容含有空格或变量时，建议使用双引号包起来
- `-n` = 输出后不换行
- `-e` = 解析转义字符
- `>` = 覆盖写入文件（会先清空原文件）
- `>>` = 追加写入文件（保留原内容）

> ⚠️ **注意**：`>` 会清空原文件内容后写入，误用会覆盖重要文件。
