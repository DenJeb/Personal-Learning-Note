# 2.2 cd（change directory） <a id="cmd-cd"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 切换当前所在目录。

**用法**

```bash
# 进入指定目录（相对路径）
cd 目录名
```

例如：

```bash
# 进入 Desktop 文件夹
cd Desktop
```

```bash
# 进入指定目录（绝对路径）
cd /home/user/Desktop
```

```bash
# 返回上一级目录
cd ..
```

```bash
# 返回用户主目录
cd ~
```

```bash
# 进入根目录
cd /
```

```bash
# 返回上一次所在的目录（在两个目录间快速切换）
cd -
```

**解释**

- `cd` = change directory
- `..` 表示上一级目录
- `~` 表示当前用户主目录
- `/` 表示根目录
- `-` 表示上一次所在的目录
