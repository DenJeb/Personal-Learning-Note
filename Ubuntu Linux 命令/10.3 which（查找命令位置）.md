# 10.3 which（查找命令位置） <a id="cmd-which"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查找命令对应的可执行文件位置。

**用法**

```bash
# 查找命令路径
which 命令
```

例如：

```bash
# 查找 ls 命令的位置
which ls
```

输出：

```text
/usr/bin/ls
```

```bash
# 查找 python3 位置（新版 Ubuntu 默认只安装 python3）
which python3
```

**解释**

- `which` = 查找命令位置
- 用于确认当前执行的是哪个程序
- Linux 中很多命令实际上对应某个可执行文件
- 新版 Ubuntu 中 `which python` 可能没有结果，因为默认只有 python3
