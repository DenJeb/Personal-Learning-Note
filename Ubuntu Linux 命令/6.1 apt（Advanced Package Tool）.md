# 6.1 apt（Advanced Package Tool） <a id="cmd-apt"></a> <a id="packages"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 管理 Ubuntu 系统中的软件包，包括安装、更新、卸载软件。

**用法**

```bash
# 更新软件源列表
sudo apt update
```

```bash
# 升级已安装的软件
sudo apt upgrade
```

```bash
# 安装软件
sudo apt install 软件名
```

例如：

```bash
# 安装 git
sudo apt install git
```

```bash
# 卸载软件（保留配置文件）
sudo apt remove 软件名
```

```bash
# 完全卸载软件（包括配置文件）
sudo apt purge 软件名
```

```bash
# 清理不再需要的依赖包
sudo apt autoremove
```

```bash
# 搜索软件
apt search 软件名
```

例如：

```bash
# 搜索 python 相关软件包
apt search python
```

```bash
# 查看已安装的软件
apt list --installed
```

**解释**

- `apt` = Advanced Package Tool
- 用于管理 Debian / Ubuntu 系统的软件包
- `apt update` = 更新软件源信息（只更新列表，不安装）
- `apt upgrade` = 升级已安装的软件
- `apt install` = 安装软件
- `apt remove` = 卸载软件，保留配置文件
- `apt purge` = 完全卸载，连配置文件一起删除
- `apt autoremove` = 清理不再需要的依赖
- 安装、卸载软件通常需要 sudo 权限
