# 9.4 同时执行多个命令（; && || |） <a id="cmd-multi"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 在一行中组合执行多个命令。

**用法**

**`;` 依次执行**

```bash
命令1 ; 命令2
```

无论前一个命令是否执行成功，都会执行后面的命令。

```bash
ls ; pwd
```

输出示例：

```text
Desktop  Documents  test.txt
/home/user
```

**`&&` 前一个成功后执行**

```bash
命令1 && 命令2
```

只有前一个命令执行成功，才会执行后面的命令。

```bash
mkdir test && cd test
```

创建目录成功，才进入 test。

**`||` 前一个失败后执行**

```bash
命令1 || 命令2
```

只有前一个命令执行失败，才会执行后面的命令。

```bash
mkdir test || echo "创建失败"
```

创建失败时输出"创建失败"。

**`|` 管道**

```bash
命令1 | 命令2
```

将前一个命令的输出作为后一个命令的输入。

```bash
# 查找当前目录中包含 txt 的文件
ls | grep txt
```

```bash
# 统计文件行数
cat test.txt | wc -l
```

**总结**

| 符号 | 作用 |
|---|---|
| `;` | 依次执行，不关心成功失败 |
| `&&` | 前一个成功后执行下一个 |
| `||` | 前一个失败后执行下一个 |
| `|` | 管道，将输出传给下一个命令 |
