# 2.7 rm（remove） <a id="cmd-rm"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 删除文件或目录。

**用法**

```bash
# 删除文件
rm 文件名
```

例如：

```bash
# 删除 hello.txt 文件
rm hello.txt
```

```bash
# 删除前询问确认
rm -i 文件名
```

```bash
# 递归删除目录
rm -r 目录名
```

例如：

```bash
# 删除 project 文件夹以及里面的内容
rm -r project
```

```bash
# 删除文件并显示过程
rm -v 文件名
```

```bash
# 递归删除并显示过程
rm -rv 目录名
```

```bash
# 强制删除文件
rm -f 文件名
```

```bash
# 强制递归删除目录
rm -rf 目录名
```

**解释**

- `rm` = remove
- `-r` = recursive，递归删除目录及里面所有内容
- `-v` = verbose，显示删除过程
- `-i` = interactive，删除前询问确认（建议养成使用习惯）
- `-f` = force，强制删除，不询问
- Linux 没有回收站，删除后通常无法恢复

> ⚠️ **注意**：`rm -rf` 非常危险，执行前务必确认路径正确，千万不要对 `/` 或 `~` 误操作。
