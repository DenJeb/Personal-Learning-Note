# 5.3 kill（向进程发送信号） <a id="cmd-kill"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 向进程发送信号，通常用于结束进程。

**用法**

```bash
# 根据 PID 结束进程（默认发送 SIGTERM，给进程保存数据的机会）
kill PID
```

例如：

```bash
# 结束 PID 为 1234 的进程
kill 1234
```

```bash
# 强制结束进程（SIGKILL，进程无法忽略）
kill -9 PID
```

```bash
# 按名称结束进程
pkill 进程名
```

例如：

```bash
# 结束所有名为 python 的进程
pkill python
```

**查看进程 PID**

```bash
# 动态查看（按 q 退出）
top
```

或者：

```bash
# 静态查看
ps aux
```

**解释**

- `kill` = 发送信号给进程
- `PID` = Process ID，进程编号
- `-15`（默认）= SIGTERM，温和终止，进程可以保存数据后退出
- `-9` = SIGKILL，强制终止，进程无法处理
- 建议先尝试默认的 `kill PID`，无效再用 `-9`

> ⚠️ **注意**：`kill -9` 会立即结束进程，可能导致数据未保存。
