# 4.2 sudo（super user do） <a id="cmd-sudo"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 以管理员（root）权限执行单条命令。

**用法**

```bash
# 使用管理员权限执行命令
sudo 命令
```

例如：

```bash
# 使用管理员权限在系统目录创建文件夹
sudo mkdir /opt/test
```

```bash
# 编辑系统配置文件
sudo nano /etc/hosts
```

**常用场景**

- 安装 / 卸载软件（`sudo apt install ...`）
- 修改系统配置文件
- 管理用户和权限

**解释**

- `sudo` = super user do
- 用于临时获得管理员权限，只对当前这一条命令生效（短时间内有缓存）
- 普通用户默认没有修改系统文件的权限
- 与 `su` 的区别：`su` 是切换到 root 用户，`sudo` 是借 root 权限执行单条命令

> ⚠️ **注意**：sudo 权限很高，执行删除、修改系统文件等操作前请确认命令无误。
