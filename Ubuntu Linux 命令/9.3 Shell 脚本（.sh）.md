# 9.3 Shell 脚本（.sh） <a id="cmd-shell-script"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 把一系列命令写入文件，实现批量、可重复执行。

**用法**

```bash
# 创建脚本文件
touch script.sh
```

```bash
# 编辑脚本
nano script.sh
```

内容例如：

```bash
#!/bin/bash

echo "Hello Linux"
date
```

```bash
# 添加执行权限
chmod +x script.sh
```

```bash
# 执行脚本
./script.sh
```

输出：

```text
Hello Linux
Thu Oct  8 18:58:00 CST 2026
```

```bash
# 或直接用 bash 执行（不需要执行权限）
bash script.sh
```

**解释**

- `.sh` = Shell Script 文件扩展名
- `#!/bin/bash` = shebang，指定使用 Bash 解释器执行
- `chmod +x` = 添加执行权限
- `./` 表示当前目录（Linux 默认不在当前目录查找命令，所以需要写 `./`）
