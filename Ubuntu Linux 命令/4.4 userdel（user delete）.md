# 4.4 userdel（user delete） <a id="cmd-userdel"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 删除用户。

**用法**

```bash
# 删除用户
sudo userdel 用户名
```

例如：

```bash
# 删除 test 用户
sudo userdel test
```

```bash
# 删除用户并同时删除主目录
sudo userdel -r 用户名
```

**解释**

- `userdel` = user delete
- `-r` = remove home directory，同时删除用户主目录
- 删除用户需要 sudo 权限
