# 4.1 chmod（change mode） <a id="cmd-chmod"></a> <a id="permissions"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 修改文件或目录的权限。

**用法**

```bash
# 修改文件权限
chmod 权限 文件名
```

例如：

```bash
# 给脚本添加执行权限（755 常用于脚本和程序）
chmod 755 script.sh
```

**Linux 文件权限**

查看权限：

```bash
ls -l
```

显示：

```text
-rwxr-xr-x 1 user user 1024 Aug  9 12:34 script.sh
```

权限分为三组：

| 权限位置 | 对象 |
|---|---|
| 第一组 `rwx` | 文件所有者（user） |
| 第二组 `r-x` | 所属用户组（group） |
| 第三组 `r-x` | 其他用户（other） |

**权限含义**

| 符号 | 含义 |
|---|---|
| `r` | read，读取权限 |
| `w` | write，写入权限 |
| `x` | execute，执行权限 |
| `-` | 没有权限 |

**数字方式设置权限**

权限对应数字：

| 权限 | 数字 |
|---|---|
| `r` | 4 |
| `w` | 2 |
| `x` | 1 |
| 无权限 | 0 |

常用组合：

| 权限 | 数字 |
|---|---|
| `rwx` | 7 |
| `rw-` | 6 |
| `r-x` | 5 |
| `r--` | 4 |

```bash
# 设置权限为 rwxr-xr-x
chmod 755 文件名
```

表示：

```text
所有者：rwx (7)
用户组：r-x (5)
其他用户：r-x (5)
```

```bash
# 设置权限为 rw-r--r--（普通文件常用）
chmod 644 文件名
```

表示：

```text
所有者：rw- (6)
用户组：r-- (4)
其他用户：r-- (4)
```

**字母方式设置权限**

```bash
# 给文件所有者增加执行权限
chmod u+x 文件名
```

```bash
# 删除文件所有者的执行权限
chmod u-x 文件名
```

```bash
# 给所有用户增加执行权限
chmod a+x 文件名
```

用户类型：

| 符号 | 含义 |
|---|---|
| `u` | user，文件所有者 |
| `g` | group，所属用户组 |
| `o` | other，其他用户 |
| `a` | all，所有用户 |

操作符：

| 符号 | 作用 |
|---|---|
| `+` | 增加权限 |
| `-` | 删除权限 |
| `=` | 直接设置权限 |

**目录权限**

```bash
chmod 755 目录名
```

可以设置目录权限。

> ⚠️ **注意**：目录的 `x` 权限表示"可以进入目录"。例如 `chmod 644 test` 会去掉目录的执行权限，导致目录无法进入、无法访问其中内容。

**解释**

- `chmod` = change mode
- Linux 权限由所有者（user）、用户组（group）、其他用户（other）三部分组成
- 数字权限：r = 4，w = 2，x = 1
- 755 常用于脚本/程序，644 常用于普通文件
