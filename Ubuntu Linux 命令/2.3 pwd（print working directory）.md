# 2.3 pwd（print working directory） <a id="cmd-pwd"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 显示当前所在目录的绝对路径。

**用法**

```bash
# 查看当前路径
pwd
```

输出示例：

```text
/home/user/Desktop
```

**解释**

- `pwd` = print working directory
- 切换目录后不确定自己在哪里时，先用 pwd 确认
