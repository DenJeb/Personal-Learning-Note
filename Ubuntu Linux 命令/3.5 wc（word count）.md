# 3.5 wc（word count） <a id="cmd-wc"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 统计文件中的行数、单词数和字节数。

**用法**

```bash
# 统计文件信息
wc 文件名
```

例如：

```bash
wc test.txt
```

输出：

```text
10 50 300 test.txt
```

表示：

```text
行数 单词数 字节数 文件名
```

```bash
# 只统计行数
wc -l 文件名
```

```bash
# 只统计单词数
wc -w 文件名
```

```bash
# 只统计字节数
wc -c 文件名
```

**解释**

- `wc` = word count
- `-l` = lines，行数
- `-w` = words，单词数
- `-c` = bytes，字节数（注意：中文等多字节字符占多个字节，不等于字符数）
- 常用于统计代码行数、日志数量等
