# 3.1 cat（concatenate） <a id="cmd-cat"></a> <a id="view"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看文件内容（适合小文件）。

**用法**

```bash
cat 文件名
```

例如：

```bash
# 查看 hello.txt 文件内容
cat hello.txt
```

**其他用法**

创建或覆盖文件：

```bash
cat > test.txt
```

输入内容后按：

```bash
Ctrl + D
```

保存退出。

追加内容：

```bash
cat >> test.txt
```

**解释**

- `cat` = concatenate，本意是拼接文件
- 常用于快速查看文本文件内容
- `>` 会覆盖已有内容，`>>` 是追加
- 文件较大时用 less 更合适（cat 会一次性输出全部内容）

> ⚠️ **注意**：`cat > 文件` 会覆盖已有文件内容，操作前确认文件名无误。
