# 2.8 cp（copy） <a id="cmd-cp"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 复制文件或目录。

**用法**

```bash
# 复制文件
cp 源文件 目标文件
```

例如：

```bash
# 复制 test.txt 为 backup.txt
cp test.txt backup.txt
```

```bash
# 复制文件到指定目录
cp 文件名 目录
```

例如：

```bash
# 将 test.txt 复制到 Desktop
cp test.txt Desktop
```

```bash
# 覆盖前询问
cp -i 源文件 目标
```

```bash
# 不覆盖已存在的文件
cp -n 源文件 目标
```

```bash
# 递归复制目录
cp -r 源目录 目标目录
```

例如：

```bash
# 复制 project 文件夹到 backup
cp -r project backup
```

**解释**

- `cp` = copy
- `-r` = recursive，递归复制目录及里面所有内容
- `-i` = interactive，覆盖前询问
- `-n` = no-clobber，不覆盖已存在的文件
- 默认情况下，目标文件已存在会被直接覆盖，建议配合 `-i` 使用
