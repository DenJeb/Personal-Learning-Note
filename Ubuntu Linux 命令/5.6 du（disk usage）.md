# 5.6 du（disk usage） <a id="cmd-du"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看文件或目录占用的磁盘空间。

**用法**

```bash
# 查看目录大小
du 目录名
```

```bash
# 以易读方式显示大小
du -h 目录名
```

```bash
# 查看目录总大小
du -sh 目录名
```

例如：

```bash
du -sh project
```

输出：

```text
500M    project
```

```bash
# 查看当前目录下各子目录的大小
du -h --max-depth=1
```

**解释**

- `du` = disk usage
- `-h` = human readable，以易读单位显示
- `-s` = summarize，只显示总大小
- `--max-depth=N` = 只统计到第 N 层子目录
- df 看磁盘整体剩余空间，du 看具体目录占用
