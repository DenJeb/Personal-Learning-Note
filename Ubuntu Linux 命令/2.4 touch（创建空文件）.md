# 2.4 touch（创建空文件） <a id="cmd-touch"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 创建空文件；如果文件已存在，则更新其修改时间。

**用法**

```bash
# 创建空文件
touch 文件名
```

例如：

```bash
# 创建 hello.txt 文件
touch hello.txt
```

```bash
# 同时创建多个文件
touch a.txt b.txt
```

```bash
# 创建指定路径下的文件
touch notes/linux.md
```

**解释**

- `touch` = 触碰
- 文件不存在时创建空文件
- 文件已存在时更新文件的修改时间（不改变内容）
