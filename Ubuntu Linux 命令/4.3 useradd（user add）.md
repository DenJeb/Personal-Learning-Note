# 4.3 useradd（user add） <a id="cmd-useradd"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 创建新用户。

**用法**

```bash
# 创建用户
sudo useradd 用户名
```

例如：

```bash
# 创建用户 test
sudo useradd test
```

```bash
# 设置用户密码
sudo passwd test
```

创建的用户默认密码锁定，需用 passwd 设置后才能登录。

```bash
# 创建用户并明确创建主目录
sudo useradd -m 用户名
```

```bash
# 创建用户并指定登录 Shell
sudo useradd -s /bin/bash 用户名
```

**解释**

- `useradd` = user add
- `-m` = 创建用户主目录。Ubuntu / Debian 上 useradd 默认就会创建主目录（/etc/login.defs 中 CREATE_HOME=yes），在其他发行版上需要显式加 `-m`
- `-s` = shell，指定登录 Shell
- 创建用户通常需要 sudo 权限
- 用户主目录默认位于 `/home/用户名`
