# 2.9 mv（move） <a id="cmd-mv"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 移动文件或目录，也可以用于重命名。

**用法**

```bash
# 移动文件
mv 源文件 目标位置
```

例如：

```bash
# 将 test.txt 移动到 Desktop
mv test.txt Desktop
```

```bash
# 移动目录
mv 源目录 目标位置
```

```bash
# 重命名文件
mv 原文件名 新文件名
```

例如：

```bash
# 将 old.txt 改名为 new.txt
mv old.txt new.txt
```

```bash
# 覆盖前询问
mv -i 源文件 目标位置
```

```bash
# 不覆盖已存在的文件
mv -n 源文件 目标位置
```

```bash
# 强制覆盖，不询问
mv -f 源文件 目标位置
```

**解释**

- `mv` = move
- 可以实现文件/目录的移动和重命名
- `-i` = interactive，覆盖前询问
- `-n` = no-clobber，不覆盖已存在的文件
- `-f` = force，强制覆盖
- 默认情况下，目标文件已存在会被直接覆盖，建议配合 `-i` 使用
