# 2.1 ls（list） <a id="cmd-ls"></a> <a id="file-ops"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看当前目录下的文件和目录。

**用法**

```bash
# 查看当前目录内容
ls
```

```bash
# 以详细信息显示文件
ls -l
```

```bash
# 显示隐藏文件（以 . 开头的文件）
ls -a
```

```bash
# 显示所有文件，并查看详细信息
ls -la
```

```bash
# 以易读方式显示文件大小（如 4.0K 而不是 4096）
ls -lh
```

```bash
# 按修改时间排序（最新的在最前）
ls -lt
```

```bash
# 按文件大小排序
ls -lS
```

**解释**

- `ls` = list
- `-l` = long，显示详细信息（权限、大小、时间等）
- `-a` = all，显示隐藏文件
- `-h` = human readable，以 K/M/G 显示大小（需配合 `-l`）
- `-t` = time，按修改时间排序
- `-S` = size，按文件大小排序
