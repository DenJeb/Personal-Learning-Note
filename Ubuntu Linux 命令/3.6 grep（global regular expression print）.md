# 3.6 grep（global regular expression print） <a id="cmd-grep"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 在文件或命令输出中搜索指定内容，支持正则表达式。

**用法**

```bash
# 搜索文件中的内容
grep 关键词 文件名
```

例如：

```bash
# 查找 test.txt 中包含 hello 的行
grep hello test.txt
```

```bash
# 忽略大小写搜索
grep -i 关键词 文件名
```

```bash
# 显示匹配内容所在行号
grep -n 关键词 文件名
```

例如：

```bash
grep -n error log.txt
```

```bash
# 反向匹配：显示不包含关键词的行
grep -v 关键词 文件名
```

```bash
# 匹配行首（如查找以 # 开头的注释行）
grep "^# " 文件名
```

```bash
# 匹配行尾
grep "end$" 文件名
```

```bash
# 使用扩展正则，一次匹配多个关键词
grep -E "error|warning" log.txt
```

```bash
# 递归搜索目录中的文件
grep -r 关键词 目录
```

```bash
# 结合管道使用
命令 | grep 关键词
```

例如：

```bash
# 查看进程中是否存在 python
ps aux | grep python
```

**解释**

- `grep` = global regular expression print
- `-i` = ignore case，忽略大小写
- `-n` = number，显示行号
- `-v` = invert，反向匹配
- `-r` = recursive，递归搜索目录
- `-E` = 扩展正则表达式（`|` 表示"或"）
- `^` 匹配行首，`$` 匹配行尾
- 经常和 `|` 管道一起使用
