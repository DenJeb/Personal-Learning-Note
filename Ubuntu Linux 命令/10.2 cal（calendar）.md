# 10.2 cal（calendar） <a id="cmd-cal"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看日历。

**用法**

```bash
# 查看当前月份日历
cal
```

```bash
# 查看指定年份日历
cal 年份
```

例如：

```bash
# 查看 2026 年日历
cal 2026
```

```bash
# 查看指定月份日历
cal 月份 年份
```

例如：

```bash
# 查看 2026 年 8 月日历
cal 8 2026
```

**解释**

- `cal` = calendar
- 用于快速查看日期
