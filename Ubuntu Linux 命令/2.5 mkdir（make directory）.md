# 2.5 mkdir（make directory） <a id="cmd-mkdir"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 创建目录（文件夹）。

**用法**

```bash
# 创建目录
mkdir 文件夹名
```

例如：

```bash
# 创建 project 文件夹
mkdir project
```

```bash
# 创建多个目录
mkdir test1 test2
```

```bash
# 创建多级目录
mkdir -p project/src
```

创建：

```text
project
└── src
```

如果父目录不存在，会自动创建。

```bash
# 创建目录并显示创建过程
mkdir -pv project/src/test
```

**解释**

- `mkdir` = make directory
- `-p` = parents，自动创建不存在的父目录
- `-v` = verbose，显示创建过程
