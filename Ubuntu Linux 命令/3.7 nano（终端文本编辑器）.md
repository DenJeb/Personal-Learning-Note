# 3.7 nano（终端文本编辑器） <a id="cmd-nano"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 使用终端编辑文本文件，简单易用。

**用法**

```bash
# 打开文件进行编辑
nano 文件名
```

例如：

```bash
# 编辑 hello.txt 文件
nano hello.txt
```

```bash
# 创建并编辑新文件（文件不存在时会自动创建）
nano test.txt
```

**nano 常用快捷键**

| 快捷键 | 作用 |
|---|---|
| `Ctrl + O` | 保存文件 |
| `Ctrl + X` | 退出 nano |
| `Ctrl + W` | 搜索内容 |
| `Ctrl + K` | 剪切当前行 |
| `Ctrl + U` | 粘贴剪切内容 |
| `Ctrl + G` | 打开帮助文档 |
| `Ctrl + C` | 显示当前光标位置 |

**解释**

- `nano` = 一个简单易用的终端文本编辑器
- 适合快速编辑配置文件
- nano 界面底部的快捷键提示中，`^` 表示 Ctrl
