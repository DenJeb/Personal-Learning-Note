# 3.3 head（查看文件开头） <a id="cmd-head"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看文件开头部分内容。

**用法**

```bash
# 查看文件前 10 行（默认）
head 文件名
```

例如：

```bash
head test.txt
```

```bash
# 指定查看行数
head -n 行数 文件名
```

例如：

```bash
# 查看前 20 行
head -n 20 test.txt
```

**解释**

- `head` = 查看头部
- 默认显示前 10 行
- `-n` = number，指定显示行数
