# 10.5 man（manual） <a id="cmd-man"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看 Linux 命令的详细帮助文档。

**用法**

```bash
# 查看命令帮助
man 命令
```

例如：

```bash
# 查看 ls 命令的帮助
man ls
```

进入帮助页面：

```text
LS(1)              User Commands              LS(1)

NAME
       ls - list directory contents
```

**man 中常用操作**

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 上下滚动查看内容 |
| `Space` | 向下翻页 |
| `b` | 向上翻页 |
| `/关键词` | 搜索内容 |
| `n` / `N` | 下一个 / 上一个搜索结果 |
| `q` | 退出 man |

**查看命令所在章节**

```bash
man -f 命令
```

例如：

```bash
man -f printf
```

显示：

```text
printf (1) - format and print data
printf (3) - formatted output conversion
```

**查看指定章节**

```bash
man 章节 命令
```

例如：

```bash
man 1 printf
```

表示查看用户命令中的 printf。

**Linux man 章节**

| 章节 | 内容 |
|---|---|
| 1 | 用户命令 |
| 2 | 系统调用 |
| 3 | 库函数 |
| 4 | 设备文件 |
| 5 | 配置文件格式 |
| 6 | 游戏 |
| 7 | 杂项 |
| 8 | 系统管理员命令 |

**解释**

- `man` = manual，手册
- 用于查看 Linux 命令的官方帮助文档
- 比 `whatis` 提供的信息更加详细
- 学习 Linux 时遇到不会的命令，可以优先使用：

```bash
man 命令
```
