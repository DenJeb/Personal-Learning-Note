# 10.1 date（查看与设置时间） <a id="cmd-date"></a> <a id="info"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看和设置系统日期时间。

**用法**

```bash
# 查看当前时间
date
```

输出：

```text
Thu Oct  8 18:58:00 CST 2026
```

```bash
# 自定义时间显示格式
date +"格式"
```

例如：

```bash
# 显示年月日
date +"%Y-%m-%d"
```

输出：

```text
2026-10-08
```

```bash
# 手动设置系统时间
sudo date -s "2026-10-08 12:00:00"
```

```bash
# 新版推荐使用 timedatectl 查看 / 设置时间
timedatectl
sudo timedatectl set-time "2026-10-08 12:00:00"
```

**常用格式**

| 格式 | 含义 |
|---|---|
| `%Y` | 年份 |
| `%m` | 月份 |
| `%d` | 日期 |
| `%H` | 小时 |
| `%M` | 分钟 |
| `%S` | 秒 |

**解释**

- `date` = 日期
- 常用于查看系统时间和在脚本中生成时间信息
