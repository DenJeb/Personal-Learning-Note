# 2.6 rmdir（remove directory） <a id="cmd-rmdir"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 删除空目录。

**用法**

```bash
# 删除空目录
rmdir 目录名
```

例如：

```bash
# 删除 test 文件夹（空目录）
rmdir test
```

```bash
# 删除多个空目录
rmdir test1 test2
```

**解释**

- `rmdir` = remove directory
- 只能删除空目录，目录中存在文件或其他目录时删除会失败
- 实际使用中，删除非空目录更常用 `rm -r`（见 rm 一节）
