# 7.2 netstat 与 ss（网络连接） <a id="cmd-netstat"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看网络连接、监听端口和对应进程。netstat 已过时，新版推荐使用 ss。

> 端口分类与端口冲突见[网络基础 2](<../网络基础/2. 端口.md>)。

**用法**

```bash
# 查看监听端口及对应进程（新版推荐）
ss -tulnp
```

输出示例：

```text
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:Port Process
tcp   LISTEN 0      128    0.0.0.0:22          0.0.0.0:*        users:(("sshd",pid=1234,fd=3))
```

> 💡 示例中的 22 端口是 SSH 的知名端口，见[网络基础 2.1](<../网络基础/2. 端口.md#2-1>)。

旧命令（未安装时需 `sudo apt install net-tools`）：

```bash
# 查看监听端口及对应进程（旧）
netstat -tulnp
```

**选项说明**

| 选项 | 作用 |
|---|---|
| `-t` | 查看 TCP 连接 |
| `-u` | 查看 UDP 连接 |
| `-l` | 仅显示监听状态 |
| `-n` | 直接显示 IP 和端口，不做名称解析 |
| `-p` | 显示对应进程 |

**解释**

- `netstat` = network statistics
- 常用于：
  - 检查服务是否启动
  - 查看开放端口
  - 排查网络问题
