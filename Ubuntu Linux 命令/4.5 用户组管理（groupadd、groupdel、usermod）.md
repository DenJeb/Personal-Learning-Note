# 4.5 用户组管理（groupadd / groupdel / usermod） <a id="cmd-group"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 管理用户组，用于对多个用户进行统一的权限管理。

**用法**

```bash
# 查看所有用户组
cat /etc/group
```

```bash
# 创建用户组
sudo groupadd 组名
```

```bash
# 删除用户组
sudo groupdel 组名
```

```bash
# 修改用户组名称
sudo groupmod -n 新组名 原组名
```

```bash
# 查看用户所属的组
groups 用户名
```

```bash
# 将用户添加到用户组
sudo usermod -aG 组名 用户名
```

例如：

```bash
# 创建 dev 组，并把 test 用户加进去
sudo groupadd dev
sudo usermod -aG dev test
```

**解释**

- `groupadd` = 创建用户组
- `groupdel` = 删除用户组
- `groupmod` = 修改用户组信息
- `groups` = 查看用户所属组
- `usermod -aG` = 将用户追加到指定组（`-a` = append，不加 `-a` 会覆盖用户原有的附加组）

Linux 权限管理主要由 user（文件所有者）、group（文件所属用户组）、other（其他用户）三部分组成（同 4.1 节的三组权限表）。
