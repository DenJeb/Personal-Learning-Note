# 10.4 whatis（命令简介） <a id="cmd-whatis"></a>

[← 返回目录](<Ubuntu Linux 命令.md>)

**作用**

> 查看命令的简单说明。

**用法**

```bash
# 查看命令简介
whatis 命令
```

例如：

```bash
# 查看 ls 的说明
whatis ls
```

输出：

```text
ls (1) - list directory contents
```

```bash
# 查看多个命令说明
whatis ls cd mkdir
```

**解释**

- `whatis` = 查看是什么
- 用于快速了解命令用途
- 类似命令的简短帮助说明
- 更详细的文档用 man

> 注意：如果 `whatis` 没有结果，可以先重建手册索引：`sudo mandb`。
