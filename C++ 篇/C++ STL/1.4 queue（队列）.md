# 1.4 queue（队列） <a id="1-4"></a>

[← 返回目录](<C++ STL.md>)

## 1.4.1 简介

queue 是队列适配器，只允许在队尾入队、队首出队，遵循先进先出（FIFO）。常用于 BFS、任务调度等场景，底层默认用 deque 实现。

## 1.4.2 特性

- 先进先出（FIFO），原理见[队列](<../../数据结构/3. 栈 & 队列.md#3-2>)

## 1.4.3 常用函数

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main(){
    queue<int> q;

    q.push(10);   // 入队（尾部插入）
    q.push(20);

    cout << q.front() << endl;   // 返回队首元素：10
    cout << q.back() << endl;    // 返回队尾元素：20
    q.pop();                     // 出队（删除队首元素）
    cout << q.front() << endl;   // 20

    return 0;
}
```
