# 1.4 queue（队列） <a id="1-4"></a>

[← 返回目录](<C++ STL.md>)

## 1.4.1 特性

- 先进先出（FIFO），原理见[队列](<../../数据结构/3. 栈 & 队列.md#3-2>)

## 1.4.2 常用函数

| 函数 | 作用 |
|---|---|
| `push(x)` | 入队（尾部插入） |
| `pop()` | 出队（删除队首元素） |
| `front()` | 返回队首元素 |
| `back()` | 返回队尾元素 |
