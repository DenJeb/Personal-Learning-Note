## 4.1.1 简介

仿函数让类的对象具有函数的行为，常用于给 STL 算法传入自定义规则。

- 重载了 `operator()` 的类的对象，可以像函数一样调用（`operator()` 重载见 [C++ 面向对象 4.6](<../C++ 面向对象/4.6 ()函数调用运算符重载.md#4-6>)）
- STL 算法里的 `greater<int>` 就是一个仿函数，用来比较两个数

```cpp
#include <iostream>
using namespace std;

class Greater{
public:
    bool operator()(int a, int b){
        return a > b;
    }
};

int main(){
    Greater g;

    cout << g(3, 5) << endl;   // 0，3 > 5 不成立
    cout << g(5, 3) << endl;   // 1

    return 0;
}
```
