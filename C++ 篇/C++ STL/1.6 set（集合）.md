# 1.6 set（集合） <a id="1-6"></a>

[← 返回目录](<C++ STL.md>)

## 1.6.1 简介

set 是集合容器，元素自动排序且不重复，底层是红黑树，插入、删除、查找都是 O(log n)。适合需要有序且去重的场景。

## 1.6.2 特性

- 自动排序
- 元素去重唯一
- 底层：[红黑树](<../../数据结构/7. 查找.md#7-7>) O(log n)

## 1.6.3 常用函数

```cpp
#include <iostream>
#include <set>
using namespace std;

int main(){
    set<int> s = {30, 10, 20};   // 自动排序为 {10, 20, 30}

    s.insert(40);   // 插入元素
    s.erase(40);    // 删除元素

    cout << s.count(10) << endl;          // 是否存在：1
    cout << *s.find(10) << endl;          // 查找，返回迭代器
    cout << *s.lower_bound(15) << endl;   // 第一个 ≥ 15：20
    cout << *s.upper_bound(20) << endl;   // 第一个 > 20：30

    return 0;
}
```
