# 1.6 set（集合） <a id="1-6"></a>

[← 返回目录](<C++ STL.md>)

## 1.6.1 特性

- 自动排序
- 元素去重唯一
- 底层：[红黑树](<../../数据结构/7. 查找.md#7-7>) O(log n)

## 1.6.2 常用函数

| 函数 | 作用 |
|---|---|
| `insert(x)` | 插入元素 x |
| `erase(x)` | 删除元素 x |
| `count(x)` | 元素 x 是否存在（0/1） |
| `find(x)` | 查找 x，返回迭代器 |
| `lower_bound(x)` | 返回第一个 ≥ x 的迭代器 |
| `upper_bound(x)` | 返回第一个 > x 的迭代器 |
