# 1.8 unordered_set / unordered_map（哈希容器） <a id="1-8"></a>

[← 返回目录](<C++ STL.md>)

## 1.8.1 简介

unordered_set / unordered_map 基于哈希表实现，插入、删除、查找平均 O(1)，但元素无序。适合只关心查找效率、不需要排序的场景。

## 1.8.2 特性

- 底层：[哈希表](<../../数据结构/7. 查找.md#7-10>)，增删查平均 O(1)
- 无序（元素不自动排序）
- key 唯一

## 1.8.3 常用函数（与 set/map 相同）

```cpp
#include <iostream>
#include <unordered_set>
#include <unordered_map>
#include <string>
using namespace std;

int main(){
    unordered_set<int> s = {10, 20, 30};

    s.insert(40);   // 插入元素
    s.erase(40);    // 删除元素
    cout << s.count(10) << endl;   // 是否存在：1
    cout << *s.find(10) << endl;   // 查找，返回迭代器

    unordered_map<string, int> mp;

    mp.insert({"Tom", 20});   // 插入键值对
    cout << mp.count("Tom") << endl;          // 是否存在：1
    cout << mp.find("Tom")->second << endl;   // 查找，返回迭代器
    mp.erase("Tom");          // 删除键 "Tom"

    return 0;
}
```

## 1.8.4 与 set/map 的区别

- set/map：红黑树，自动排序，查询 O(log n)
- unordered_set/unordered_map：哈希表，无序，查询平均 O(1)
- 需要排序用 set/map；只查重、查映射用 unordered
