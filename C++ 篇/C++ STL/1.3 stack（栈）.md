# 1.3 stack（栈） <a id="1-3"></a>

[← 返回目录](<C++ STL.md>)

## 1.3.1 特性

- 后进先出（LIFO），原理见[栈](<../../数据结构/3. 栈 & 队列.md#3-1>)

## 1.3.2 常用函数

| 函数 | 作用 |
|---|---|
| `push(x)` | 入栈（压入栈顶） |
| `pop()` | 出栈（删除栈顶元素） |
| `top()` | 返回栈顶元素 |
| `empty()` | 判断栈是否为空 |
