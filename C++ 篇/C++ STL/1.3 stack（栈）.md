# 1.3 stack（栈） <a id="1-3"></a>

[← 返回目录](<C++ STL.md>)

## 1.3.1 简介

stack 是栈适配器，只允许在栈顶操作，遵循后进先出（LIFO）。常用于括号匹配、表达式求值等场景，底层默认用 deque 实现。

## 1.3.2 特性

- 后进先出（LIFO），原理见[栈](<../../数据结构/3. 栈 & 队列.md#3-1>)

## 1.3.3 常用函数

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main(){
    stack<int> s;

    s.push(10);   // 入栈（压入栈顶）
    s.push(20);

    cout << s.top() << endl;    // 返回栈顶元素：20
    s.pop();                    // 出栈（删除栈顶元素）
    cout << s.top() << endl;    // 10
    cout << s.empty() << endl;  // 是否为空：0

    return 0;
}
```
