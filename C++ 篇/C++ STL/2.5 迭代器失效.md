# 2.5 迭代器失效 <a id="2-5"></a>

[← 返回目录](<C++ STL.md>)

## 2.5.1 简介

向容器插入或删除元素后，原先的迭代器可能失效；继续使用失效的迭代器属于未定义行为。

- vector：插入元素可能因扩容（重新分配内存）导致所有迭代器失效，即使不扩容，插入位置及其后的迭代器也会失效；erase 删除元素会使被删位置及其后的迭代器失效
- list、set、map 删除元素后，只有指向被删元素的迭代器失效
- list、set、map 插入元素不会使迭代器失效
- 解决办法：用 erase 返回的新迭代器

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main(){
    vector<int> v = {1, 2, 3, 4};

    // 删除所有偶数：erase 返回下一个元素的迭代器
    for (auto it = v.begin(); it != v.end(); ){
        if (*it % 2 == 0)
            it = v.erase(it);
        else
            it++;
    }

    for (int x : v)
        cout << x << " ";   // 1 3
    cout << endl;

    return 0;
}
```
