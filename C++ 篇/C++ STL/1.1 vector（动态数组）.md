# 1.1 vector（动态数组） <a id="1-1"></a> <a id="container"></a>

[← 返回目录](<C++ STL.md>)

## 1.1.1 简介

vector 是动态数组，元素在内存中连续存放，支持下标随机访问。它能自动扩容，适合以尾部插入/删除为主、需要频繁随机访问的场景。

## 1.1.2 特性

- 连续内存（类似数组），对应数据结构中的[顺序表](<../../数据结构/2. 顺序表 & 链表.md#2-1>)
- 尾部插入快（摊还 O(1)）
- 支持随机访问 O(1)

## 1.1.3 常用函数

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main(){
    vector<int> v = {10, 20, 30};

    // 尾部插入 / 删除
    v.push_back(40);
    v.pop_back();

    // 元素个数 / 判空
    cout << v.size() << endl;
    cout << v.empty() << endl;

    // 访问元素
    cout << v.at(0) << endl;   // 越界会抛异常
    cout << v.front() << endl;
    cout << v.back() << endl;

    // 迭代器
    for (auto it = v.begin(); it != v.end(); it++)
        cout << *it << " ";
    cout << endl;

    // 按位置插入 / 删除（pos 为迭代器）
    v.insert(v.begin() + 1, 15);
    v.erase(v.begin() + 1);

    // 清空所有元素
    v.clear();

    return 0;
}
```
