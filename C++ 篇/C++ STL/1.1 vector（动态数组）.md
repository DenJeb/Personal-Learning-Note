# 1.1 vector（动态数组） <a id="1-1"></a> <a id="container"></a>

[← 返回目录](<C++ STL.md>)

## 1.1.1 特性

- 连续内存（类似数组），对应数据结构中的[顺序表](<../../数据结构/2. 顺序表 & 链表.md#2-1>)
- 尾部插入快（摊还 O(1)）
- 支持随机访问 O(1)

## 1.1.2 常用函数

| 函数 | 作用 |
|---|---|
| `push_back(x)` | 尾部插入元素 x |
| `pop_back()` | 删除尾部元素 |
| `size()` | 返回元素个数 |
| `empty()` | 判断是否为空 |
| `clear()` | 清空所有元素 |
| `at(i)` | 访问下标 i 的元素（越界报错） |
| `front()` | 返回第一个元素 |
| `back()` | 返回最后一个元素 |
| `begin(), end()` | 返回首元素迭代器和尾后迭代器 |
| `insert(pos, x)` | 在 pos 位置插入元素 x |
| `erase(pos)` | 删除 pos 位置的元素 |
