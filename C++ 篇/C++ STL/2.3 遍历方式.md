# 2.3 遍历方式 <a id="2-3"></a>

[← 返回目录](<C++ STL.md>)

## 2.3.1 简介

遍历容器需要借助迭代器或范围 for，下面两种写法效果相同。

- 传统迭代器遍历：`for(auto it = v.begin(); it != v.end(); it++)`，用 `*it` 访问元素
- 范围 for（C++11）：`for(auto x : v)`，直接得到元素
- 要修改元素时用引用：`for(auto &x : v)`
