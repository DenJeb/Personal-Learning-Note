# 1.2 list（双向链表） <a id="1-2"></a>

[← 返回目录](<C++ STL.md>)

## 1.2.1 特性

- 非连续内存，对应数据结构中的[双链表](<../../数据结构/2. 顺序表 & 链表.md#2-3>)
- 插入删除 O(1)
- 不支持随机访问

## 1.2.2 常用函数

| 函数 | 作用 |
|---|---|
| `push_back(x)` | 尾部插入元素 x |
| `push_front(x)` | 头部插入元素 x |
| `insert(pos, x)` | 在 pos 位置插入元素 x |
| `erase(pos)` | 删除 pos 位置的元素 |
| `remove(x)` | 删除所有值为 x 的元素 |
