# 1.2 list（双向链表） <a id="1-2"></a>

[← 返回目录](<C++ STL.md>)

## 1.2.1 简介

list 是双向链表，元素在内存中不连续，插入和删除只需修改指针，因此任意位置操作都是 O(1)。代价是不能随机访问，只能通过迭代器顺序访问。

## 1.2.2 特性

- 非连续内存，对应数据结构中的[双链表](<../../数据结构/2. 顺序表 & 链表.md#2-3>)
- 插入删除 O(1)
- 不支持随机访问

## 1.2.3 常用函数

```cpp
#include <iostream>
#include <list>
using namespace std;

int main(){
    list<int> l = {10, 20, 30};

    l.push_back(40);          // 尾部插入元素
    l.push_front(0);          // 头部插入元素
    l.insert(l.begin(), 5);   // 在 pos 位置插入元素
    l.erase(l.begin());       // 删除 pos 位置的元素
    l.remove(20);             // 删除所有值为 20 的元素

    for (auto it = l.begin(); it != l.end(); it++)
        cout << *it << " ";
    cout << endl;

    return 0;
}
```
