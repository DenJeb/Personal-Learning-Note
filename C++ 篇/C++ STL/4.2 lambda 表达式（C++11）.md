## 4.2.1 简介

lambda 表达式让临时函数可以直接写在调用处，不必在类外单独定义。

- 匿名函数，不必单独定义函数
- 格式：`[捕获列表](参数列表){ 函数体 }`
- 常用于 sort 自定义排序

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main(){
    vector<int> v = {3, 1, 2};

    // 不用写 cmp 函数，直接传匿名函数
    sort(v.begin(), v.end(), [](int a, int b){
        return a > b;
    });

    for (int x : v)
        cout << x << " ";   // 3 2 1
    cout << endl;

    return 0;
}
```
