# 1.7 map（映射） <a id="1-7"></a>

[← 返回目录](<C++ STL.md>)

## 1.7.1 特性

- key 自动排序（底层通常为[红黑树](<../../数据结构/7. 查找.md#7-7>)）
- key 唯一

## 1.7.2 常用函数

| 函数 | 作用 |
|---|---|
| `mp[key] = val` | 插入或修改键值对 |
| `insert({k, v})` | 插入键值对 {k, v} |
| `erase(k)` | 删除键 k 的键值对 |
| `find(k)` | 查找键 k，返回迭代器 |
| `count(k)` | 键 k 是否存在（0/1） |
