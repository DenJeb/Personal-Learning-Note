# 1.7 map（映射） <a id="1-7"></a>

[← 返回目录](<C++ STL.md>)

## 1.7.1 简介

map 是关联容器，以键值对（key-value）形式存储，key 自动排序且唯一，底层是红黑树，插入、删除、查找都是 O(log n)。

## 1.7.2 特性

- key 自动排序（底层通常为[红黑树](<../../数据结构/7. 查找.md#7-7>)）
- key 唯一

## 1.7.3 常用函数

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main(){
    map<string, int> mp;

    mp["Tom"] = 20;           // 插入或修改键值对
    mp.insert({"Jeb", 18});   // 插入键值对
    mp.erase("Jeb");          // 删除键 "Jeb" 的键值对

    cout << mp.find("Tom")->second << endl;   // 查找，返回迭代器
    cout << mp.count("Tom") << endl;          // 是否存在：1

    for (auto it = mp.begin(); it != mp.end(); it++)
        cout << it->first << " " << it->second << endl;

    return 0;
}
```
