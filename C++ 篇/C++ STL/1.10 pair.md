# 1.10 pair <a id="1-10"></a>

[← 返回目录](<C++ STL.md>)

## 1.10.1 特性

- 将两个值组合成一个整体（map 里存的就是 pair）
- 不是容器，但常与容器配合使用

## 1.10.2 常用用法

| 用法 | 作用 |
|---|---|
| `make_pair(a, b)` | 创建 pair |
| `{a, b}` | 初始化 pair（C++11） |
| `p.first` | 第一个值 |
| `p.second` | 第二个值 |
