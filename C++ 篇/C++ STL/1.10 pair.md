# 1.10 pair <a id="1-10"></a>

[← 返回目录](<C++ STL.md>)

## 1.10.1 简介

pair 把两个值组合成一个整体，用 first 和 second 分别访问。它常用来表示二元组，也是 map 中存储的元素类型。

## 1.10.2 特性

- 将两个值组合成一个整体（map 里存的就是 pair）
- 不是容器，但常与容器配合使用

## 1.10.3 常用用法

```cpp
#include <iostream>
#include <string>
#include <utility>
using namespace std;

int main(){
    pair<int, string> p = {1, "Tom"};   // 初始化 pair（C++11）

    cout << p.first << endl;    // 第一个值：1
    cout << p.second << endl;   // 第二个值：Tom

    p = make_pair(2, "Jeb");    // 创建 pair 并赋值
    cout << p.first << " " << p.second << endl;   // 2 Jeb

    return 0;
}
```
