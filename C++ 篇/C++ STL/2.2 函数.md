## 2.2.1 简介

迭代器函数用于获取容器的首尾位置，以及不同方向和权限的迭代器。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main(){
    vector<int> v = {1, 2, 3};

    // begin() / end()：指向首元素 / 尾后位置
    for (auto it = v.begin(); it != v.end(); it++)
        cout << *it << " ";
    cout << endl;

    // rbegin() / rend()：反向迭代器，从尾到头遍历
    for (auto it = v.rbegin(); it != v.rend(); it++)
        cout << *it << " ";
    cout << endl;

    // cbegin() / cend()：const 迭代器，只能读不能改
    for (auto it = v.cbegin(); it != v.cend(); it++)
        cout << *it << " ";
    cout << endl;

    return 0;
}
```
