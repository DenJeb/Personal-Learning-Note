# 1.9 priority_queue（优先队列） <a id="1-9"></a>

[← 返回目录](<C++ STL.md>)

## 1.9.1 简介

priority_queue 是优先队列适配器，底层是堆，每次取出的都是当前优先级最高（默认最大）的元素。常用于求前 K 大、Dijkstra 最短路等。

## 1.9.2 特性

- 底层：[堆](<../../数据结构/8. 内部排序.md#8-6>)
- 默认大顶堆：top() 永远是最大元素
- 常用于求前 K 大、[Dijkstra 最短路](<../../数据结构/6. 图.md#6-6-1>)

## 1.9.3 常用函数

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main(){
    priority_queue<int> pq;

    pq.push(10);   // 入队
    pq.push(30);
    pq.push(20);

    cout << pq.top() << endl;    // 返回队首（最大）元素：30
    pq.pop();                    // 出队（删除队首/最大元素）
    cout << pq.top() << endl;    // 20
    cout << pq.size() << endl;   // 元素个数：2
    cout << pq.empty() << endl;  // 是否为空：0

    return 0;
}
```

## 1.9.4 小顶堆（队首最小）

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

int main(){
    priority_queue<int, vector<int>, greater<int>> pq;   // 小顶堆

    pq.push(30);
    pq.push(10);
    pq.push(20);

    cout << pq.top() << endl;   // 10

    return 0;
}
```
