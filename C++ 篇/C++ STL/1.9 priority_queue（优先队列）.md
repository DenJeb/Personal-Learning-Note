# 1.9 priority_queue（优先队列） <a id="1-9"></a>

[← 返回目录](<C++ STL.md>)

## 1.9.1 特性

- 底层：[堆](<../../数据结构/8. 内部排序.md#8-6>)
- 默认大顶堆：top() 永远是最大元素
- 常用于求前 K 大、[Dijkstra 最短路](<../../数据结构/6. 图.md#6-6-1>)

## 1.9.2 常用函数

| 函数 | 作用 |
|---|---|
| `push(x)` | 入队 |
| `pop()` | 出队（删除队首/最大元素） |
| `top()` | 返回队首（最大）元素 |
| `empty()` | 判断是否为空 |
| `size()` | 返回元素个数 |

## 1.9.3 小顶堆（队首最小）

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```
