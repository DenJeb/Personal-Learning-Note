# 1.5 deque（双向队列） <a id="1-5"></a>

[← 返回目录](<C++ STL.md>)

## 1.5.1 简介

deque 是双端队列，两端都能以 O(1) 插入和删除，同时支持随机访问；它由多段连续空间拼接而成，内存不完全连续。

## 1.5.2 特性

- 两端插入/删除都快 O(1)，原理见[双端队列](<../../数据结构/3. 栈 & 队列.md#3-2-3>)
- 支持随机访问
- 内存不完全连续

## 1.5.3 常用函数

```cpp
#include <iostream>
#include <deque>
using namespace std;

int main(){
    deque<int> d = {10, 20, 30};

    d.push_back(40);    // 尾部插入元素
    d.push_front(0);    // 头部插入元素
    d.pop_back();       // 删除尾部元素
    d.pop_front();      // 删除头部元素

    cout << d.front() << endl;   // 返回头部元素
    cout << d.back() << endl;    // 返回尾部元素

    return 0;
}
```
