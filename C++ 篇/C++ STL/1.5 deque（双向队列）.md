# 1.5 deque（双向队列） <a id="1-5"></a>

[← 返回目录](<C++ STL.md>)

## 1.5.1 特性

- 两端插入/删除都快 O(1)，原理见[双端队列](<../../数据结构/3. 栈 & 队列.md#3-2-3>)
- 支持随机访问
- 内存不完全连续

## 1.5.2 常用函数

| 函数 | 作用 |
|---|---|
| `push_back(x)` | 尾部插入元素 x |
| `push_front(x)` | 头部插入元素 x |
| `pop_back()` | 删除尾部元素 |
| `pop_front()` | 删除头部元素 |
| `front()` | 返回头部元素 |
| `back()` | 返回尾部元素 |
