# 4.4 `=`赋值运算符重载 <a id="4-4"></a>

[← 返回目录](<C++面向对象编程.md>)

- **定义：控制对象间的赋值行为，解决浅拷贝带来的内存重复释放或数据不一致问题。**

- 注意：要处理自赋值（**`if (this == &p) return *this;`**）；先释放旧资源再分配新空间；返回 **`*this`** 以支持链式赋值。

- **场景：类成员包含指针、文件句柄、动态数组等需要深拷贝的资源管理类。**

```cpp
class Person{
public:
    Person(int age){
        my_age = new int(age);
    }

    ~Person(){
        if(my_age != nullptr){
            delete my_age;
            my_age = nullptr;
        }
    }

    // 注意：类含指针成员，还应提供拷贝构造函数（深拷贝），否则拷贝时仍会重复释放内存
    Person& operator=(const Person& p){
        // 处理自赋值（如 p1 = p1），否则下面的 delete 会释放自己的数据
        if(this == &p){
            return *this;
        }

        // 检查是否有属性在堆区，如果有则先释放
        if(my_age != nullptr){
            delete my_age;
            my_age = nullptr;
        }

        my_age = new int(*p.my_age);
        return *this;
    }

    int *my_age;
};

void test(){
    Person p1(10);
    Person p2(20);
    Person p3(30);

    p3 = p2 = p1;

    cout << "p1的年龄为：" << *p1.my_age << endl;
    cout << "p2的年龄为：" << *p2.my_age << endl;
    cout << "p3的年龄为：" << *p3.my_age << endl;
}
```
