## 2.5.1 成员变量 和 成员函数 分开储存

```cpp
class Person{
public:
    int age; // 非静态成员变量 sizeof(p) = 4，属于类对象
    static int height; // 静态成员变量 sizeof(p) = 4，不属于类对象
    void func1(){} // 非静态成员函数 sizeof(p) = 4，不属于类对象
    static void func2(){} // 静态成员函数 sizeof(p) = 4，不属于类对象
};

int Person::height = 175;
```

## 2.5.2 this指针

- **this指针**指向被调用函数所属的对象

- **this指针**隐含在每一个**非静态成员函数**内

**this指针的用途：**

1. 当形参和成员变量同名时（名称冲突），用this指针区分

2. 在类的非静态成员函数中返回对象本身：`return *this`

```cpp
class Person{
public:
    Person(int age){
        this->age = age;
    }

    // Person 后面不加 & 就是 20 岁
    Person& PersonAddAge(Person &p){
        this->age += p.age;
        return *this; // this 指向调用者对象（p2），*this 就是 p2 本体
    }

    int age;
};

void test1(){
    Person p1(18);
    cout << "p1的年龄: " << p1.age << endl;
}

void test2(){
    Person p1(10);
    Person p2(10);
    p2.PersonAddAge(p1);
    cout << "p2的年龄: " << p2.age << endl;
}

void test3(){
    Person p1(10);
    Person p2(10);
    p2.PersonAddAge(p1).PersonAddAge(p1).PersonAddAge(p1);
    cout << "p2的年龄: " << p2.age << endl;
}
```
