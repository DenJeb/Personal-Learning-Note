# 2.4 静态成员 <a id="2-4"></a>

[← 返回目录](<C++面向对象编程.md>)

- 在成员变量和成员函数前加上**关键字`static`**，称为静态成员

## 2.4.1 静态成员变量

- 所有对象共享一份数据，不属于某一对象

- 在编译阶段分配内存

- 类内声明，类外初始化

```cpp
class Person{
public:
    static string name;
    static string gender;
    static int age;
};

int Person::age = 18;
string Person::name = "Den";
string Person::gender = "男";

void test(){
    Person p;
    cout << "姓名：" << p.name << " 性别：" << p.gender << " 年龄：" << p.age << endl;

    p.age = 19;
    cout << "姓名：" << p.name << " 性别：" << p.gender << " 年龄：" << p.age << endl;
}

int main(){
    test();
    return 0;
}
```

1. 通过对象访问 `p.age`

2. 通过类名访问 `Person::age`

**类外不能访问 `private` 的静态成员变量**

## 2.4.2 静态成员函数

- 所有对象共享一个函数

- **静态成员函数只能访问静态成员变量**

```cpp
class Person{
public:
    static void func(){
        cout << "静态成员函数调用" << endl;
    }
};

void test(){
    Person p;

    // 通过对象访问
    p.func();

    // 通过类名访问
    Person::func();
}

int main(){
    test();
    return 0;
}
```

1. 通过对象访问 `p.func()`

2. 通过类名访问 `Person::func()`

**类外不能访问 `private` 的静态成员函数**
