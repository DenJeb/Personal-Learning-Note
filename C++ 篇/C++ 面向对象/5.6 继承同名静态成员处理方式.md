# 5.6 继承同名静态成员处理方式 <a id="5-6"></a>

[← 返回目录](<C++面向对象编程.md>)

静态成员和非静态成员出现同名，处理方式一致

- 访问子类同名成员，**直接访问**即可

- 访问父类同名成员，需要加**作用域**

```cpp
class Father{
public:
    static int age;
    static void func();
};
int Father::age = 40;
void Father::func(){
    cout << "Father::func()" << endl;
}

class Son: public Father{
public:
    static int age;
    static void func();
};
int Son::age = 14;
void Son::func(){
    cout << "Son::func()" << endl;
}

void test(){
    Son s;
    cout << "s.age = " << s.age << endl;
    cout << "Son::age = " << Son::age << endl;
    cout << "s.Father::age = " << s.Father::age << endl;
    cout << "Son::Father::age = " << Son::Father::age << endl;
    s.func();
    Son::func();
    s.Father::func();
    Son::Father::func();
}
```
