# 5.5 继承同名成员处理方式 <a id="5-5"></a>

[← 返回目录](<C++面向对象编程.md>)

- 访问子类同名成员，**直接访问**即可

- 访问父类同名成员，需要加**作用域**

```cpp
class Father{
public:
    Father(){
        age = 40;
    }

    void func(){
        cout << "Father 的 func 函数调用" << endl;
    }

    int age;
};

class Son: public Father{
public:
    Son(){
        age = 14;
    }

    void func(){
        cout << "Son 的 func 函数调用" << endl;
    }

    int age;
};

void test(){
    Son s;
    cout << "s.age = " << s.age << endl;
    cout << "s.Father::age = " << s.Father::age << endl;
    s.func();
    s.Father::func();
}
```
