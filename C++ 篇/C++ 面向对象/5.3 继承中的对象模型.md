# 5.3 继承中的对象模型 <a id="5-3"></a>

[← 返回目录](<C++面向对象编程.md>)

父类中所有**非静态成员**属性都会被子类继承

```cpp
class A{
public:
    int a;
protected:
    int b;
private:
    int c;
};

class B: public A{
public:
    int d;
};

void test(){
    cout << "size of class B = " << sizeof(B) << endl; // 16
}
```
