## 2.1.1 构造函数

主要作用在于创建对象时为对象的成员属性赋值，构造函数由编译器自动调用，无需手动调用

**构造函数语法：**`类名(){}`

1. 没有返回值也不写void

2. 函数名与类名相同

3. 可以有参数，可以发生重载

4. 程序创建对象时会自动调用，且只调用一次

```cpp
class Person{
public:
    Person(/* 参数 */){
        // 函数内容
    }
};
```

### 2.1.1.1 构造函数分类

#### 2.1.1.1.1 按参数分类：

1. 无参（默认）构造

2. 有参构造

#### 2.1.1.1.2 按类型分类

1. 普通构造函数

2. 拷贝构造函数

```cpp
class Person{
public:
    Person(const Person &p){
        age = p.age;
        // 将传入对象的所有属性拷贝到当前对象里
    }

    int age;
};
```

### 2.1.1.2 构造函数调用

1. **括号法**

```cpp
Person p1;       // 默认构造函数调用
Person p2(参数); // 有参构造函数调用
Person p3(p2);   // 拷贝构造函数调用
```

2. 显式法

```cpp
Person p1;
Person p2 = Person(参数);
Person p3 = Person(p2);
```

3. 隐式转换法

```cpp
Person p1;
Person p2 = 参数;
Person p3 = p2;
```

**拷贝构造函数的调用时机：**

1. 使用一个已经创建完毕的对象来初始化一个新对象

2. 值传递的方式给函数参数传值

3. 以值的方式返回局部对象

### 2.1.1.3 深拷贝与浅拷贝

1. 浅拷贝：简单的复制拷贝

2. 深拷贝：在堆区重新申请空间，进行拷贝

```cpp
class Person{
public:
    int age; // 普通成员
    int* height; // 指针成员，数据在堆区

    // 构造函数
    Person(int a, int h) : age(a){
        height = new int(h);
    }

    // 拷贝构造函数（深拷贝）：在堆区重新申请空间，进行拷贝
    // 如果不写，编译器提供的默认拷贝构造（浅拷贝）会让两个对象的 height 指向同一块堆区内存，
    // 析构时重复释放同一块内存，导致程序崩溃
    Person(const Person &p) : age(p.age){
        height = new int(*p.height);
    }

    // 析构函数
    ~Person(){
        if(height != nullptr){
            delete height;
            height = nullptr;
        }
    }

    void show(){
        cout << "年龄：" << age << " 身高：" << *height << endl;
    }
};

int main(){
    Person p1(20, 175);
    Person p2(p1); // 拷贝构造：p1 和 p2 的 height 各自指向独立的堆区空间

    p1.show();
    p2.show();

    return 0;
}
```

## 2.1.2 析构函数

主要作用在于对象销毁前系统自动调用，执行一些清理工作

**析构函数语法：**`~类名(){}`

1. 没有返回值也不写void

2. 函数名与类名相同，在前面加上\~

3. 不可以有参数，不可发生重载

4. 程序在销毁对象前会自动调用，且只调用一次

```cpp
class Person{
public:
    ~Person(){
        // 函数内容
    }
};
```
