# 2.3 类对象作为类成员 <a id="2-3"></a>

[← 返回目录](<C++面向对象编程.md>)

**构造**对象时先有其他类的对象，再有本对象（下面**构造**先有`Phone`，再有`Person`；**析构**的时候**反过来**）

```cpp
class Phone{
public:
    Phone(string PName){
        cout << "Phone构造函数" << endl;
        Name = PName;
    }

    string Name;

    ~Phone(){
        cout << "Phone析构函数" << endl;
    }
};

class Person{
public:
    Person(string Name, string pName) : person_Name(Name), phone_Name(pName){
        cout << "Person构造函数" << endl;
    }

    string person_Name;
    Phone phone_Name;

    ~Person(){
        cout << "Person析构函数" << endl;
    }
};
```
