# 6.1 多态基本概念 <a id="6-1"></a> <a id="6"></a>

[← 返回目录](<C++面向对象编程.md>)

多态分为两类：

- 静态多态：**函数重载**和**运算符重载**属于静态多态，复用函数名

- 动态多态：**派生类**和**虚函数**实现运行时多态

两者区别：

- 静态多态的函数地址**早绑定**（**编译阶段**）

- 动态多态的函数地址**晚绑定**（**运行阶段**）

***❗动态多态要求***

1. ***有继承***

2. ***子类重写父类虚函数***

3. ***父类指针或引用指向子类对象***

```cpp
class Animal{
public:
    void voice(){
        cout << "动物" << endl;
    }
};

class Cat: public Animal{
public:
    void voice(){
        cout << "喵" << endl;
    }
};

void test1(Animal &animal){
    animal.voice(); // 动物，早绑定问题
}

void test2(){
    Cat c;
    test1(c); // 父类引用指向子类对象，输出"动物"（早绑定）

    cout << "size of Animal: " << sizeof(Animal) << endl; // 1，类似于空对象
}
```

解决方式↓，加个**`virtual`**

```cpp
class Animal{
public:
    virtual void voice(){
        cout << "动物" << endl;
    }
};

class Cat: public Animal{
public:
    void voice(){
        cout << "喵" << endl;
    }
};

void test1(Animal &animal){
    animal.voice(); // 喵
}

void test2(){
    Cat c;
    test1(c); // 父类引用指向子类对象，输出"喵"（晚绑定）

    cout << "size of Animal: " << sizeof(Animal) << endl; // 8，虚函数指针占8（Win64）/4（Win32）字节
}
```

虚函数（表）指针`vfptr`，占4字节（32位）/8字节（64位）
