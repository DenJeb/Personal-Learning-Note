# 7.1 文本文件 <a id="7-1"></a> <a id="7"></a>

[← 返回目录](<C++面向对象编程.md>)

C\+\+中对文件操作需要包含`<fstream>`

- 文件类型分为2种：

1. **文本文件**：以**ASCII码**形式储存在计算机中

2. **二进制文件**：以**二进制**形式储存在计算机中，一般读不懂（暂未整理）

- 操作文件三大类

1. `ofstream`：写文件

2. `ifstream`：读文件

3. `fstream`：读写文件

## 7.1.1 **写文件**

```cpp
#include <fstream> // 1.包含头文件

ofstream ofs; // 2.创建流对象

ofs.open("文件路径", 打开方式); // 3.打开文件

ofs << "写入的内容..."; // 4.写文件

ofs.close(); // 5.关闭文件
```

|**打开方式**|**解释**|
|---|---|
|**ios::in**|**为读文件而打开文件**|
|**ios::out**|**为写文件而打开文件**|
|**ios::ate**|**初始位置：文件尾**|
|**ios::app**|**追加方式写文件**|
|**ios::trunc**|**如果文件存在先删除，再创建**|
|**ios::binary**|**二进制方式**|

## 7.1.2 读文件

```cpp
#include <fstream> // 1.包含头文件

ifstream ifs; // 2.创建流对象

ifs.open("文件路径", 打开方式); // 3.打开文件

if(ifs.is_open()){            // 4.是否打开成功
    cout << "文件打开成功" << endl;
}else{
    cout << "文件打开失败" << endl;
    return 1;
}

string str;             // 5.读文件
while(getline(ifs, str))
    cout << str << endl;

ifs.close(); // 6.关闭文件
```
