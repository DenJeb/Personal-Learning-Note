# 4.3 `++`递增运算符重载 <a id="4-3"></a>

[← 返回目录](<C++面向对象编程.md>)

- 定义：为对象提供自增行为，分为前置（**`++i`**）和后置（**`i++`**）两种形式。

- 注意：前置返回引用（**`*this`**），后置返回临时对象（值返回）并用 **`int`** 占位区分；后置效率略低。

- **场景：[迭代器](<../C++ STL/2.1 特性.md#iterator>)、计数器、索引类型等需要自增逻辑的对象。**

```cpp
class Integer{
public:
    Integer(){
        num = 0;
    }

    // 前置递增，返回引用是为了一直对一个对象进行递增
    Integer& operator++(){
        num++;
        return *this;
    }

    // 后置递增，int作为占位参数，用于区分前置递增和后置递增
    Integer operator++(int){
        Integer temp = *this;
        num++;
        return temp;
    }

    friend ostream& operator<<(ostream &cout, const Integer &myint);

private:
    int num;
};

ostream& operator<<(ostream &cout, const Integer &myint){
    cout << myint.num;
    return cout;
}

void test1(){
    Integer myint;
    cout << ++myint << endl;
    cout << myint << endl;
}

void test2(){
    Integer myint;
    cout << myint++ << endl;
    cout << myint << endl;
}
```
