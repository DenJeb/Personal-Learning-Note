# 2.7 const修饰成员函数 <a id="2-7"></a>

[← 返回目录](<C++面向对象编程.md>)

**常函数：**

- 成员函数后加`const`成为常函数

- 常函数内不可以修改成员属性

- 常函数成员属性声明时加`mutable`关键字后，可以修改

**常对象：**

- 声明对象时在对象名前加上`const`

- 常对象只能调用常函数

```cpp
class Person{
public:
    void showPerson() const{
        // this->age = 20; // 报错：常函数中 this 是 const Person* const，指向常量对象，成员不可修改
        this->height = 175; // mutable 成员在常函数中可以修改
    }

    int age = 18;
    mutable int height;
};

void test1(){
    Person p;
    p.showPerson();
}

// 常对象
void test2(){
    const Person p{}; // const 对象不能默认初始化（本类没有用户提供的默认构造函数），用 {} 值初始化
    p.height = 180;
    p.showPerson();
}
```
