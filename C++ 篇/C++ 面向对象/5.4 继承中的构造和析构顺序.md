# 5.4 继承中的构造和析构顺序 <a id="5-4"></a>

[← 返回目录](<C++面向对象编程.md>)

**构造（父）→构造（子）→析构（子）→析构（父）**

```cpp
class Father{
public:
    Father(){
        cout << "Father构造函数" << endl;
    }
    ~Father(){
        cout << "Father析构函数" << endl;
    }
};

class Son: public Father{
public:
    Son(){
        cout << "Son构造函数" << endl;
    }
    ~Son(){
        cout << "Son析构函数" << endl;
    }
};

void test(){
    Son s;
}
```
