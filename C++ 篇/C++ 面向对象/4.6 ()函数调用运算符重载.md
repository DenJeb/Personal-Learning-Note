# 4.6 `()`函数调用运算符重载 <a id="4-6"></a>

[← 返回目录](<C++面向对象编程.md>)

- **定义：使对象可以像函数一样被调用，也称“仿函数”或“函数对象”。**（STL 中的仿函数见 [4.1](<../C++ STL/4.1 仿函数（函数对象）.md#4-1>)）

- 注意：可带任意参数和返回值；支持匿名对象调用（**`类名()(参数)`**）。

- **场景：[STL 算法](<../C++ STL/3. algorithm：对数据操作.md#algorithm>)中的自定义规则（如排序、遍历）、策略模式、简单闭包行为模拟。**

```cpp
class MyPrint{
public:
    void operator()(string txt){
        cout << txt << endl;
    }
};

class MyAdd{
public:
    int operator()(int a, int b){
        return a + b;
    }
};

void test(){
    MyPrint myPrint;
    myPrint("Hello World!");

    MyAdd myAdd;
    cout << myAdd(12, 16) << endl;
    cout << MyAdd()(12, 16) << endl; // 匿名函数对象
}
```
