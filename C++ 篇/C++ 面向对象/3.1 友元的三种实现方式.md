# 3.1 **友元的三种实现方式** <a id="3-1"></a> <a id="3"></a>

[← 返回目录](<C++面向对象编程.md>)

对于一些私有`private`属性，可以用友元访问。

友元的关键字为`friend`

## 3.1.1 全局函数做友元

```cpp
class Building{
    friend void goodFriend(Building *building); // 全局函数goodFriend做友元可访问私有成员

public:
    Building();

    string sittingRoom;

private:
    string bedRoom;
};

Building::Building(){
    sittingRoom = "客厅";
    bedRoom = "卧室";
}

// 全局函数
void goodFriend(Building *building){
    cout << "goodFriend 正在访问你的" << building->sittingRoom << endl;
    cout << "goodFriend 正在访问你的" << building->bedRoom << endl;
}

void test(){
    Building building;
    goodFriend(&building);
}
```

## 3.1.2 类做友元

- 让一个类访问另一个类的私有成员

```cpp
class Building{
    friend class GoodFriend;

public:
    Building();

    string sittingRoom;

private:
    string bedRoom;
};

class GoodFriend{
public:
    GoodFriend();

    void visit();

    Building *building;
};

Building::Building(){
    sittingRoom = "客厅";
    bedRoom = "卧室";
}

GoodFriend::GoodFriend(){
    building = new Building; // 注意：示例中 new 的空间未释放，实际使用需在析构函数中 delete
}

void GoodFriend::visit(){
    cout << "goodFriend 正在访问你的" << building->sittingRoom << endl;
    cout << "goodFriend 正在访问你的" << building->bedRoom << endl;
}

void test(){
    GoodFriend gf;
    gf.visit();
}
```

## 3.1.3 成员函数做友元

```cpp
class Building; // 类声明

class GoodFriend{
public:
    GoodFriend();

    void visit();

    Building *building;
};

class Building{
    friend void GoodFriend::visit(); // GoodFriend的成员函数

public:
    Building();

    string sittingRoom;

private:
    string bedRoom;
};

Building::Building(){
    sittingRoom = "客厅";
    bedRoom = "卧室";
}

GoodFriend::GoodFriend(){
    building = new Building; // 注意：示例中 new 的空间未释放，实际使用需在析构函数中 delete
}

void GoodFriend::visit(){
    cout << "goodFriend 正在访问你的" << building->sittingRoom << endl;
    cout << "goodFriend 正在访问你的" << building->bedRoom << endl;
}

void test(){
    GoodFriend gf;
    gf.visit();
}
```
