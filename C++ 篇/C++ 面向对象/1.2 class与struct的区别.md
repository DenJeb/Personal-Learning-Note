# 1.2 class与struct的区别 <a id="1-2"></a>

[← 返回目录](<C++面向对象编程.md>)

struct默认权限为公开，class默认权限为私有。

除此之外，class与struct都能设置权限，区别在默认权限不同：

```cpp
class 名称{
private:   //私有权限，类内可以访问，类外不能访问，子类不能访问
protected: //保护权限，类内可以访问，类外不能访问，子类可以访问
public:    //公共权限，类内可以访问，类外可以访问，子类可以访问
};
```
