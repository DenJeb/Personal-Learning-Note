# 2.6 空指针访问成员函数 <a id="2-6"></a>

[← 返回目录](<C++面向对象编程.md>)

```cpp
class Person{
public:
    void showClassName(){
        cout << "this is Person class" << endl; // 不会报错
    }

    void showPersonAge(){
        // 防止报错
        // if(this == nullptr){
        //     return;
        // }

        cout << "age = " << age << endl; // 会报错
    }

    int age;
};

void test1(){
    Person* p = nullptr;

    p->showClassName(); // 不报错
    p->showPersonAge(); // 报错
}
```
