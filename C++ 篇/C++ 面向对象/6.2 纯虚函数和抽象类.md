# 6.2 纯虚函数和抽象类 <a id="6-2"></a>

[← 返回目录](<C++面向对象编程.md>)

有了纯虚函数的类是抽象类

- 纯虚函数语法：`virtual 返回值类型 函数名(参数) = 0;`

**抽象类特点：**

1. 无法实例化对象

2. 子类必须重写抽象类中的纯虚函数，否则也属于抽象类

```cpp
class Base{
public:
    virtual void func() = 0;

    virtual ~Base() {} // 虚析构：基类指针 delete 派生类对象时才能正确调用派生类析构函数
};

class Son: public Base{
public:
    virtual void func(){
        cout << "func调用" << endl;
    }
};

void test(){
    Base *b = new Son();
    b->func();
    delete b;
}
```
