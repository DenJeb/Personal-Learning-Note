# 5.2 继承方式 <a id="5-2"></a>

[← 返回目录](<C++面向对象编程.md>)

## 5.2.1 公共继承

继承方式：`class B: public A`

| 父类成员权限 | 子类中访问权限 |
|---|---|
| public | public |
| protected | protected |
| private | 不可访问 |

## 5.2.2 保护继承

继承方式：`class B: protected A`

| 父类成员权限 | 子类中访问权限 |
|---|---|
| public | protected |
| protected | protected |
| private | 不可访问 |

## 5.2.3 私有继承

继承方式：`class B: private A`

| 父类成员权限 | 子类中访问权限 |
|---|---|
| public | private |
| protected | private |
| private | 不可访问 |

**注意：父类的 private 成员同样会被继承，只是不可访问。**
