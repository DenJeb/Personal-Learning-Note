# 4. 域名系统（DNS） <a id="4"></a>

[← 返回目录](<网络基础.md>)

URL 是资源的地址，例如 `https://github.com/`；其中的域名 `github.com` 可以通过 DNS 解析为 IP 地址。IP 地址代表了网络上的唯一位置，但不好记忆，这就是域名系统（DNS）诞生的原因。DNS 使用专门的服务器，把你输入的域名（例如 `mozilla.org`）与网站的真实 IP 地址进行匹配。

DNS 查询的大致过程：

1. 先查本地缓存（浏览器缓存、系统 DNS 缓存）和系统 hosts 文件
2. 本地未命中，则向 DNS 服务器发起查询
3. DNS 服务器逐级查询，最终从权威服务器得到 IP 并返回

![DNS 解析示意图](<图片和附件/DNS 解析.jpg>)

大型网站通常会部署在多个服务器上，以便为世界各地的不同用户高效加载；DNS 可能根据你的位置返回不同的 IP 地址（就近调度）。

> 💡 查看本机 IP 可用 Ubuntu 的 [ip addr](<../Ubuntu Linux 命令/7.1 ifconfig 与 ip（网络接口）.md#cmd-ifconfig>)。
