# 8. 实战：命令行 <a id="8"></a>

[← 返回目录](<网络基础.md>)

用三个命令就可以亲手验证前面讲的核心链路——DNS 解析 → 网络连通性 → 应用层访问：

```text
nslookup github.com
        ↓
   DNS：域名 → IP

ping github.com
        ↓
   ICMP：测试网络连通性

curl.exe -I https://github.com
        ↓
   HTTPS：真正访问 Web 服务
```
