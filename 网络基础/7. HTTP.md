# 7. HTTP <a id="7"></a>

[← 返回目录](<网络基础.md>)

HTTP（HyperText Transfer Protocol）是一种**应用层协议**，用于客户端和服务器之间进行资源交换。

HTTP 采用**客户端-服务器（Client-Server）模型**：客户端发送 **Request（请求）**，服务器返回 **Response（响应）**。

HTTP 最初主要用于获取超文本资源，但现在也广泛用于获取图片、视频、JSON 数据，以及向服务器提交数据，因此是 Web 数据交换的核心协议。

![HTTP 客户端-服务器交互示意图](<图片和附件/客户端-服务器交互.png>)

## 7.1 HTTP 消息（HTTP Messages） <a id="7-1"></a>

客户端和服务器通过交换 **HTTP 消息（HTTP Message）** 进行通信：

- 客户端发送 **Request（请求）**
- 服务器返回 **Response（响应）**

```text
Client
   │
   │ HTTP Request
   ▼
Server
   │
   │ HTTP Response
   ▼
Client
```

![HTTP 请求与响应示意图](<图片和附件/HTTP 请求与响应.png>)

常见的 HTTP 通信基于：

```text
HTTP/1.1 → TCP
HTTP/2   → TCP
HTTP/3   → QUIC（基于UDP）
```

HTTPS 并不是另一种独立的应用层协议，而是 **HTTP + TLS**，用于加密 HTTP 通信。

HTTP/1.1 的消息可以直接以文本形式观察，非常适合用来理解 HTTP 的基本结构；HTTP/2、HTTP/3 对底层传输方式进行了优化，但 HTTP 的核心语义（方法、状态码、Header、Body 等）仍然保留。

## 7.2 请求（Request） <a id="7-2"></a>

请求包含以下要素：

```text
HTTP Request

┌──────────────────────────────┐
│ Request Line                 │
│ Method + Path + Version      │
├──────────────────────────────┤
│ Headers                      │
├──────────────────────────────┤
│ Body（可选）                 │
└──────────────────────────────┘
```

![HTTP 请求示意图](<图片和附件/HTTP 请求.jpg>)

- **请求行（Request Line）**：`方法 + 路径 + HTTP 版本`，例如 `GET /en-US/ HTTP/1.1`
- **方法（Method）**：要执行的操作，常见的有 GET、POST、PUT、PATCH、DELETE（FastAPI 中对应 `@app.get` 等路由装饰器，见 [FastAPI 路由](<../Python 篇/FastAPI/1.2 路由.md>)）
- **路径（Path）**：URL 中域名（和端口）之后、查询参数（`?`）之前的部分，例如 `/en-US/`
- **HTTP 协议版本（Version）**
- **标头（Headers）**：可选，用于向服务器传递附加信息
- **Body（主体）**：可选，包含发送的资源（如 POST 提交的表单或 JSON 数据）（FastAPI 的请求体参数见 [FastAPI 1.2](<../Python 篇/FastAPI/1.2 路由.md>)）

常见方法对应的命令行示例：

```shell
# GET
curl.exe https://httpbin.org/get

# POST
curl.exe -X POST https://httpbin.org/post

# PUT
curl.exe -X PUT https://httpbin.org/put

# PATCH
curl.exe -X PATCH https://httpbin.org/patch

# DELETE
curl.exe -X DELETE https://httpbin.org/delete
```

## 7.3 响应（Response） <a id="7-3"></a>

响应包含以下要素：

![HTTP 响应示意图](<图片和附件/HTTP 响应.jpg>)

- **HTTP 协议版本（Version）**
- **状态码（Status Code）**：表示服务器处理请求的结果，详见 [MDN 状态码参考](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status)，FastAPI 中对应 `HTTPException`，见 [FastAPI 1.4](<../Python 篇/FastAPI/1.4 处理异常.md>)
- **状态消息（Status Message）**：对状态码的非权威性简短描述
- **标头（Headers）**：关于响应的附加信息，例如响应的位置或提供该响应的服务器信息
- **Body（主体）**：已获取资源的内容

### 7.3.1 状态码分类

| 分类 | 含义       | 常见例子                           |
|------|------------|------------------------------------|
| 1xx  | 信息性响应 | 101 Switching Protocols            |
| 2xx  | 成功       | 200 OK、201 Created                |
| 3xx  | 重定向     | 301 永久移动、302 临时移动         |
| 4xx  | 客户端错误 | 400 Bad Request、404 Not Found     |
| 5xx  | 服务器错误 | 500 服务器内部错误、503 服务不可用 |

## 7.4 标头（Header） <a id="7-4"></a>

Header（请求头 / 响应头）是 HTTP 消息中的**元数据**，用于描述请求或响应的附加信息。

### 7.4.1 请求头（Request Headers）

包含有关要获取的资源或请求该资源的客户端的更多信息。

常见请求头：

- `Host`：目标主机（域名）
- `User-Agent`：客户端信息（浏览器、操作系统等）
- `Accept`：客户端可接受的响应内容类型
- `Content-Type`：请求 Body 的内容类型

### 7.4.2 响应头（Response Headers）

常见响应头：

- `Content-Type`：响应 Body 的内容类型
- `Content-Length`：响应 Body 的长度（字节数）
- `Set-Cookie`：要求客户端保存的 Cookie
- `Location`：重定向的目标地址

## 7.5 JSON <a id="7-5"></a>

JSON（JavaScript Object Notation）是一种常见的**数据交换格式**。HTTP 接口通常用 JSON 作为请求/响应的 Body，配合 `Content-Type: application/json` 使用。（FastAPI 的请求/响应模型见 [FastAPI 1.2](<../Python 篇/FastAPI/1.2 路由.md>)）

例如：

```json
{
    "name": "Den",
    "age": 19,
    "student": true,
    "skills": ["JSON", "Python", "HTTP"],
    "address": {
        "city": "Beijing",
        "country": "China"
    }
}
```

![JSON 对象结构示意图](<图片和附件/JSON 对象结构.jpg>)

## 7.6 基于 HTTP 的 API <a id="7-6"></a>

客户端可以通过各种工具或编程语言发起 HTTP 请求，例如：

- JavaScript：Fetch API
- Python：`requests`
- 命令行：`curl`
- 浏览器：地址栏 / DevTools

后端通常通过 HTTP API 向客户端提供服务。（Python 后端框架示例见 [FastAPI](<../Python 篇/FastAPI/FastAPI.md>)）

## 7.7 请求与响应示例 <a id="7-7"></a>

HTTP 使用一组简单的方法（动词）表达操作，其中 GET 最常用。例如：

```http
GET /en-US/ HTTP/1.1
Host: developer.mozilla.org
Accept: text/html
```

服务器发送的响应：

```http
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 45227

<!doctype html>
...
```
