# 1.2 路由

[← 返回目录](FastAPI.md)

路由就是**URL 地址**和**处理函数**的映射关系，它决定了当用户访问某个 URL 时，会调用哪个处理函数。

> 💡 路径参数、查询参数都是 URL 的组成部分，见[网络基础 5](<../../网络基础/网络基础.md#5>)；装饰器名对应 HTTP 方法，见[网络基础 7.2](<../../网络基础/网络基础.md#7-2>)。

![FastAPI 请求参数来源对照图](<图片和附件/FastAPI 请求参数来源对照图.jpg>)

## 1.2.1 路径参数

* 位置：URL 路径的一部分
* 例如：`/user/{user_id}`
* 作用：指向唯一、特定的资源
* 代码：
```python
from fastapi import Path

@app.get("/user/{user_id}")
async def get_user(user_id: int = Path(gt=0, lt=101, description="1-100之间的用户ID")):
    return {"user_id": user_id}
```
**`Path`：用于声明路径参数的额外信息和校验规则**
* `gt`/`ge`：大于/大于等于
* `lt`/`le`：小于/小于等于
* `min_length`：最小长度
* `max_length`：最大长度
* `description`：参数描述
* `default`：默认值

## 1.2.2 查询参数

* 位置：URL ? 之后，用 & 分隔
* 例如：`/user?name=Den&age=18`
* 作用：用于过滤、排序、分页等操作
* 代码：
```python
from fastapi import Query

@app.get("/user")
async def get_user(
    name: str = Query(..., description="用户姓名"),
    age: int = Query(18, description="用户年龄，默认18")
):
    return {"name": name, "age": age}
```
**`Query`：用于声明查询参数的额外信息和校验规则**
* `gt`/`ge`：大于/大于等于
* `lt`/`le`：小于/小于等于
* `min_length`：最小长度
* `max_length`：最大长度
* `description`：参数描述
* `default`：默认值

## 1.2.3 请求体参数

* 位置：HTTP 请求的消息体（Body）中（见[网络基础 7.2](<../../网络基础/网络基础.md#7-2>)）
* 作用：用于创建、更新资源，携带大量数据（如 JSON）
* 代码：
```python
from pydantic import BaseModel, Field

class User(BaseModel):
    username: str = Field(min_length=2, max_length=10, description="用户名(2-10个字符)")
    password: str = Field(min_length=8, max_length=16, description="密码(8-16个字符)")

@app.post("/register")
async def register(user: User):
    # 不返回 password 字段，避免密码泄露（也可用 response_model 过滤，见 1.3.2 节）
    return {"username": user.username}
```
**`BaseModel`：定义 Pydantic 数据模型，并进行数据解析与验证**

**`Field`：用于为模型字段添加校验规则、描述、默认值等信息**
* `gt`/`ge`：大于/大于等于
* `lt`/`le`：小于/小于等于
* `min_length`：最小长度
* `max_length`：最大长度
* `description`：参数描述
