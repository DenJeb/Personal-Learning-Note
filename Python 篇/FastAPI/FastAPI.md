# FastAPI

> 🏠 [返回笔记首页](<../../README.md>)

> FastAPI 是一个现代、快速（高性能）的 Python Web 框架，用于构建 API。它基于 Python 的类型提示（Type Hints），使用 Starlette 作为 Web 部分，Pydantic 作为数据部分。
