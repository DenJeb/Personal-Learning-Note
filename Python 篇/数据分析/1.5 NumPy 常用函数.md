# 1.5 NumPy 常用函数 <a id="1-5"></a>

[← 返回目录](<Python数据分析.md>)

常用函数按功能分为 7 类：

| 分类 | 函数 | 说明 |
|------|------|------|
| 基本数学 | `np.sqrt(x)` | 平方根 |
| | `np.exp(x)` | e 的 x 次方 |
| | `np.log(x)` | 自然对数 |
| | `np.sin(x)` | 正弦 |
| | `np.abs(x)` | 绝对值 |
| | `np.power(a, b)` | a 的 b 次方 |
| | `np.round(x, n)` | 银行家舍入（四舍六入五成双），保留 n 位小数 |
| 统计 | `np.sum(x)` | 求和 |
| | `np.mean(x)` | 平均值 |
| | `np.median(x)` | 中位数 |
| | `np.std(x)` | 标准差 |
| | `np.var(x)` | 方差 |
| | `np.min(x) / np.max(x)` | 最小值 / 最大值 |
| | `np.percentile(x, q)` | 第 q 分位数 |
| 比较 | `np.greater(a, b)` | a > b |
| | `np.less(a, b)` | a < b |
| | `np.equal(a, b)` | a == b |
| | `np.where(条件, 满足返回, 不满足返回)` | 按条件返回对应值 |
| 排序 | `np.sort(x)` | 排序 |
| 去重 | `np.unique(x)` | 去重 |
| 分割 | `np.split(x, m)` | 分成 m 个 |
| 重整（改变形状） | `np.reshape(x, shape)` | 改变数组形状 |
