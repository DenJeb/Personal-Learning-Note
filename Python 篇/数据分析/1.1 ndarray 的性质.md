# 1.1 ndarray 的性质 <a id="1-1"></a> <a id="numpy"></a>

[← 返回目录](<Python数据分析.md>)

NumPy（Numerical Python）是 Python 科学计算的基础库，其核心是 **ndarray**（N 维数组），可以理解为“高性能的列表”——计算速度比 Python 原生列表更快，功能也更丰富。

- **多维性**：ndarray 可以是一维、二维甚至更高维度的数组。
- **同质性**：同一个 ndarray 中的所有元素必须是相同的数据类型。
