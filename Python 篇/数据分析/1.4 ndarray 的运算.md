# 1.4 ndarray 的运算 <a id="1-4"></a>

[← 返回目录](<Python数据分析.md>)

- 一维、二维数组：`arr1 + arr2` —— 对应位置的元素逐个相加
- 列表（实现相同的效果需要循环）：

```python
for i in range(len(list1)):
    list1[i] += list2[i]
```

- 矩阵乘法：`arr1 @ arr2`

> ⚠️ 注意：
> - `arr1 * arr2` 是矩阵**相同位置的元素相乘**，不是矩阵乘法。
> - 列表的合并是 `list1 + list2`（拼接），而 ndarray 的 `+` 是逐元素相加——两者语义完全不同。
