# 2.1 核心数据结构——Series <a id="2-1"></a> <a id="pandas"></a>

[← 返回目录](<Python数据分析.md>)

Pandas 建立在 NumPy 之上，是处理表格型数据的核心库，提供两种核心数据结构：

| 数据结构   | 维度 | 说明                     |
|-----------|------|--------------------------|
| Series    | 一维 | 带索引的数组             |
| DataFrame | 二维 | 表格，由行索引和列名组成 |

Series 是带**标签（索引）**的一维数组，可以理解为“带索引的列表”。

## 2.1.1 Series 的创建

```python
import pandas as pd

# 初始创建
s1 = pd.Series([1, 2, 3])
print(s1)

# 自定义 index
s2 = pd.Series([1, 2, 3], index=['A', 'B', 'C'])
print(s2)

# 自定义 name
s3 = pd.Series([1, 2, 3], index=['A', 'B', 'C'], name='嘿嘿')
print(s3)

# 通过字典创建
s4 = pd.Series({"A": 1, "B": 2, "C": 3})
print(s4)

# 通过已有 Series 选取部分索引
s5 = pd.Series(s4, index=["A", "C"])
print(s5)
```

## 2.1.2 Series 的属性

```python
import pandas as pd

s = pd.Series([1, 2, 3], index=['A', 'B', 'C'], name="test")
print(s.index)    # 索引
print(s.values)   # 值
print(s.name)     # 名称
print(s.dtype)    # 数据类型
print(s.shape)    # 形状
print(s.ndim)     # 维度数
print(s.size)     # 元素个数
```

## 2.1.3 Series 访问数据

访问单个元素的四种方式对比：

| 方法 | 索引类型 | 是否支持切片 |
|------|---------|-------------|
| `loc` | 显式（标签） | 支持 |
| `iloc` | 隐式（位置） | 支持 |
| `at` | 显式（标签） | 不支持 |
| `iat` | 隐式（位置） | 不支持 |

```python
import pandas as pd

s = pd.Series([1, 2, 3, 4, 5, 6], index=['A', 'B', 'C', 'D', 'E', 'F'], name="test")
# bool 索引访问
print(s[s > 3])
# 访问前 5 个数据（默认）
print(s.head())
# 访问前 3 个数据
print(s.head(3))
# 访问后 5 个数据（默认）
print(s.tail())
# 访问后 3 个数据
print(s.tail(3))
```

## 2.1.4 Series 的常用方法

**统计与查看**

| 方法 | 说明 |
| --- | --- |
| `head()` | 查看前 n 行数据，默认 5 行 |
| `tail()` | 查看后 n 行数据，默认 5 行 |
| `isin()` | 判断元素是否包含在参数集合中 |
| `isna()` | 判断是否为缺失值（如 NaN 或 None） |
| `sum()` | 求和，自动忽略缺失值 |
| `mean()` | 平均值 |
| `min()` | 最小值 |
| `max()` | 最大值 |
| `var()` | 方差 |
| `std()` | 标准差 |
| `median()` | 中位数 |
| `mode()` | 众数（可返回多个） |
| `quantile(q)` | 分位数，q 取 0~1 之间 |
| `describe()` | 常见统计信息（count、mean、std、min、25%、50%、75%、max） |

**数据处理与排序**

| 方法 | 说明 |
| --- | --- |
| `value_counts()` | 每个唯一值的出现次数 |
| `count()` | 非缺失值数量 |
| `nunique()` | 唯一值个数（去重） |
| `unique()` | 获取去重后的值数组 |
| `drop_duplicates()` | 去除重复项 |
| `sample()` | 随机抽样 |
| `sort_index()` | 按索引排序 |
| `sort_values()` | 按值排序 |
| `replace()` | 替换值 |
| `keys()` | 返回 Series 的索引对象 |
