# 2.2 核心数据结构——DataFrame <a id="2-2"></a>

[← 返回目录](<Python数据分析.md>)

DataFrame 是带**行索引**和**列名**的二维表格，可以看作多个 Series 按列组合。

## 2.2.1 DataFrame 的创建

```python
import numpy as np
import pandas as pd

# 通过 Series 创建
s1 = pd.Series([1, 2, 3, 4, 5])
s2 = pd.Series([6, 7, 8, 9, 10])
df = pd.DataFrame({"Line1": s1, "Line2": s2})
print(type(df))
print(type(df["Line1"]))

# 通过字典创建
df = pd.DataFrame(
    {
        "id": ['a', 'b', 'c', 'd', 'e'],
        "name": ["Jack", "Curry", "Jeb", "Pluto", "Den"],
        "age": [11, 36, 18, 16, 19],
    }, index=[1, 2, 3, 4, 5], columns=["id", "name", "age"]
)
print(df)
```

## 2.2.2 DataFrame 的属性

```python
# df 沿用 2.2.1 创建的 DataFrame
print(df)
print(df.index)    # 行索引
print(df.columns)  # 列名
print(df.values)   # 数据值
print(df.shape)    # 形状（5 行 3 列）
print(df.ndim)     # 维度数
print(df.size)     # 元素个数
print(df.dtypes)   # 每列的数据类型
print(df.T)        # 转置
```

## 2.2.3 DataFrame 访问数据

```python
# df 沿用 2.2.1 创建的 DataFrame
print(df['name'])            # 访问单列
print(df.name)               # 通过属性名访问单列
print(df[['name', 'age']])   # 访问多列
print(df.tail(3))            # 访问后 3 行
print(df[df['age'] >= 18])   # bool 索引（筛选年龄 >= 18 的行）
print(df.sample())           # 随机抽样
```

## 2.2.4 DataFrame 的常用方法

| 方法 | 说明 |
| --- | --- |
| `head()` | 查看前 n 行数据，默认 5 行 |
| `tail()` | 查看后 n 行数据，默认 5 行 |
| `isin()` | 判断元素是否包含在参数集合中 |
| `isna()` | 判断是否为缺失值（如 NaN 或 None） |
| `sum()` | 求和，自动忽略缺失值 |
| `mean()` | 平均值 |
| `min()` | 最小值 |
| `max()` | 最大值 |
| `var()` | 方差 |
| `std()` | 标准差 |
| `median()` | 中位数 |
| `mode()` | 众数（可返回多个） |
| `quantile(q)` | 分位数，q 取 0~1 之间 |
| `describe()` | 常见统计信息（count、mean、std、min、25%、50%、75%、max） |
| `value_counts()` | 每个唯一值的出现次数 |
| `count()` | 非缺失值数量 |
| `duplicated()` | 是否重复 |
| `drop_duplicates()` | 去除重复项 |
| `sample()` | 随机抽样 |
| `replace()` | 替换值 |
| `sort_index()` | 按索引排序 |
| `sort_values()` | 按值排序 |
| `nlargest()` | 返回某列最大的 n 条数据 |
| `nsmallest()` | 返回某列最小的 n 条数据 |
