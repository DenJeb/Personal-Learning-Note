# 1.4 DML

[← 返回目录](<MySQL.md>)

> **DML（Data Manipulation Language）**：数据操作语言，用于操作表中的数据。

## 1.4.1 INSERT

**插入一条数据**

```sql
INSERT INTO users (id, username, age)
VALUES (1, 'Tom', 18);
```

**插入多条数据**

```sql
INSERT INTO users (id, username, age)
VALUES
    (2, 'Jack', 20),
    (3, 'Alice', 19);
```

如果按照表中所有字段的顺序插入：

```sql
INSERT INTO users
VALUES (4, 'Bob', 21);
```

## 1.4.2 UPDATE

修改数据：

```sql
UPDATE users
SET age = 22
WHERE id = 4;
```

同时修改多个字段：

```sql
UPDATE users
SET username = 'Robert',
    age = 23
WHERE id = 4;
```

> ⚠️ **注意**
>
> `UPDATE` 不写 `WHERE`，会修改所有数据。

```sql
UPDATE users
SET age = 20;
```

## 1.4.3 DELETE

删除指定数据：

```sql
DELETE FROM users
WHERE id = 4;
```

> ⚠️ **注意**
>
> `DELETE` 不写 `WHERE`，会删除表中的所有数据。

```sql
DELETE FROM users;
```
