# 1.3 DDL

[← 返回目录](MySQL.md)

> **DDL（Data Definition Language）**：数据定义语言，用于操作数据库和表结构。

## 1.3.1 数据库操作

**查看数据库**

```sql
SHOW DATABASES;
```

**创建数据库**

```sql
CREATE DATABASE test;
```

指定字符集：

```sql
CREATE DATABASE test
DEFAULT CHARACTER SET utf8mb4;
```

**删除数据库**

```sql
DROP DATABASE test;
```

**使用数据库**

```sql
USE test;
```

**查看当前使用的数据库**

```sql
SELECT DATABASE();
```

## 1.3.2 表操作

**查看当前数据库中的所有表**

```sql
SHOW TABLES;
```

**查看表结构**

```sql
DESC user;
```

**查看完整建表语句**

```sql
SHOW CREATE TABLE user;
```

**创建表**

```sql
CREATE TABLE user (
    id INT,
    name VARCHAR(20),
    age INT
);
```

**添加字段**

```sql
ALTER TABLE user
ADD email VARCHAR(50);
```

**修改字段类型**

```sql
ALTER TABLE user
MODIFY age TINYINT;
```

**修改字段名和类型**

```sql
ALTER TABLE user
CHANGE name username VARCHAR(20);
```

**删除字段**

```sql
ALTER TABLE user
DROP email;
```

**修改表名**

```sql
ALTER TABLE user
RENAME TO users;
```

**删除表**

```sql
DROP TABLE users;
```

如果不确定表是否存在：

```sql
DROP TABLE IF EXISTS users;
```

> ⚠️ `DROP TABLE` 会删除表结构以及表中的所有数据。
