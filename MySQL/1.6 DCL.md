# 1.6 DCL

[← 返回目录](<MySQL.md>)

> **DCL（Data Control Language）**：数据控制语言，用于管理数据库用户和权限。

## 1.6.1 用户管理

**查询用户**

```sql
SELECT *
FROM mysql.user;
```

**创建用户**

```sql
CREATE USER 'dev'@'localhost'
IDENTIFIED BY '123456';
```

**修改用户密码**

```sql
ALTER USER 'dev'@'localhost'
IDENTIFIED BY '654321';
```

**删除用户**

```sql
DROP USER 'dev'@'localhost';
```

## 1.6.2 权限管理

**查询用户权限**

```sql
SHOW GRANTS FOR 'dev'@'localhost';
```

**授予查询权限**

```sql
GRANT SELECT
ON test.users
TO 'dev'@'localhost';
```

**授予所有权限**

```sql
GRANT ALL
ON test.*
TO 'dev'@'localhost';
```

**撤销查询权限**

```sql
REVOKE SELECT
ON test.users
FROM 'dev'@'localhost';
```
