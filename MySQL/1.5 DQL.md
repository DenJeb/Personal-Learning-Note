# 1.5 DQL

[← 返回目录](MySQL.md)

> **DQL（Data Query Language）**：数据查询语言，核心语句是 `SELECT`。

## 1.5.1 基本查询

查询所有字段：

```sql
SELECT *
FROM users;
```

查询指定字段：

```sql
SELECT username, age
FROM users;
```

## 1.5.2 字段别名

使用 `AS`：

```sql
SELECT username AS name
FROM users;
```

`AS` 可以省略：

```sql
SELECT username name
FROM users;
```

## 1.5.3 条件查询

使用 `WHERE`：

```sql
SELECT *
FROM users
WHERE age > 18;
```

常见比较运算符：

| 运算符         | 含义   |
| ----------- | ---- |
| `=`         | 等于   |
| `<>` / `!=` | 不等于  |
| `>`         | 大于   |
| `<`         | 小于   |
| `>=`        | 大于等于 |
| `<=`        | 小于等于 |

## 1.5.4 逻辑运算符

**AND**

多个条件同时满足：

```sql
SELECT *
FROM users
WHERE age >= 18
  AND age <= 30;
```

**OR**

满足其中一个条件：

```sql
SELECT *
FROM users
WHERE age < 18
   OR age > 60;
```

**NOT**

对条件取反：

```sql
SELECT *
FROM users
WHERE NOT age = 18;
```

## 1.5.5 BETWEEN

查询指定范围：

```sql
SELECT *
FROM users
WHERE age BETWEEN 18 AND 30;
```

等价于：

```sql
SELECT *
FROM users
WHERE age >= 18
  AND age <= 30;
```

> 💡 `BETWEEN ... AND ...` 包含两端的值。

## 1.5.6 IN

判断是否属于指定集合：

```sql
SELECT *
FROM users
WHERE age IN (18, 20, 22);
```

等价于：

```sql
SELECT *
FROM users
WHERE age = 18
   OR age = 20
   OR age = 22;
```

## 1.5.7 LIKE

用于模糊查询。

`%` 表示任意数量的字符：

```sql
SELECT *
FROM users
WHERE username LIKE 'Tom%';
```

`_` 表示一个字符：

```sql
SELECT *
FROM users
WHERE username LIKE 'Tom_';
```

## 1.5.8 NULL

不能使用 `=` 判断 `NULL`：

```sql
SELECT *
FROM users
WHERE age = NULL;
```

应该使用 `IS NULL`：

```sql
SELECT *
FROM users
WHERE age IS NULL;
```

判断非空：

```sql
SELECT *
FROM users
WHERE age IS NOT NULL;
```

> ⚠️ `NULL` 表示“没有值”，不是普通的数据值。

## 1.5.9 DISTINCT

去除查询结果中的重复数据：

```sql
SELECT DISTINCT age
FROM users;
```

## 1.5.10 聚合函数

> **聚合函数**：对一列数据做整体计算，返回单个结果。
>
> 💡 本小节及 1.5.11~1.5.13 的示例基于 [1.8.3 外键约束](1.8%20约束.md#183-外键约束) 定义的 `dept`/`emp` 表与 [1.9.2 多表查询概述](1.9%20多表查询.md#192-多表查询概述) 的示例数据，首次阅读可先跳到 1.9.2 查看。

| 函数      | 作用             |
| --------- | ---------------- |
| COUNT     | 统计数量         |
| MAX / MIN | 最大值 / 最小值  |
| SUM       | 求和             |
| AVG       | 平均值           |

```sql
-- 查询员工总数、最高薪资、平均薪资
SELECT COUNT(*), MAX(salary), AVG(salary)
FROM emp;
```

> ⚠️ 聚合函数不计算 `NULL` 值（`COUNT(*)` 除外，它统计的是行数）。
>
> 💡 `COUNT(字段)` 会忽略该字段为 `NULL` 的行，`COUNT(*)` 统计所有行。

## 1.5.11 分组查询

> **分组查询**：按某列分组（`GROUP BY`），对每组分别做聚合计算。

```sql
SELECT 分组字段, 聚合函数(...)
FROM 表
[WHERE 条件]
GROUP BY 分组字段
[HAVING 分组后过滤条件];
```

```sql
-- 查询每个部门的平均薪资
SELECT dept_id, AVG(salary) AS avg_salary
FROM emp
WHERE dept_id IS NOT NULL
GROUP BY dept_id;
```

`WHERE` 与 `HAVING` 的区别：

| 关键字 | 过滤时机 | 能否使用聚合函数 |
| ------ | -------- | ---------------- |
| WHERE  | 分组之前 | 不能             |
| HAVING | 分组之后 | 能               |

```sql
-- 查询平均薪资高于 6500 的部门
SELECT dept_id, AVG(salary) AS avg_salary
FROM emp
WHERE dept_id IS NOT NULL
GROUP BY dept_id
HAVING AVG(salary) > 6500;
```

## 1.5.12 排序查询

> **排序查询**：`ORDER BY` 对查询结果排序。

```sql
-- 按薪资升序（ASC 为默认值，可省略）
SELECT name, salary
FROM emp
ORDER BY salary;

-- 按薪资降序
SELECT name, salary
FROM emp
ORDER BY salary DESC;

-- 多字段排序：先按部门升序，同部门内按薪资降序
SELECT name, dept_id, salary
FROM emp
ORDER BY dept_id, salary DESC;
```

## 1.5.13 分页查询

> **分页查询**：`LIMIT` 限制返回的记录数，常配合起始索引实现分页。

```sql
-- 第 1 页：从索引 0 开始取 2 条
SELECT *
FROM emp
LIMIT 0, 2;

-- 第 2 页：跳过前 2 条，取 2 条
SELECT *
FROM emp
LIMIT 2, 2;
```

> 💡 语法为 `LIMIT 起始索引, 查询条数`，起始索引从 0 开始。第 n 页的起始索引 = (n - 1) × 每页条数。

## 1.5.14 执行顺序

DQL 的书写顺序与执行顺序不同：

```sql
SELECT ...          -- 5
FROM ...            -- 1
WHERE ...           -- 2
GROUP BY ...        -- 3
HAVING ...          -- 4
ORDER BY ...        -- 6
LIMIT ...;          -- 7
```

> 💡 由此可知：`WHERE` 中不能使用 `SELECT` 里定义的别名（`WHERE` 先于 `SELECT` 执行），而 `ORDER BY` 中可以。
