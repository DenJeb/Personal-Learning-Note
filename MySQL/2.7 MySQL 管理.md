## 2.7.1 系统数据库

| 数据库             | 作用                                                       |
| ------------------ | ---------------------------------------------------------- |
| `mysql`            | 核心系统库：用户、权限、存储过程、事件等系统信息           |
| `information_schema` | 元数据信息：库、表、列、索引、权限等（虚拟库，不占磁盘） |
| `performance_schema` | 性能监控数据：SQL 执行、锁等待、内存使用等               |
| `sys`              | 基于 `performance_schema` 的视图，便于查看性能指标         |

## 2.7.2 常用工具

**mysql 客户端**

```bash
# 登录
mysql -u root -p

# 登录指定主机和端口
mysql -h 192.168.1.10 -P 3306 -u root -p

# 直接执行 SQL 并退出
mysql -u root -p test -e "SELECT COUNT(*) FROM emp;"
```

**mysqladmin**

```bash
mysqladmin -u root -p status      # 查看运行状态
mysqladmin -u root -p version     # 查看版本信息
mysqladmin -u root -p shutdown    # 关闭 MySQL 服务
```

**mysqlbinlog**

```bash
# 查看二进制日志内容
mysqlbinlog -vv binlog.000001
```

**mysqlshow**

```bash
mysqlshow -u root -p              # 查看所有数据库
mysqlshow -u root -p test         # 查看库中的表
mysqlshow -u root -p test emp     # 查看表结构
```

**mysqldump**

```bash
# 备份单个数据库
mysqldump -u root -p test > test.sql

# 备份所有数据库
mysqldump -u root -p --all-databases > all.sql

# 只备份表结构
mysqldump -u root -p -d test > test_schema.sql

# 备份并获取一致性快照（InnoDB，不锁表）
mysqldump -u root -p --single-transaction test > test.sql
```

**数据导入**

```bash
# 命令行导入 SQL 文件
mysql -u root -p test < test.sql

# mysqlimport 导入文本数据
mysqlimport -u root -p test /path/emp.txt
```

```sql
-- 在 mysql 客户端中使用 source
SOURCE /path/test.sql;
```

> 💡 `mysqldump` 属于逻辑备份，生成 SQL 文件，可跨版本、跨平台恢复，但数据量大时速度较慢；物理备份（直接复制数据文件）速度更快，但通常要求版本一致。
