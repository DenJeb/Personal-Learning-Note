# 1.2 SQL 分类

[← 返回目录](MySQL.md)

SQL 根据功能主要分为以下几类：

| 分类      | 全称                         | 作用        |
| ------- | -------------------------- | --------- |
| **DDL** | Data Definition Language   | 定义数据库、表结构 |
| **DML** | Data Manipulation Language | 增、删、改数据   |
| **DQL** | Data Query Language        | 查询数据      |
| **DCL** | Data Control Language      | 用户与权限管理   |
