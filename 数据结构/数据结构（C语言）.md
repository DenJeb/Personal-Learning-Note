## 1. 算法基本概念 <a id="ch1"></a>

### 1.1 时间复杂度 <a id="1-1"></a>

定义：算法中基本运算（通常是最深层循环内的语句）的重复执行次数，是问题规模 n 的函数 T(n)。只保留最高阶项、忽略系数，用大 O 记号表示。

加法规则：T(n) = T₁(n) + T₂(n) = O(max(f(n), g(n)))

乘法规则：T(n) = T₁(n) × T₂(n) = O(f(n) × g(n))

常见复杂度从小到大：

O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)

最好、最坏、平均时间复杂度：通常最关心**最坏时间复杂度**。

### 1.2 空间复杂度 <a id="1-2"></a>

定义：算法运行过程中额外消耗的存储空间 S(n)。

**原地工作**：空间复杂度为 O(1)，即所需辅助空间为常数级。

## 2. 顺序表 & 链表 <a id="ch2"></a>

### 2.1 顺序表 <a id="2-1"></a>

定义：用一组地址连续的存储单元依次存储线性表中的数据元素，支持**随机存取**。

> 💡 C++ STL 对应实现：[vector](<../C++ 篇/C++ STL/C++ STL.md#1-1>)。

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];  // 存放数据元素
    int length;         // 当前表长
} SqList;
```

1. 插入：平均移动 n/2 个元素，O(n)
2. 删除：平均移动 (n-1)/2 个元素，O(n)
3. 按位查找：O(1)（随机存取）；按值查找：O(n)

### 2.2 单链表 <a id="2-2"></a>

定义：通过指针链接的链式存储，节点 = 数据域 + 指针域。只能**顺序存取**。

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

头插法建表（结果与输入顺序**相反**）：

```c
// 带头节点的头插法：每次插入到表头
void HeadInsert(LinkList &L, int x){
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = x;
    s->next = L->next;
    L->next = s;
}
```

尾插法建表（结果与输入顺序**相同**）：

```c
void TailInsert(LinkList &L, int x){  // 需维护尾指针 r
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = x;
    s->next = NULL;
    r->next = s;
    r = s;
}
```

删除第 i 个节点（先找到前驱 p，即第 i-1 个节点）：

```c
LNode *q = p->next;
p->next = q->next;
free(q);
```

按位查找、按值查找均为 O(n)。带头节点的好处：插入/删除操作统一，无需特殊处理首元素。

### 2.3 双链表 <a id="2-3"></a>

> 💡 C++ STL 对应实现：[list](<../C++ 篇/C++ STL/C++ STL.md#1-2>)；MySQL 的 B+Tree 索引叶子节点也用双向链表串联，见 [MySQL 2.2.2](<../MySQL/MySQL.md#222-索引结构>)。

```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

在 p 之后插入节点 s（假设 p 不是表尾节点）：

```c
s->next = p->next;
p->next->prior = s;
s->prior = p;
p->next = s;
```

删除 p 的后继节点 q（假设 q 不是表尾节点）：

```c
DNode *q = p->next;
p->next = q->next;
q->next->prior = p;
free(q);
```

### 2.4 循环链表 <a id="2-4"></a>

1. 循环单链表：表尾节点的 next 指向头节点。判空：L->next == L
2. 循环双链表：头节点的 prior 指向表尾。判空：L->next == L 且 L->prior == L

### 2.5 静态链表 <a id="2-5"></a>

用数组实现的链表，节点的指针域存放数组下标（游标），结束标志为 -1。适用于不支持指针的语言（如早期 Basic/Fortran）。

### 2.6 顺序表 vs 链表 <a id="2-6"></a>

| 对比项 | 顺序表 | 链表 |
|---|---|---|
| 存取方式 | 随机存取 O(1) | 顺序存取 O(n) |
| 插入/删除 | 需移动元素 O(n) | 只需修改指针 O(1)（已知位置时） |
| 空间 | 静态分配，可能浪费 | 按需分配，但有指针开销 |
| 适用场景 | 表长固定、查多改少 | 表长变化大、改多查少 |

## 3. 栈 & 队列 <a id="ch3"></a>

### 3.1 栈 <a id="3-1"></a>

定义：只允许在**一端**（栈顶）进行插入和删除的线性表。**后进先出（LIFO）**。

> 💡 C++ STL 对应实现：[stack](<../C++ 篇/C++ STL/C++ STL.md#1-3>)。

#### 3.1.1 顺序栈

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;  // 栈顶指针
} SqStack;
```

1. 初始：top = -1
2. 判空：top == -1；判满：top == MaxSize - 1
3. 入栈：data[++top] = x；出栈：x = data[top--]

#### 3.1.2 链栈

用单链表实现，栈顶在表头。入栈 = 头插法，出栈 = 删除第一个节点。不存在栈满问题。

#### 3.1.3 栈在递归中的应用

递归调用的本质是函数调用栈：每层递归的局部变量、参数、返回地址保存在栈帧中。递归过深可能导致**栈溢出**（stack overflow）。

#### 3.1.4 练习：括号匹配

```c
bool check(char str[]){
    char stack[MaxSize];
    int top = -1;
    for(int i = 0; str[i] != '\0'; i++){
        char c = str[i];
        if(c == '(' || c == '[' || c == '{')
            stack[++top] = c;                       // 左括号入栈
        else {
            if(top == -1) return false;             // 右括号多了
            char t = stack[top--];
            if((c == ')' && t != '(') ||
               (c == ']' && t != '[') ||
               (c == '}' && t != '{'))
                return false;                       // 不匹配
        }
    }
    return top == -1;                               // 左括号多了则栈非空
}
```

### 3.2 队列 <a id="3-2"></a>

定义：只允许在**队尾**插入、**队头**删除的线性表。**先进先出（FIFO）**。

> 💡 C++ STL 对应实现：[queue](<../C++ 篇/C++ STL/C++ STL.md#1-4>)。

应用：[树的层次遍历](#5-5-4)、[图的 BFS](#6-3)、操作系统缓冲区。

#### 3.2.1 顺序队列（循环队列）

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;  // 队头指针、队尾指针
} SqQueue;
```

1. 初始：front = rear = 0
2. 判空：front == rear
3. 判满：(rear + 1) % MaxSize == front（**牺牲一个存储单元**）
4. 入队：data[rear] = x; rear = (rear + 1) % MaxSize
5. 出队：x = data[front]; front = (front + 1) % MaxSize
6. 元素个数：(rear - front + MaxSize) % MaxSize

#### 3.2.2 链式队列

带头节点的单链表 + 队头、队尾两个指针。入队尾插，出队头删。

#### 3.2.3 双端队列 <a id="3-2-3"></a>

两端都可以入队和出队。

> 💡 C++ STL 对应实现：[deque](<../C++ 篇/C++ STL/C++ STL.md#1-5>)。

1. 输出受限的双端队列：一端可入可出，另一端只可入
2. 输入受限的双端队列：一端可入可出，另一端只可出

## 4. 串 <a id="ch4"></a>

定义：串（字符串）是由零个或多个字符组成的有限序列。

**基本操作（常见计算题）**：

| 操作 | 示例 | 结果 |
|---|---|---|
| StrLength | StrLength('abc') | 3 |
| SubString | SubString('command', 4, 3) | 'man' |
| Index | S = 'abcaabcaaabc'，T = 'bca' | Index(S, T, 1) = 2；Index(S, T, 3) = 6；Index(S, T, 8) = 0 |
| Replace | S = 'abcaabcaabca'，T = 'bca'，V = 'x' | S = 'axaxax' |
| StrInsert | S = 'sdent'，T = 'tu' | StrInsert(S, 2, T) → S = 'student' |

### 4.1 串的存储结构 <a id="4-1"></a>

#### 4.1.1 定长顺序存储

```c
#define MAXSTRLEN 255
typedef unsigned char SString[MAXSTRLEN + 1];  // 0 号单元存放串长
```

1. 用定长数组存储，0 号单元存放串长
2. 超过 MAXSTRLEN 的串值会被**截断**
3. Concat(&T, S1, S2) 的三种情况：
   - S1[0] + S2[0] ≤ MAXSTRLEN：完整联接，不截断
   - S1[0] < MAXSTRLEN 且 S1[0] + S2[0] > MAXSTRLEN：S2 部分截断
   - S1[0] = MAXSTRLEN：T 只等于 S1（S2 全部丢失）

#### 4.1.2 堆分配存储

```c
typedef struct {
    char *ch;    // 按串长动态分配；空串为 NULL
    int length;
} HString;
```

用 malloc/free 按需分配空间，不会被截断。操作思路：先分配再复制（如 StrInsert 需先为 S 重新分配 S、T 长度之和的空间，再复制）。

#### 4.1.3 块链存储

把串分成若干块，每块存若干字符，用链表连接。块越大，存储密度越高（存储密度 = 串值所占存储位 / 实际分配存储位）。

### 4.2 朴素模式匹配 <a id="4-2"></a>

```c
// 返回子串 t 在主串 s 中第一次出现的位置，未找到返回 -1
int Index(char s[], char t[]){
    int n = strlen(s), m = strlen(t);
    for(int i = 0; i <= n - m; i++){
        int j;
        for(j = 0; j < m; j++)
            if(s[i + j] != t[j]) break;
        if(j == m) return i;
    }
    return -1;
}
```

最坏时间复杂度 O(nm)（如 s = "aaa...aab"、t = "aaab" 时）。

### 4.3 KMP 算法 & next 数组 <a id="4-3"></a>

核心思想：主串指针 i **不回溯**，利用已匹配的信息移动模式串。时间复杂度 O(n + m)。

#### 4.3.1 求 next 数组

```c
// next[j]：模式串第 j 个字符失配时，应回退到的位置（0 基下标版本）
void getNext(char t[], int next[]){
    int m = strlen(t);
    int i = 0, j = -1;
    next[0] = -1;                        // 首字符失配，主串 i 前进一位
    while(i < m - 1){
        if(j == -1 || t[i] == t[j])
            next[++i] = ++j;
        else
            j = next[j];
    }
}
```

手动求法（1 基下标）：

1. next[1] = 0，next[2] = 1
2. 第 j 个字符前的 j-1 个字符中，最长的**相等前后缀**长度为 k，则 next[j] = k + 1

手算示例（T = 'abaabcac'）：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | a | b | c | a | c |
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

如 j = 6：前 5 个字符 'abaab' 的最长相等前后缀为 'ab'（长度为 2），故 next[6] = 2 + 1 = 3。

#### 4.3.2 KMP 匹配

```c
int KMP(char s[], char t[]){
    int next[100];                   // next 数组长度 ≥ 模式串长度
    getNext(t, next);
    int i = 0, j = 0;
    while(i < strlen(s) && j < strlen(t)){
        if(j == -1 || s[i] == t[j]){ i++; j++; }
        else j = next[j];                // 主串不动，模式串回退
    }
    if(j == strlen(t)) return i - j;
    return -1;
}
```

改进：**nextval 数组**。当 t[j] == t[next[j]] 时，直接继承 nextval[next[j]]，避免重复比较（如 "aaaab" 这类模式串）。上例 T = 'abaabcac' 的 nextval 为：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |
| nextval[j] | 0 | 1 | 0 | 2 | 1 | 3 | 0 | 2 |

如 j = 3：T[3] = T[next[3]] = T[1] = 'a'，失配回溯后必然再次失配，故 nextval[3] = nextval[1] = 0。

## 5. 树 <a id="ch5"></a>

### 5.1 树的基本性质 <a id="5-1"></a>

1. 节点数 = 总度数 + 1（除根外每个节点恰有一个前驱）
2. 度为 m 的树，第 i 层至多有 m^(i-1) 个节点
3. 高度为 h 的 m 叉树至多有 (m^h - 1)/(m - 1) 个节点

### 5.2 二叉树 <a id="5-2"></a>

定义：每个节点至多有两棵子树，且**左右次序不可颠倒**。

与度为 2 的树的区别：二叉树可以为空；度为 2 的树至少有 3 个节点。若某节点只有一个孩子，二叉树必须区分是左孩子还是右孩子，而度为 2 的树不区分。

性质：

1. 第 i 层至多有 2^(i-1) 个节点
2. 高度为 h 的二叉树至多有 2^h - 1 个节点
3. 叶子节点数 n₀ = 度为 2 的节点数 n₂ + 1
4. 具有 n 个节点的**完全二叉树**：高度 ⌈log₂(n+1)⌉；按层序从 1 编号，编号 i 的节点——左孩子 2i、右孩子 2i+1、父节点 ⌊i/2⌋；i > ⌊n/2⌋ 的节点为叶子
5. 满二叉树：每层都满（共 2^h - 1 个节点）；完全二叉树：只允许最后一层不满，且节点靠左排列

### 5.3 二叉树的存储 <a id="5-3"></a>

#### 5.3.1 顺序存储

按层序编号存入数组（下标从 1 开始）。适合完全二叉树；一般二叉树会浪费大量空间。

#### 5.3.2 链式存储

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

n 个节点的二叉链表共有 2n 个指针域，其中 n + 1 个为空（[线索二叉树](#5-7)的出发点）。

### 5.4 树的存储 <a id="5-4"></a>

1. **双亲表示法**：每个节点存数据 + 父节点下标（数组实现）。找双亲 O(1)，找孩子需遍历全表
2. **孩子表示法**：每个节点用单链表存其所有孩子。找孩子方便，找双亲麻烦
3. **孩子兄弟表示法**（树的二叉树表示法，与[树 → 二叉树转换](#5-6)的规则一致）：左孩子右兄弟

```c
typedef struct CSNode {
    int data;
    struct CSNode *firstchild, *nextsibling;  // 第一个孩子、右兄弟
} CSNode, *CSTree;
```

### 5.5 遍历方法 <a id="5-5"></a>

#### 5.5.1 先序遍历（根左右）

```c
void PreOrder(BiTree T){
    if(T == NULL) return;
    visit(T);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}
```

#### 5.5.2 中序遍历（左根右）

```c
void InOrder(BiTree T){
    if(T == NULL) return;
    InOrder(T->lchild);
    visit(T);
    InOrder(T->rchild);
}
```

#### 5.5.3 后序遍历（左右根）

```c
void PostOrder(BiTree T){
    if(T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    visit(T);
}
```

#### 5.5.4 层次遍历（借助队列） <a id="5-5-4"></a>

```c
void LevelOrder(BiTree T){
    Queue Q;
    EnQueue(Q, T);
    while(!isEmpty(Q)){
        BiTNode *p = DeQueue(Q);
        visit(p);
        if(p->lchild) EnQueue(Q, p->lchild);
        if(p->rchild) EnQueue(Q, p->rchild);
    }
}
```

> 提示：已知**先序 + 中序**或**后序 + 中序**可唯一确定一棵二叉树（先/后序定根，中序分左右子树）。仅知先序 + 后序不能唯一确定。

### 5.6 转换方法 <a id="5-6"></a>

1. 树 → 二叉树：每个节点左指针接第一个孩子，右指针接右兄弟（"左孩子右兄弟"）
2. 森林 → 二叉树：各树分别转换，再依次作为前一棵的右子树链接
3. 二叉树 → 森林：沿右链依次断开（根有右孩子则属于森林）
4. 二叉树 → 树：左孩子右兄弟的逆过程

### 5.7 线索二叉树 <a id="5-7"></a>

背景：n 个节点的二叉链表有 n + 1 个空指针域，浪费。线索化：用空指针存放遍历序列中的**前驱/后继**。

```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // tag = 0：孩子指针；tag = 1：线索
} ThreadNode, *ThreadTree;
```

中序线索化：

```c
void InThread(ThreadTree &T, ThreadTree &pre){
    if(T == NULL) return;
    InThread(T->lchild, pre);
    if(T->lchild == NULL){ T->lchild = pre; T->ltag = 1; }        // 左线索指向前驱
    if(pre != NULL && pre->rchild == NULL){ pre->rchild = T; pre->rtag = 1; }  // 前驱的右线索指向当前
    pre = T;
    InThread(T->rchild, pre);
}
```

作用：不用栈/递归即可实现遍历；找中序前驱/后继方便（ltag = 1 时 lchild 即前驱，rtag = 1 时 rchild 即后继）。

### 5.8 哈夫曼树与哈夫曼编码 <a id="5-8"></a>

#### 5.8.1 定义

1. 节点的带权路径长度：权值 × 节点到根的路径长度（边数）
2. 树的带权路径长度 WPL = Σ(叶节点权值 × 路径长度)
3. **哈夫曼树**：n 个带权叶子构成的二叉树中 WPL 最小的树，也称最优二叉树

#### 5.8.2 构造

每次从集合中取权值最小的两棵树合并成一棵新树（新树权值 = 两者之和），重复 n - 1 次。可用[小根堆](#8-6)（优先队列）实现。

```c
// 用最小堆（优先队列）实现：每次取两个最小节点合并后放回
HuffmanTree CreateHuffman(int w[], int n){
    // 1. n 个叶子节点（权值 w[i]）放入小根堆
    // 2. 循环 n-1 次：取出两个权值最小的节点，
    //    合并为新节点（权值 = 两者之和），新节点放回堆中
    // 3. 堆中最后一个节点即为哈夫曼树的根
}
```

性质：哈夫曼树只有度为 0 和度为 2 的节点，总节点数 = 2n - 1。

#### 5.8.3 哈夫曼编码

左分支记 0、右分支记 1，从根到叶子的路径即该字符的编码。是**前缀编码**（任一编码都不是另一编码的前缀），解码无歧义；频率高的字符路径短，总编码长度最短。

### 5.9 并查集 <a id="5-9"></a>

支持两种操作的数据结构：**查**（判断两个元素是否属于同一集合）、**并**（合并两个集合）。用双亲表示法（数组）实现。

```c
int fa[N];

void Init(int n){                    // 初始化：每个元素各成一棵树
    for(int i = 0; i < n; i++) fa[i] = i;
}

int Find(int x){                     // 查：找根节点（含路径压缩）
    return fa[x] == x ? x : (fa[x] = Find(fa[x]));
}

void Union(int a, int b){            // 并：合并两棵树
    fa[Find(a)] = Find(b);
}
```

另一种实现：**负数双亲 + 按大小合并**（根的双亲值存负数，绝对值为集合元素数；合并时把元素少的根接到元素多的根下，降低树高）：

```c
// 初始化 S[i] = -1；S[root] < 0 表示 root 是根，|S[root]| 为集合元素数
void Union(int S[], int Root1, int Root2){
    if(S[Root1] > S[Root2]){   // Root1 元素少（负数更大）
        S[Root2] += S[Root1];  // 元素数累加
        S[Root1] = Root2;      // 元素少的根接到元素多的根下
    } else {
        S[Root1] += S[Root2];
        S[Root2] = Root1;
    }
}
```

应用：[Kruskal 算法](#6-5)判断边的两端是否已连通。

## 6. 图 <a id="ch6"></a>

### 6.1 图的定义与术语 <a id="6-1"></a>

定义：图 G 由顶点集 V 和边（弧）集 E 构成，记作 G = (V, E)。

1. **有向图 / 无向图**：有向边（弧）带方向，记为 <v, w>（v 为弧尾，w 为弧头）；无向边记为 (v, w)
2. **度 / 入度 / 出度**：无向图中顶点度 = 依附该顶点的边数；有向图中入度 = 指向该顶点的弧数，出度 = 从该顶点出发的弧数，度 = 入度 + 出度
3. **路径 / 回路**：顶点序列 v₁, v₂, ..., vₖ 中相邻顶点间有边（弧）则构成路径；起点 = 终点的路径称为回路。简单路径：顶点不重复出现的路径；简单回路：除起点终点外顶点不重复的回路
4. **连通 / 连通分量**：无向图中两顶点间有路径则连通；极大连通子图称为连通分量
5. **强连通 / 强连通分量**：有向图中两顶点互相可达则强连通；极大强连通子图称为强连通分量
6. **完全图**：n 个顶点的无向完全图有 n(n - 1) / 2 条边；有向完全图有 n(n - 1) 条弧
7. **生成树 / 生成森林**：连通图包含全部顶点的极小连通子图（恰 n - 1 条边）为生成树；非连通图各连通分量的生成树构成生成森林
8. **权与网**：边（弧）上带的数值称为权；带权的图称为网
9. **稠密图 / 稀疏图**：|E| 接近 |V|² 的图为稠密图；|E| 远小于 |V|² 的图为稀疏图

边与度的关系（握手定理）：无向图所有顶点的度之和 = 2|E|；有向图 Σ入度 = Σ出度 = |E|

### 6.2 图的存储 <a id="6-2"></a>

#### 6.2.1 邻接矩阵法

n 个顶点用 n×n 矩阵表示，边存在则为权值（无权图记 1），否则为 0 或 ∞。

```c
#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];                       // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum];         // 邻接矩阵
    int vexnum, arcnum;                           // 顶点数、边数
} MGraph;
```

特点：适合**稠密图**；判断两顶点是否相邻 O(1)；求某顶点的所有邻边需遍历一行 O(n)。无向图的矩阵对称，可压缩存储。

#### 6.2.2 邻接表法

每个顶点一个单链表，存其所有邻接边。

```c
typedef struct ArcNode {
    int adjvex;               // 该边指向的顶点
    struct ArcNode *next;     // 下一条边
    int weight;               // 权值（可选）
} ArcNode;

typedef struct VNode {
    char data;
    ArcNode *first;           // 第一条边
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```

特点：适合**稀疏图**；空间复杂度无向图 O(|V| + 2|E|)、有向图 O(|V| + |E|)；求顶点的出边方便，求入边需遍历全表（可另建逆邻接表）。

#### 6.2.3 十字链表法（有向图）

```c
typedef struct ArcBox {           // 弧节点
    int tailvex, headvex;         // 弧尾、弧头顶点编号
    struct ArcBox *hlink, *tlink; // 同弧头链、同弧尾链
    int weight;
} ArcBox;
typedef struct VexNode {          // 顶点节点
    char data;
    ArcBox *firstin, *firstout;   // 第一条入弧、第一条出弧
} VexNode;
```

每个弧节点同时挂在"同弧头链"（hlink）和"同弧尾链"（tlink）上。既能方便找出边，也能方便找入边。

#### 6.2.4 邻接多重表法（无向图）

```c
typedef struct EBox {             // 边节点
    int ivex, jvex;               // 边的两个端点
    struct EBox *ilink, *jlink;   // 分别指向依附于 ivex / jvex 的下一条边
    int weight;
} EBox;
```

每条边只存一个节点，被两个端点的边链共享。方便删除边、标记已访问的边。

### 6.3 图的广度优先遍历（BFS） <a id="6-3"></a>

类似树的层次遍历：借助队列 + visited 数组。

```c
bool visited[MaxVertexNum];

void BFS(ALGraph G, int v){
    Queue Q;
    visit(v); visited[v] = true;
    EnQueue(Q, v);
    while(!isEmpty(Q)){
        int u = DeQueue(Q);
        for(ArcNode *p = G.vertices[u].first; p != NULL; p = p->next){
            int w = p->adjvex;
            if(!visited[w]){
                visit(w); visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}

void BFSTraverse(ALGraph G){          // 非连通图需遍历所有顶点
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;
    for(int i = 0; i < G.vexnum; i++)
        if(!visited[i]) BFS(G, i);
}
```

复杂度：邻接表 O(|V| + |E|)，邻接矩阵 O(|V|²)。

应用：求[无权图的单源最短路径](#6-6-1)。

### 6.4 图的深度优先遍历（DFS） <a id="6-4"></a>

类似树的先序遍历：递归（本质是栈）+ visited 数组。

```c
void DFS(ALGraph G, int v){
    visit(v); visited[v] = true;
    for(ArcNode *p = G.vertices[v].first; p != NULL; p = p->next){
        int w = p->adjvex;
        if(!visited[w]) DFS(G, w);
    }
}

void DFSTraverse(ALGraph G){          // 非连通图需遍历所有顶点
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;
    for(int i = 0; i < G.vexnum; i++)
        if(!visited[i]) DFS(G, i);
}
```

复杂度同 BFS。

### 6.5 最小生成树 <a id="6-5"></a>

定义：连通无向图的[生成树](#6-1)中，权值之和最小的那棵。

1. **Prim 算法**：从某个顶点开始构建生成树，每次将代价最小的新顶点纳入新生成树，直到所有顶点都纳入。时间复杂度 O(|V|²)，与边数无关，适用于**稠密图**。

2. **Kruskal 算法**：每次选择一条权值最小的边，使这条边的两头连通（用[并查集](#5-9)判断是否成环），直到所有节点都连通。时间复杂度 O(|E|log₂|E|)（排序），适用于**稀疏图**。

```c
// Kruskal 伪代码：边按权值从小到大排序，用并查集判断是否成环
for(每条边按权值从小到大){
    if(Find(边.起点) != Find(边.终点)){
        Union(边.起点, 边.终点);
        将该边纳入生成树;
    }
}
```

### 6.6 最短路径问题 <a id="6-6"></a>

#### 6.6.1 单源最短路径 <a id="6-6-1"></a>

1. **[BFS 算法](#6-3)**（无权图）：从源点 BFS，第一次访问到某顶点时的路径即最短路径。O(|V| + |E|)

2. **Dijkstra 算法**（带权图，**权值非负**）：贪心，每次选未确定顶点中 dist 最小的，用其更新邻接点的 dist。O(|V|²)（邻接矩阵）。不适用于负权值

> 💡 C++ 可用 [priority_queue](<../C++ 篇/C++ STL/C++ STL.md#1-9>) 维护待确定顶点。

```c
// Dijkstra 伪代码
初始化：dist[源点] = 0，其余为 ∞；所有顶点未确定;
循环 n 次：
    取未确定顶点中 dist 最小的 v，标记为已确定;
    对 v 的所有邻接点 w：
        dist[w] = min(dist[w], dist[v] + 边(v, w)权值);
```

#### 6.6.2 各顶点间最短路径

**Floyd 算法**（无权、带权图，允许负权值，不允许负环）：动态规划，三重循环 O(|V|³)。

```c
// 初始化 d[i][j]：i == j 为 0，有边为边权，无边为 ∞
for(int k = 0; k < n; k++)            // 允许经过的中间顶点集合逐步扩大
    for(int i = 0; i < n; i++)
        for(int j = 0; j < n; j++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

### 6.7 有向无环图（DAG） <a id="6-7"></a>

#### 6.7.1 拓扑排序 <a id="6-7-1"></a>

定义：把 DAG 的顶点排成线性序列，使得每条有向边的起点都排在终点之前。时间复杂度 O(|V| + |E|)。

```c
// 思路：每次输出入度为 0 的顶点，并删除其所有出边
初始化入度表 indegree[];
将所有入度为 0 的顶点入栈（或队列）;
while(栈不空){
    弹出 v，输出 v;
    对 v 的每个邻接点 w：
        indegree[w]--;
        if(indegree[w] == 0) 入栈;
}
若输出顶点数 < n，说明图中存在环（拓扑排序失败）;
```

应用：检测有向图中是否有环；安排 [AOV 网](#6-7-2)中活动的先后顺序。

#### 6.7.2 AOV 网 <a id="6-7-2"></a>

用 DAG 图（有向无环图）表示一个工程。顶点表示活动，有向边 <Vi, Vj> 表示活动 Vi 必须先于活动 Vj 进行。

#### 6.7.3 AOE 网

在带权有向图中，以顶点表示事件，以有向边表示活动，以边上的权值表示完成该活动的开销（如完成活动所需的时间）。AOE 网中只有一个入度为 0 的点，为开始顶点（源点）；只有一个出度为 0 的点，为结束顶点（汇点）。

#### 6.7.4 关键路径

定义：从源点到汇点的**最长路径**，其长度决定整个工程的最短完成时间。关键路径上的活动称为**关键活动**，任何关键活动的延迟都会导致整个工程延迟。

求解步骤：

1. [拓扑排序](#6-7-1)，求各事件的最早发生时间 ve(k)：ve(源点) = 0；ve(k) = max{ve(j) + 边(j, k)权值}
2. 逆拓扑排序，求各事件的最迟发生时间 vl(k)：vl(汇点) = ve(汇点)；vl(j) = min{vl(k) - 边(j, k)权值}
3. 活动 a = <j, k> 的最早开始时间 e = ve(j)；最迟开始时间 l = vl(k) - 边权值
4. **e = l 的活动为关键活动**；所有关键活动组成的路径即关键路径

## 7. 查找 <a id="ch7"></a>

### 7.1 查找长度与平均查找长度 <a id="7-1"></a>

1. 查找长度：在查找运算中，需要对比关键字的次数
2. 平均查找长度（ASL）：所有查找过程需要对比关键字次数的平均值

### 7.2 顺序查找 O(n) <a id="7-2"></a>

```c
for(int i = 0; i < n; i++)
    if(target == a[i])
        return true;
```

哨兵优化版（省去每次循环的越界判断）：

```c
// 下标 0 作为哨兵，数据从下标 1 开始存放
int SeqSearch(int a[], int n, int target){
    a[0] = target;
    int i;
    for(i = n; a[i] != target; i--);
    return i;  // 返回 0 表示查找失败
}
```

ASL(成功) = (n + 1) / 2；ASL(失败) = n + 1。适用于顺序表和链表（链表无法[折半](#7-3)）。

### 7.3 折半查找（二分）O(log₂n) <a id="7-3"></a>

前提：**顺序存储 + 有序**。

> 💡 C++ STL 对应函数：[binary_search / lower_bound / upper_bound](<../C++ 篇/C++ STL/C++ STL.md#algorithm>)。

```c
while(left <= right){
    int mid = left + (right - left) / 2;
    if(a[mid] < target)
        left = mid + 1;
    else if(a[mid] > target)
        right = mid - 1;
    else
        return true;
}
```

1. 折半查找判定树是平衡二叉树
2. 折半查找判定树：左子树节点数 - 右子树节点数 = 1 或 0
3. ASL ≈ log₂(n + 1) - 1

### 7.4 分块查找（分治） <a id="7-4"></a>

把表分成若干块，**块内无序、块间有序**（前一块的最大关键字 < 后一块的最小关键字）。先在索引表中[折半查找](#7-3)确定所在块，再在块内顺序查找。

若均匀分为 b 块、每块 s 个记录（n = bs），索引和块内都用顺序查找：ASL = (b + 1) / 2 + (s + 1) / 2；当 s = √n 时 ASL 最小。

### 7.5 二叉排序树（BST） <a id="7-5"></a>

性质：

1. 左子树上所有节点的关键字都小于根节点的关键字；
2. 右子树上所有节点的关键字都大于根节点的关键字（左子树关键字 < 根节点关键字 < 右子树关键字）；
3. 左子树和右子树也各是一棵二叉排序树。

```c
BSTNode *BSTSearch(BSTree T, int key){
    if (T == NULL) return NULL;

    if (key == T->key)
        return T;
    else if (key < T->key)
        return BSTSearch(T->lchild, key);
    else
        return BSTSearch(T->rchild, key);
}
```

> 提示：
> 1. 树有多高就递归几层；
> 2. 插入节点和查找节点都源于这个代码思想。

构造 BST：

```c
void Creat_BST(BSTree &T, int str[], int n){
    T = NULL;
    int i = 0;
    while(i < n){
        BST_Insert(T, str[i]);
        i++;
    }
}
```

删除节点：

1. 叶子节点：直接删
2. 只有一个子树：用子树顶替删除位置
3. 有两个子树：用前驱（左子树最右下）或后继（右子树最左下）顶替

### 7.6 平衡二叉树（AVL 树）O(log₂n) <a id="7-6"></a>

特性：插入/删除操作很容易破坏"平衡"，需要频繁调整树的形态。适合**以查为主**。

平衡因子：左子树高度 - 右子树高度（AVL 树所有节点的平衡因子只能为 -1、0、1）。

#### 7.6.1 插入操作

（在最小不平衡子树上调整）

1. LL：在 A 的左孩子的左子树中插入导致不平衡——A 的左孩子右上旋转
2. RR：在 A 的右孩子的右子树中插入导致不平衡——A 的右孩子左上旋转
3. LR：在 A 的左孩子的右子树中插入导致不平衡——A 的左孩子的右孩子先左上旋转再右上旋转
4. RL：在 A 的右孩子的左子树中插入导致不平衡——A 的右孩子的左孩子先右上旋转再左上旋转

#### 7.6.2 删除操作

1. 删除节点（同 [BST 删除](#7-5)）
2. 一路向上找最小不平衡子树（可能并没有）
3. 调整平衡（LL / RR / LR / RL）
4. 如果不平衡向上传导，重复上述步骤

### 7.7 红黑树（RBT）O(log₂n) <a id="7-7"></a>

> 💡 C++ STL 中 [set](<../C++ 篇/C++ STL/C++ STL.md#1-6>) / [map](<../C++ 篇/C++ STL/C++ STL.md#1-7>) 的底层通常为红黑树。

特性：插入/删除操作很多时候不会破坏"红黑"特性，无需频繁调整树的形态。适合**以插入/删除为主**。

定义：

1. 节点值（左子树 < 根 < 右子树）
2. 每个节点是红色或黑色
3. 根节点是黑色
4. 叶节点（外部节点、NULL 节点、失败节点）都是黑色
5. 不存在两个相邻的红节点（红节点的父、子必为黑色）
6. 对于每个节点，从该节点到任一叶节点的简单路径上，所含黑节点的数目相同

节点的黑高：从某节点出发到叶节点路径上的黑节点总数（**不包含当前节点**）。黑高为 h 时，内部节点至少有 2^h - 1 个。

性质：

1. 从根节点到叶节点的最长路径不大于最短路径的 2 倍
2. 有 n 个内部节点的红黑树高度 h ≤ 2log₂(n + 1)

#### 7.7.1 插入

先查找，确定插入位置：

1. 新节点是根——染为黑色
2. 新节点非根——染为红色

若插入后不满足红黑树定义，则需调整：

- ① 黑叔：旋转 + 染色（LL 右旋、RR 左旋、LR 先左后右、RL 先右后左；"父换爷" + 染色）
- ② 红叔：染色 + 变新（叔、父、爷染色，爷变为新节点继续向上调整）

#### 7.7.2 删除

可能破坏"红黑"特性，需重新调整（较复杂，理解思路即可）。

### 7.8 B 树（多路平衡查找树） <a id="7-8"></a>

> 💡 B+ 树是 B 树的变体，MySQL InnoDB 的索引使用 B+Tree，见 [7.9](#7-9)。

性质（m 阶 B 树 / m 叉树）：

1. 树中每个节点至多有 m 棵子树，m - 1 个关键字
2. 若根节点不是终端节点，则至少有两棵子树
3. 除根节点以外的所有非叶节点至少有 ⌈m/2⌉ 棵子树，⌈m/2⌉ - 1 个关键字
4. 所有的叶节点都出现在同一层次上，且不带关键字（失败节点）

特性：

1. 根节点的子树数 ∈ [2, m]，关键字数 ∈ [1, m - 1]；其他节点的子树数 ∈ [⌈m/2⌉, m]，关键字数 ∈ [⌈m/2⌉ - 1, m - 1]
2. 对任一节点，所有子树高度都相同（绝对平衡）
3. 含 n 个关键字的 m 阶 B 树：log(m, n + 1) ≤ h ≤ log(⌈m/2⌉, (n + 1) / 2) + 1（推导见下）

**高度范围推导**：

1. 高度最小：每层节点都装满 m 棵子树，关键字数 n ≤ m^h - 1，故 h ≥ log(m, n + 1)
2. 高度最大：每层节点都只有 ⌈m/2⌉ 棵子树。高为 h 的 B 树（失败节点在第 h + 1 层）的最少节点数逐层为：
   - 第 1 层：1 个
   - 第 2 层：2 个
   - 第 3 层：2⌈m/2⌉ 个
   - 第 4 层：2(⌈m/2⌉)² 个
   - ……
   - 第 h + 1 层（失败节点）：2(⌈m/2⌉)^(h-1) 个
3. 含 n 个关键字的 B 树恰有 n + 1 个失败节点，故 n + 1 ≥ 2(⌈m/2⌉)^(h-1)，即 h ≤ log(⌈m/2⌉, (n + 1) / 2) + 1

#### 7.8.1 查找与插入

1. 节点内关键字有序（可顺序或折半查找）
2. 子树0 < 关键字1 < 子树1 < 关键字2 < ...（多路查找）
3. 新元素一定是插入到最底层"终端节点"，用"查找"来确定插入位置
4. 插入后若该节点关键字数 ≤ m - 1，插入结束
5. 若关键字数达到 m（溢出），则**分裂**：从中间位置 ⌈m/2⌉ 处一分为二，中间关键字上移到父节点，左右两部分成为两个新节点
6. 分裂可能向上传播：父节点也溢出则继续分裂；**根节点分裂时树高 + 1**

示例（3 阶 B 树，每个节点最多 2 个关键字）：依次插入 60、90、30——前两个同处一个节点 (60, 90)；插入 30 后溢出为 (30, 60, 90)，分裂成左右两个节点 30 和 90，中间关键字 60 上移成为根。

#### 7.8.2 删除

非终端节点关键字：

1. 用其直接前驱或直接后继代替其位置，转化为对"终端节点"的删除
2. 直接前驱：当前关键字左边指针所指子树中"最右下"的元素
3. 直接后继：当前关键字右边指针所指子树中"最左下"的元素

终端节点关键字：

- 删除后节点关键字个数未低于下限 ⌈m/2⌉ - 1，无需处理
- 低于下限：
  1. 右兄弟够借，则当前节点的后继、后继的后继依次顶替空缺（父节点关键字下移，右兄弟最小关键字上移）
  2. 左兄弟够借，则当前节点的前驱、前驱的前驱依次顶替空缺
  3. 都不够借，则需与父节点内的关键字、左（右）兄弟进行合并

### 7.9 B+ 树 <a id="7-9"></a>

性质（m 阶 B+ 树）：

1. 每个分支节点最多有 m 棵子树
2. 非叶根节点至少有两棵子树，其他每个分支节点至少有 ⌈m/2⌉ 棵子树
3. 节点的子树个数与关键字个数相等
4. 所有叶节点包含全部关键字及指向相应记录的指针，叶节点中将关键字按大小排列，并且相邻叶节点按大小顺序相互连接
5. 所有分支节点中仅包含它的各个子节点中关键字的最大值及指向其子节点的指针（分支节点只起索引作用）

**与 B 树的区别**：

1. 数据（记录）只存放在**叶节点**，分支节点只存索引——同样大小的节点能存更多索引，树更矮
2. 叶节点之间用指针**链成有序链表**，支持顺序访问和范围查找
3. 查找**必须进行到叶节点**（分支节点的关键字只是索引，不代表记录存在），所有叶节点的查找路径长度相同

> 💡 MySQL InnoDB 默认使用 B+Tree 作为索引结构，见 [MySQL 2.2.2](<../MySQL/MySQL.md#222-索引结构>)。

### 7.10 散列表（哈希表） <a id="7-10"></a>

散列表：一种数据结构，可以根据数据元素的关键字计算出它在散列表中的存储地址。散列函数（哈希函数）H(key) 建立了"关键字 → 存储地址"的映射关系。

> 💡 C++ STL 对应实现：[unordered_set / unordered_map](<../C++ 篇/C++ STL/C++ STL.md#1-8>)；MySQL 的 Hash 索引见 [2.2.3](<../MySQL/MySQL.md#223-hash-索引>)。

#### 7.10.1 散列函数的构造要求

1. 定义域必须涵盖所有可能出现的关键字；
2. 值域不能超出散列表的地址范围；
3. 尽可能减少冲突；
4. 尽量简单，能够快速算出任意一个关键字对应的散列地址。

#### 7.10.2 构造方法

1. 除留余数法（最常用）：H(key) = key % p。散列表长 m，取一个最接近且不大于 m 的质数 p
2. 直接定址法：H(key) = key 或 H(key) = a * key + b。其中 a 和 b 是常数，适用于关键字基本连续
3. 数字分析法：选取数码分布较为均匀的若干位作为散列地址。适用于关键字集合已知，且关键字的某几个数码位分布均匀
4. 平方取中法：取关键字的平方值的中间几位作为散列地址。适用于关键字的每位取值都不够均匀

#### 7.10.3 冲突

1. 定义：在散列表中插入一个数据元素时，需要根据关键字的值确定其存储地址，若该地址已经存储了其他元素，则称为"冲突"
2. 同义词：不同的关键字通过散列函数映射到同一个存储地址，则称它们为"同义词"。同义词之间就会发生冲突

处理冲突的方法：

**拉链法**：把冲突的元素连成链表（默认头插法），可以对（散列表 + 链表）进行增、删、改、查等操作。

**开放定址法**（如果发生冲突，就给新元素找另一个空闲的位置）：发生第 i 次冲突时的散列地址 H[i] = (H(key) + d[i]) % m，0 ≤ i ≤ m - 1 且 d[0] = 0，m 为散列表表长。也可进行增、删、改、查等操作。分为以下四种：

1. 线性探测法：d[i] = 0, 1, 2, ..., m - 1
2. 平方探测法：d[i] = 0², 1², (-1)², 2², (-2)², ..., k², (-k)²
3. 双散列法：d[i] = i * hash₂(key)，hash₂(key) 是另一个散列函数
4. 伪随机序列法：d[i] 是一个伪随机序列，如 d[i] = 0, 5, 3, 11...

> 提示：开放定址法的删除操作要**逻辑删除**（打删除标记），不能物理删除，不然会影响后续查找。如果有很多逻辑删除的元素，**查找效率**会降低。

#### 7.10.4 散列查找的性能分析

ASL 计算：

1. ASL(成功) = ΣC[i] / n（i = 1..n）。n 为散列表已存元素个数，C[i] 为成功查找第 i 个元素所需要的比较次数
2. ASL(失败) = ΣC[i] / r（i = 1..r）。r 为散列函数取值个数（r 就是哈希函数里的 m），C[i] 为查找失败第 i 个位置所需要的比较次数

装填因子：α = 表中记录数 n / 散列表长度 m，表示散列表满的程度。

1. 装填因子越大，越容易发生冲突，从而导致**插入、查找效率降低，ASL 增大**

聚集（堆积）现象：在处理冲突的过程中，几个初始散列地址不同的元素争夺同一个后继散列地址的现象。

1. 聚集越明显，**插入、查找效率越低，ASL 越大**，在**线性探测法**中尤为明显
2. 可以用**平方探测法（或其他方法）**减少聚集现象

## 8. 内部排序 <a id="ch8"></a>

数据都在内存中，考察时间、空间复杂度（外部排序见[第 9 章](#ch9)）。

> 💡 C++ STL 的排序与二分函数见 [algorithm](<../C++ 篇/C++ STL/C++ STL.md#algorithm>)。

### 8.1 插入排序 ⭐⭐⭐⭐ <a id="8-1"></a>

```c
void insertSort(int a[], int n){
    for(int i = 1; i < n; i++)
        for(int j = i; j > 0 && a[j] < a[j - 1]; j--)
            swap(&a[j], &a[j - 1]);
}
```

时间复杂度最好 O(n)（基本有序时）、最坏 O(n²)。可用二分优化：内层查找插入位置改为[折半查找](#7-3)（折半插入排序），比较次数降为 O(nlog₂n)，但移动元素次数不变，总复杂度仍为 O(n²)。

### 8.2 希尔排序（增量排序）⭐⭐⭐ <a id="8-2"></a>

先追求表中元素部分有序，再逐渐逼近全局有序。

```c
void shellSort(int a[], int n){
    for(int d = n / 2; d > 0; d /= 2){        // d 为增量，逐次减半
        for(int i = d; i < n; i++){
            for(int j = i; j >= d; j -= d){
                if(a[j - d] > a[j]){
                    swap(&a[j - d], &a[j]);
                }else{
                    break;
                }
            }
        }
    }
}
```

时间复杂度最坏 O(n²)（取决于增量序列，目前无统一最优结论）。只适用于顺序表，不适于链表。不稳定。

### 8.3 冒泡排序 ⭐⭐⭐⭐ <a id="8-3"></a>

```c
void bubbleSort(int a[], int n){
    for(int i = 0; i < n - 1; i++){
        bool flag = false;                    // 本轮是否发生交换
        for(int j = 0; j < n - i - 1; j++)
            if(a[j] > a[j + 1]){
                swap(&a[j], &a[j + 1]);
                flag = true;
            }
        if(!flag) break;                      // 未发生交换则已有序
    }
}
```

时间复杂度最坏 O(n²)，最好 O(n)（加 flag 优化后）；空间复杂度 O(1)。适用于链表、顺序表。稳定。

### 8.4 快速排序 ⭐⭐⭐⭐⭐ <a id="8-4"></a>

```c
void quickSort(int a[], int left, int right){
    if(left >= right) return;

    int i = left, j = right;
    int pivot = a[left];                      // 基准元素取第一个

    while(i < j){
        while(i < j && a[j] >= pivot) j--;    // 从右往左找比基准小的
        while(i < j && a[i] <= pivot) i++;    // 从左往右找比基准大的
        if(i < j) swap(&a[i], &a[j]);         // 交换不满足前两个 while 循环的元素
    }

    swap(&a[left], &a[i]);                    // 基准元素归位

    quickSort(a, left, i - 1);
    quickSort(a, i + 1, right);
}
```

时间复杂度最坏 O(n²)（基本有序时取第一个元素为基准会退化）、最好 O(nlog₂n)；空间复杂度最坏 O(n)、最好 O(log₂n)（递归栈深度）。不稳定。优化：随机选基准或取中值。

### 8.5 选择排序 ⭐⭐⭐ <a id="8-5"></a>

```c
void selectionSort(int a[], int n){
    for(int i = 0; i < n - 1; i++){
        int min_index = i;
        for(int j = i + 1; j < n; j++){
            if(a[j] < a[min_index]){
                min_index = j;
            }
        }
        swap(&a[i], &a[min_index]);
    }
}
```

时间复杂度 O(n²)（与初始序列无关）；空间复杂度 O(1)。适用于链表、顺序表。不稳定。

### 8.6 堆排序 ⭐⭐⭐⭐⭐ <a id="8-6"></a>

堆（Heap）：一种数据结构，可以理解为[完全二叉树](#5-2)。数组从下标 1 开始存放。

> 💡 C++ STL 对应实现：[priority_queue](<../C++ 篇/C++ STL/C++ STL.md#1-9>)。

1. 若满足：L[i] ≥ L[2i] 且 L[i] ≥ L[2i + 1]（1 ≤ i ≤ n / 2）——大根堆（大顶堆），用于递增排序。完全二叉树理解：根 ≥ 左、右孩子
2. 若满足：L[i] ≤ L[2i] 且 L[i] ≤ L[2i + 1]（1 ≤ i ≤ n / 2）——小根堆（小顶堆），用于递减排序。完全二叉树理解：根 ≤ 左、右孩子

堆排序思路：每一趟把**堆顶元素**和**待排序的堆底元素**进行互换，再调整剩余部分，直到全部有序。

```c
// 建立大根堆（a[0] 作为暂存单元，数据从 a[1] 开始）
void buildMaxHeap(int a[], int len){
    for(int i = len / 2; i > 0; i--)    // 从最后一个非终端节点开始向上调整
        headAdjust(a, i, len);
}

// 将以 k 为根的子树调整为大根堆
void headAdjust(int a[], int k, int len){
    a[0] = a[k];
    for(int i = 2 * k; i <= len; i *= 2){
        if(i < len && a[i] < a[i + 1])
            i++;                        // i 指向更大的孩子
        if(a[0] >= a[i]){
            break;
        }else{
            a[k] = a[i];                // 孩子上移
            k = i;
        }
    }
    a[k] = a[0];
}

// 堆排序
void heapSort(int a[], int len){
    buildMaxHeap(a, len);
    for(int i = len; i > 1; i--){
        swap(&a[i], &a[1]);             // 堆顶元素换到堆底
        headAdjust(a, 1, i - 1);
    }
}
```

建堆时间复杂度 O(n)，排序时间复杂度 O(nlog₂n)，空间复杂度 O(1)。不稳定。

堆的插入、删除（最终构建好大/小根堆）：

1. 插入：
   - ① 对于小根堆，新元素放到表尾，与父节点对比，比父节点小则交换位置，直到不能上升为止
   - ② 对于大根堆，新元素放到表尾，与父节点对比，比父节点大则交换位置，直到不能上升为止
2. 删除：
   - ① 对于小根堆，表尾元素放到删除元素位置，对比子节点，与最小的互换，直到不能下坠为止
   - ② 对于大根堆，表尾元素放到删除元素位置，对比子节点，与最大的互换，直到不能下坠为止

### 8.7 归并排序 ⭐⭐⭐⭐⭐ <a id="8-7"></a>

定义：把多个有序数组合并成一个有序数组。一般用二路归并。

```c
int *b = (int*)malloc(n * sizeof(int));  // 辅助数组

void Merge(int a[], int low, int mid, int high){
    int i, j, k;
    for(k = low; k <= high; k++)
        b[k] = a[k];  // a 数组复制到 b 数组
    // 归并 ↓
    for(i = low, j = mid + 1, k = i; i <= mid && j <= high; k++){
        if(b[i] <= b[j])
            a[k] = b[i++];
        else
            a[k] = b[j++];
    }
    while(i <= mid) a[k++] = b[i++];
    while(j <= high) a[k++] = b[j++];
}

void MergeSort(int a[], int low, int high){
    if(low < high){
        int mid = (low + high) / 2;  // 从中间划分
        MergeSort(a, low, mid);      // 对左半部分归并排序
        MergeSort(a, mid + 1, high); // 对右半部分归并排序
        Merge(a, low, mid, high);    // 归并
    }
}
```

每次归并时间复杂度 O(n)，算法时间复杂度 O(nlog₂n)（与初始序列无关）；空间复杂度 O(n)，来源于辅助数组 b。稳定。

### 8.8 基数排序 ⭐⭐⭐ <a id="8-8"></a>

1. **步骤：**
   1. 设置 r 个空队列，r 为基数
   2. 按照各个关键字位权重递增的次序（个、十、百...），对 d 个关键字位分别做"分配"和"收集"
      1. 分配：顺序扫描各个元素，若当前处理的关键字位为 x，则插入 Q[x] 队尾
      2. 收集：把所有队列中的节点依次出队并连接

空间复杂度 O(r)，时间复杂度 O(d(n + r))。稳定。不基于比较。

2. **适用情况：**
   1. 数据元素的关键字可以方便地拆分为 d 组，且 d 较小
   2. 每组关键字的取值范围不大，即 r 较小
   3. 数据元素个数 n 较大

### 8.9 计数排序 ⭐⭐ <a id="8-9"></a>

统计每个关键字出现的次数，再按关键字顺序依次填回数组。适用于关键字取值范围不大（如成绩 0~100）的整数排序。

```c
void countSort(int a[], int n){
    int count[RANGE + 1] = {0};    // RANGE 为关键字最大值
    for(int i = 0; i < n; i++)
        count[a[i]]++;             // 统计每个关键字出现次数
    int k = 0;
    for(int i = 0; i <= RANGE; i++)
        while(count[i]--)          // 按序填回
            a[k++] = i;
}
```

时间复杂度 O(n + RANGE)，空间复杂度 O(RANGE)。稳定。

### 8.10 内部排序总结 <a id="8-10"></a>

| 排序算法 | 最好时间 | 最坏时间 | 空间复杂度 | 稳定性 | 适用场景 |
|---|---|---|---|---|---|
| 插入排序 | O(n) | O(n²) | O(1) | 稳定 | 基本有序、n 较小 |
| 希尔排序 | — | O(n²) | O(1) | 不稳定 | 仅顺序表 |
| 冒泡排序 | O(n) | O(n²) | O(1) | 稳定 | 链表、顺序表 |
| 快速排序 | O(nlog₂n) | O(n²) | O(log₂n)~O(n) | 不稳定 | 平均性能最好 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 | n 较小 |
| 堆排序 | O(nlog₂n) | O(nlog₂n) | O(1) | 不稳定 | 内存紧张、选最大/最小 |
| 归并排序 | O(nlog₂n) | O(nlog₂n) | O(n) | 稳定 | 要求稳定且 n 较大 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 | 关键字可拆分 |

## 9. 外部排序 <a id="ch9"></a>

数据太多，无法全部放入内存（考察读、写磁盘次数）。

### 9.1 外部排序步骤 <a id="9-1"></a>

1. 生成初始归并段（见[置换-选择排序](#9-4)）
2. 第一趟归并
3. 第二趟归并
4. 第三趟归并
5. ...直到归并为一段

**外部排序时间开销 = 读写外存时间 + 内部排序时间 + 内部归并时间**

**示例：10000 个记录，内存一次最多对 1000 个记录做内部排序**

1. 生成 10 个初始归并段（10000 / 1000）
2. 2 路归并：10 → 5 → 3 → 2 → 1，共 4 趟
3. 设数据块大小为 200 个记录，则处理一遍文件需访问外存 100 次（读 50 + 写 50）
4. 总外存访问次数 = 100（生成初始归并段）+ 4 × 100（4 趟归并）= **500 次**

### 9.2 优化：多路归并 <a id="9-2"></a>

多路归并（不是二路），归并树就是 k（k 路归并）叉树。

归并趟数 s = ⌈log(k, m)⌉（m 为初始归并段数）。k 越大趟数越少：上面的例子改用 5 路归并只需 2 趟，总外存访问次数 = 100 + 2 × 100 = **300 次**。

**多路归并负面影响：**

1. k 路归并需要开辟 k 个输入缓冲区，内存开销增加
2. 每挑选一个关键字需要对比关键字 (k - 1) 次，内部归并所需时间增加——可用[败者树](#9-3)优化

### 9.3 败者树 <a id="9-3"></a>

败者树——可视为一棵完全二叉树。k 个叶节点分别是当前参加比赛的元素，非叶节点用来记忆左右子树中的"失败者"，而让胜者往上继续比较，直到根节点。每选出一个最小关键字只需 ⌈log₂k⌉ 次比较。

### 9.4 置换-选择排序 <a id="9-4"></a>

用于生成**更长的初始归并段**（突破内存工作区大小的限制）。设输入文件 FI、输出文件 FO、内存工作区 WA 可容纳 w 个记录：

1. 从 FI 读入 w 个记录到 WA
2. 从 WA 中选出关键字最小的记录（MINIMAX），输出到 FO
3. 若 FI 不空，从 FI 读入下一个记录补入 WA
4. 从 WA 中选关键字大于刚输出的 MINIMAX 的最小者，作为新的 MINIMAX
5. 重复 3~4，直到 WA 中选不出比 MINIMAX 更大的记录——当前初始归并段结束，输出段结束标志
6. 重复 2~5，直到 WA 为空，得到全部初始归并段

结论：各初始归并段的**长度不等**。可用[败者树](#9-3)实现（段号小者优先胜出）。

### 9.5 最佳归并树 <a id="9-5"></a>

各初始归并段长度不同时，按[哈夫曼树](#5-8)的思想组织归并顺序（权值 = 段长度），使总读磁盘次数最少。WPL = 总读磁盘次数，总读写次数 = 2 × WPL。

**示例：段长 9, 30, 12, 18, 3, 17, 2, 6, 24，3 路归并**

1. 简单两趟归并：总读写次数 = (9+30+12+18+3+17+2+6+24) × 2 × 2 = **484 次**
2. 最佳归并树（哈夫曼树）：[(3+2+6)×3 + (9+12+17+18+24)×2 + 30×1] × 2 = **446 次**

**虚段**：初始归并段数 m 不满足 (m - 1) % (k - 1) == 0 时，需补充长度为 0 的"虚段"补足（如 8 段做 3 路归并需补 1 个虚段）。
