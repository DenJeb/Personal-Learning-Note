## 6.1 图的定义与术语 <a id="6-1"></a>

定义：图 G 由顶点集 V 和边（弧）集 E 构成，记作 G = (V, E)。

1. **有向图 / 无向图**：有向边（弧）带方向，记为 <v, w>（v 为弧尾，w 为弧头）；无向边记为 (v, w)
2. **度 / 入度 / 出度**：无向图中顶点度 = 依附该顶点的边数；有向图中入度 = 指向该顶点的弧数，出度 = 从该顶点出发的弧数，度 = 入度 + 出度
3. **路径 / 回路**：顶点序列 v₁, v₂, ..., vₖ 中相邻顶点间有边（弧）则构成路径；起点 = 终点的路径称为回路。简单路径：顶点不重复出现的路径；简单回路：除起点终点外顶点不重复的回路
4. **连通 / 连通分量**：无向图中两顶点间有路径则连通；极大连通子图称为连通分量
5. **强连通 / 强连通分量**：有向图中两顶点互相可达则强连通；极大强连通子图称为强连通分量
6. **完全图**：n 个顶点的无向完全图有 n(n - 1) / 2 条边；有向完全图有 n(n - 1) 条弧
7. **生成树 / 生成森林**：连通图包含全部顶点的极小连通子图（恰 n - 1 条边）为生成树；非连通图各连通分量的生成树构成生成森林
8. **权与网**：边（弧）上带的数值称为权；带权的图称为网
9. **稠密图 / 稀疏图**：|E| 接近 |V|² 的图为稠密图；|E| 远小于 |V|² 的图为稀疏图

边与度的关系（握手定理）：无向图所有顶点的度之和 = 2|E|；有向图 Σ入度 = Σ出度 = |E|

## 6.2 图的存储 <a id="6-2"></a>

### 6.2.1 邻接矩阵法

n 个顶点用 n×n 矩阵表示，边存在则为权值（无权图记 1），否则为 0 或 ∞。

```c
#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];                       // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum];         // 邻接矩阵
    int vexnum, arcnum;                           // 顶点数、边数
} MGraph;
```

特点：适合**稠密图**；判断两顶点是否相邻 O(1)；求某顶点的所有邻边需遍历一行 O(n)。无向图的矩阵对称，可压缩存储。

### 6.2.2 邻接表法

每个顶点一个单链表，存其所有邻接边。

```c
typedef struct ArcNode {
    int adjvex;               // 该边指向的顶点
    struct ArcNode *next;     // 下一条边
    int weight;               // 权值（可选）
} ArcNode;

typedef struct VNode {
    char data;
    ArcNode *first;           // 第一条边
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```

特点：适合**稀疏图**；空间复杂度无向图 O(|V| + 2|E|)、有向图 O(|V| + |E|)；求顶点的出边方便，求入边需遍历全表（可另建逆邻接表）。

### 6.2.3 十字链表法（有向图）

```c
typedef struct ArcBox {           // 弧节点
    int tailvex, headvex;         // 弧尾、弧头顶点编号
    struct ArcBox *hlink, *tlink; // 同弧头链、同弧尾链
    int weight;
} ArcBox;
typedef struct VexNode {          // 顶点节点
    char data;
    ArcBox *firstin, *firstout;   // 第一条入弧、第一条出弧
} VexNode;
```

每个弧节点同时挂在"同弧头链"（hlink）和"同弧尾链"（tlink）上。既能方便找出边，也能方便找入边。

### 6.2.4 邻接多重表法（无向图）

```c
typedef struct EBox {             // 边节点
    int ivex, jvex;               // 边的两个端点
    struct EBox *ilink, *jlink;   // 分别指向依附于 ivex / jvex 的下一条边
    int weight;
} EBox;
```

每条边只存一个节点，被两个端点的边链共享。方便删除边、标记已访问的边。

![邻接多重表：一条无向边只存一个节点](<图片和附件/邻接多重表.png>)

## 6.3 图的广度优先遍历（BFS） <a id="6-3"></a>

类似树的层次遍历：借助队列 + visited 数组。

```c
bool visited[MaxVertexNum];

void BFS(ALGraph G, int v){
    Queue Q;
    visit(v); visited[v] = true;
    EnQueue(Q, v);
    while(!isEmpty(Q)){
        int u = DeQueue(Q);
        for(ArcNode *p = G.vertices[u].first; p != NULL; p = p->next){
            int w = p->adjvex;
            if(!visited[w]){
                visit(w); visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}

void BFSTraverse(ALGraph G){          // 非连通图需遍历所有顶点
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;
    for(int i = 0; i < G.vexnum; i++)
        if(!visited[i]) BFS(G, i);
}
```

复杂度：邻接表 O(|V| + |E|)，邻接矩阵 O(|V|²)。

应用：求[无权图的单源最短路径](#6-6-1)。

## 6.4 图的深度优先遍历（DFS） <a id="6-4"></a>

类似树的先序遍历：递归（本质是栈）+ visited 数组。

```c
void DFS(ALGraph G, int v){
    visit(v); visited[v] = true;
    for(ArcNode *p = G.vertices[v].first; p != NULL; p = p->next){
        int w = p->adjvex;
        if(!visited[w]) DFS(G, w);
    }
}

void DFSTraverse(ALGraph G){          // 非连通图需遍历所有顶点
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;
    for(int i = 0; i < G.vexnum; i++)
        if(!visited[i]) DFS(G, i);
}
```

复杂度同 BFS。

## 6.5 最小生成树 <a id="6-5"></a>

定义：连通无向图的[生成树](#6-1)中，权值之和最小的那棵。

1. **Prim 算法**：从某个顶点开始构建生成树，每次将代价最小的新顶点纳入新生成树，直到所有顶点都纳入。时间复杂度 O(|V|²)，与边数无关，适用于**稠密图**。

2. **Kruskal 算法**：每次选择一条权值最小的边，使这条边的两头连通（用[并查集](<5. 树.md#5-9>)判断是否成环），直到所有节点都连通。时间复杂度 O(|E|log₂|E|)（排序），适用于**稀疏图**。

```c
// Kruskal 伪代码：边按权值从小到大排序，用并查集判断是否成环
for(每条边按权值从小到大){
    if(Find(边.起点) != Find(边.终点)){
        Union(边.起点, 边.终点);
        将该边纳入生成树;
    }
}
```

## 6.6 最短路径问题 <a id="6-6"></a>

### 6.6.1 单源最短路径 <a id="6-6-1"></a>

1. **[BFS 算法](#6-3)**（无权图）：从源点 BFS，第一次访问到某顶点时的路径即最短路径。O(|V| + |E|)

2. **Dijkstra 算法**（带权图，**权值非负**）：贪心，每次选未确定顶点中 dist 最小的，用其更新邻接点的 dist。O(|V|²)（邻接矩阵）。不适用于负权值

> 💡 C++ 可用 [priority_queue](<../C++ 篇/C++ STL/1.9 priority_queue（优先队列）.md#1-9>) 维护待确定顶点。

```c
// Dijkstra 伪代码
初始化：dist[源点] = 0，其余为 ∞；所有顶点未确定;
循环 n 次：
    取未确定顶点中 dist 最小的 v，标记为已确定;
    对 v 的所有邻接点 w：
        dist[w] = min(dist[w], dist[v] + 边(v, w)权值);
```

### 6.6.2 各顶点间最短路径

**Floyd 算法**（无权、带权图，允许负权值，不允许负环）：动态规划，三重循环 O(|V|³)。

```c
// 初始化 d[i][j]：i == j 为 0，有边为边权，无边为 ∞
for(int k = 0; k < n; k++)            // 允许经过的中间顶点集合逐步扩大
    for(int i = 0; i < n; i++)
        for(int j = 0; j < n; j++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

## 6.7 有向无环图（DAG） <a id="6-7"></a>

### 6.7.1 拓扑排序 <a id="6-7-1"></a>

定义：把 DAG 的顶点排成线性序列，使得每条有向边的起点都排在终点之前。时间复杂度 O(|V| + |E|)。

```c
// 思路：每次输出入度为 0 的顶点，并删除其所有出边
初始化入度表 indegree[];
将所有入度为 0 的顶点入栈（或队列）;
while(栈不空){
    弹出 v，输出 v;
    对 v 的每个邻接点 w：
        indegree[w]--;
        if(indegree[w] == 0) 入栈;
}
若输出顶点数 < n，说明图中存在环（拓扑排序失败）;
```

应用：检测有向图中是否有环；安排 [AOV 网](#6-7-2)中活动的先后顺序。

### 6.7.2 AOV 网 <a id="6-7-2"></a>

用 DAG 图（有向无环图）表示一个工程。顶点表示活动，有向边 <Vi, Vj> 表示活动 Vi 必须先于活动 Vj 进行。

### 6.7.3 AOE 网

在带权有向图中，以顶点表示事件，以有向边表示活动，以边上的权值表示完成该活动的开销（如完成活动所需的时间）。AOE 网中只有一个入度为 0 的点，为开始顶点（源点）；只有一个出度为 0 的点，为结束顶点（汇点）。

### 6.7.4 关键路径

定义：从源点到汇点的**最长路径**，其长度决定整个工程的最短完成时间。关键路径上的活动称为**关键活动**，任何关键活动的延迟都会导致整个工程延迟。

求解步骤：

1. [拓扑排序](#6-7-1)，求各事件的最早发生时间 ve(k)：ve(源点) = 0；ve(k) = max{ve(j) + 边(j, k)权值}
2. 逆拓扑排序，求各事件的最迟发生时间 vl(k)：vl(汇点) = ve(汇点)；vl(j) = min{vl(k) - 边(j, k)权值}
3. 活动 a = <j, k> 的最早开始时间 e = ve(j)；最迟开始时间 l = vl(k) - 边权值
4. **e = l 的活动为关键活动**；所有关键活动组成的路径即关键路径
