# 4. 串 <a id="ch4"></a>

[← 返回目录](<数据结构（C语言）.md>)

定义：串（字符串）是由零个或多个字符组成的有限序列。

**基本操作（常见计算题）**：

| 操作 | 示例 | 结果 |
|---|---|---|
| StrLength | StrLength('abc') | 3 |
| SubString | SubString('command', 4, 3) | 'man' |
| Index | S = 'abcaabcaaabc'，T = 'bca' | Index(S, T, 1) = 2；Index(S, T, 3) = 6；Index(S, T, 8) = 0 |
| Replace | S = 'abcaabcaabca'，T = 'bca'，V = 'x' | S = 'axaxax' |
| StrInsert | S = 'sdent'，T = 'tu' | StrInsert(S, 2, T) → S = 'student' |

## 4.1 串的存储结构 <a id="4-1"></a>

### 4.1.1 定长顺序存储

```c
#define MAXSTRLEN 255
typedef unsigned char SString[MAXSTRLEN + 1];  // 0 号单元存放串长
```

1. 用定长数组存储，0 号单元存放串长
2. 超过 MAXSTRLEN 的串值会被**截断**
3. Concat(&T, S1, S2) 的三种情况：
   - S1[0] + S2[0] ≤ MAXSTRLEN：完整联接，不截断
   - S1[0] < MAXSTRLEN 且 S1[0] + S2[0] > MAXSTRLEN：S2 部分截断
   - S1[0] = MAXSTRLEN：T 只等于 S1（S2 全部丢失）

### 4.1.2 堆分配存储

```c
typedef struct {
    char *ch;    // 按串长动态分配；空串为 NULL
    int length;
} HString;
```

用 malloc/free 按需分配空间，不会被截断。操作思路：先分配再复制（如 StrInsert 需先为 S 重新分配 S、T 长度之和的空间，再复制）。

### 4.1.3 块链存储

把串分成若干块，每块存若干字符，用链表连接。块越大，存储密度越高（存储密度 = 串值所占存储位 / 实际分配存储位）。

## 4.2 朴素模式匹配 <a id="4-2"></a>

```c
// 返回子串 t 在主串 s 中第一次出现的位置，未找到返回 -1
int Index(char s[], char t[]){
    int n = strlen(s), m = strlen(t);
    for(int i = 0; i <= n - m; i++){
        int j;
        for(j = 0; j < m; j++)
            if(s[i + j] != t[j]) break;
        if(j == m) return i;
    }
    return -1;
}
```

最坏时间复杂度 O(nm)（如 s = "aaa...aab"、t = "aaab" 时）。

## 4.3 KMP 算法 & next 数组 <a id="4-3"></a>

核心思想：主串指针 i **不回溯**，利用已匹配的信息移动模式串。时间复杂度 O(n + m)。

### 4.3.1 求 next 数组

```c
// next[j]：模式串第 j 个字符失配时，应回退到的位置（0 基下标版本）
void getNext(char t[], int next[]){
    int m = strlen(t);
    int i = 0, j = -1;
    next[0] = -1;                        // 首字符失配，主串 i 前进一位
    while(i < m - 1){
        if(j == -1 || t[i] == t[j])
            next[++i] = ++j;
        else
            j = next[j];
    }
}
```

手动求法（1 基下标）：

1. next[1] = 0，next[2] = 1
2. 第 j 个字符前的 j-1 个字符中，最长的**相等前后缀**长度为 k，则 next[j] = k + 1

手算示例（T = 'abaabcac'）：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | a | b | c | a | c |
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

如 j = 6：前 5 个字符 'abaab' 的最长相等前后缀为 'ab'（长度为 2），故 next[6] = 2 + 1 = 3。

### 4.3.2 KMP 匹配

```c
int KMP(char s[], char t[]){
    int next[100];                   // next 数组长度 ≥ 模式串长度
    getNext(t, next);
    int i = 0, j = 0;
    while(i < strlen(s) && j < strlen(t)){
        if(j == -1 || s[i] == t[j]){ i++; j++; }
        else j = next[j];                // 主串不动，模式串回退
    }
    if(j == strlen(t)) return i - j;
    return -1;
}
```

改进：**nextval 数组**。当 t[j] == t[next[j]] 时，直接继承 nextval[next[j]]，避免重复比较（如 "aaaab" 这类模式串）。上例 T = 'abaabcac' 的 nextval 为：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |
| nextval[j] | 0 | 1 | 0 | 2 | 1 | 3 | 0 | 2 |

如 j = 3：T[3] = T[next[3]] = T[1] = 'a'，失配回溯后必然再次失配，故 nextval[3] = nextval[1] = 0。
