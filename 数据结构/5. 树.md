# 5. 树 <a id="ch5"></a>

[← 返回目录](<数据结构（C语言）.md>)

## 5.1 树的基本性质 <a id="5-1"></a>

1. 节点数 = 总度数 + 1（除根外每个节点恰有一个前驱）
2. 度为 m 的树，第 i 层至多有 m^(i-1) 个节点
3. 高度为 h 的 m 叉树至多有 (m^h - 1)/(m - 1) 个节点

## 5.2 二叉树 <a id="5-2"></a>

定义：每个节点至多有两棵子树，且**左右次序不可颠倒**。

与度为 2 的树的区别：二叉树可以为空；度为 2 的树至少有 3 个节点。若某节点只有一个孩子，二叉树必须区分是左孩子还是右孩子，而度为 2 的树不区分。

性质：

1. 第 i 层至多有 2^(i-1) 个节点
2. 高度为 h 的二叉树至多有 2^h - 1 个节点
3. 叶子节点数 n₀ = 度为 2 的节点数 n₂ + 1
4. 具有 n 个节点的**完全二叉树**：高度 ⌈log₂(n+1)⌉；按层序从 1 编号，编号 i 的节点——左孩子 2i、右孩子 2i+1、父节点 ⌊i/2⌋；i > ⌊n/2⌋ 的节点为叶子
5. 满二叉树：每层都满（共 2^h - 1 个节点）；完全二叉树：只允许最后一层不满，且节点靠左排列

## 5.3 二叉树的存储 <a id="5-3"></a>

### 5.3.1 顺序存储

按层序编号存入数组（下标从 1 开始）。适合完全二叉树；一般二叉树会浪费大量空间。

### 5.3.2 链式存储

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

n 个节点的二叉链表共有 2n 个指针域，其中 n + 1 个为空（[线索二叉树](#5-7)的出发点）。

## 5.4 树的存储 <a id="5-4"></a>

1. **双亲表示法**：每个节点存数据 + 父节点下标（数组实现）。找双亲 O(1)，找孩子需遍历全表
2. **孩子表示法**：每个节点用单链表存其所有孩子。找孩子方便，找双亲麻烦
3. **孩子兄弟表示法**（树的二叉树表示法，与[树 → 二叉树转换](#5-6)的规则一致）：左孩子右兄弟

```c
typedef struct CSNode {
    int data;
    struct CSNode *firstchild, *nextsibling;  // 第一个孩子、右兄弟
} CSNode, *CSTree;
```

## 5.5 遍历方法 <a id="5-5"></a>

![二叉树的三种遍历顺序](<图片和附件/二叉树三种遍历.png>)

### 5.5.1 先序遍历（根左右）

```c
void PreOrder(BiTree T){
    if(T == NULL) return;
    visit(T);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}
```

### 5.5.2 中序遍历（左根右）

```c
void InOrder(BiTree T){
    if(T == NULL) return;
    InOrder(T->lchild);
    visit(T);
    InOrder(T->rchild);
}
```

### 5.5.3 后序遍历（左右根）

```c
void PostOrder(BiTree T){
    if(T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    visit(T);
}
```

### 5.5.4 层次遍历（借助队列） <a id="5-5-4"></a>

```c
void LevelOrder(BiTree T){
    Queue Q;
    EnQueue(Q, T);
    while(!isEmpty(Q)){
        BiTNode *p = DeQueue(Q);
        visit(p);
        if(p->lchild) EnQueue(Q, p->lchild);
        if(p->rchild) EnQueue(Q, p->rchild);
    }
}
```

> 提示：已知**先序 + 中序**或**后序 + 中序**可唯一确定一棵二叉树（先/后序定根，中序分左右子树）。仅知先序 + 后序不能唯一确定。

## 5.6 转换方法 <a id="5-6"></a>

1. 树 → 二叉树：每个节点左指针接第一个孩子，右指针接右兄弟（"左孩子右兄弟"）
2. 森林 → 二叉树：各树分别转换，再依次作为前一棵的右子树链接
3. 二叉树 → 森林：沿右链依次断开（根有右孩子则属于森林）
4. 二叉树 → 树：左孩子右兄弟的逆过程

## 5.7 线索二叉树 <a id="5-7"></a>

背景：n 个节点的二叉链表有 n + 1 个空指针域，浪费。线索化：用空指针存放遍历序列中的**前驱/后继**。

```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // tag = 0：孩子指针；tag = 1：线索
} ThreadNode, *ThreadTree;
```

中序线索化：

```c
void InThread(ThreadTree &T, ThreadTree &pre){
    if(T == NULL) return;
    InThread(T->lchild, pre);
    if(T->lchild == NULL){ T->lchild = pre; T->ltag = 1; }        // 左线索指向前驱
    if(pre != NULL && pre->rchild == NULL){ pre->rchild = T; pre->rtag = 1; }  // 前驱的右线索指向当前
    pre = T;
    InThread(T->rchild, pre);
}
```

![中序线索二叉树：把空指针变成线索](<图片和附件/中序线索二叉树.png>)

作用：不用栈/递归即可实现遍历；找中序前驱/后继方便（ltag = 1 时 lchild 即前驱，rtag = 1 时 rchild 即后继）。

## 5.8 哈夫曼树与哈夫曼编码 <a id="5-8"></a>

### 5.8.1 定义

1. 节点的带权路径长度：权值 × 节点到根的路径长度（边数）
2. 树的带权路径长度 WPL = Σ(叶节点权值 × 路径长度)
3. **哈夫曼树**：n 个带权叶子构成的二叉树中 WPL 最小的树，也称最优二叉树

### 5.8.2 构造

每次从集合中取权值最小的两棵树合并成一棵新树（新树权值 = 两者之和），重复 n - 1 次。可用[小根堆](<8. 内部排序.md#8-6>)（优先队列）实现。

```c
// 用最小堆（优先队列）实现：每次取两个最小节点合并后放回
HuffmanTree CreateHuffman(int w[], int n){
    // 1. n 个叶子节点（权值 w[i]）放入小根堆
    // 2. 循环 n-1 次：取出两个权值最小的节点，
    //    合并为新节点（权值 = 两者之和），新节点放回堆中
    // 3. 堆中最后一个节点即为哈夫曼树的根
}
```

![哈夫曼树构造](<图片和附件/哈夫曼树构造.png>)

性质：哈夫曼树只有度为 0 和度为 2 的节点，总节点数 = 2n - 1。

### 5.8.3 哈夫曼编码

左分支记 0、右分支记 1，从根到叶子的路径即该字符的编码。是**前缀编码**（任一编码都不是另一编码的前缀），解码无歧义；频率高的字符路径短，总编码长度最短。

## 5.9 并查集 <a id="5-9"></a>

支持两种操作的数据结构：**查**（判断两个元素是否属于同一集合）、**并**（合并两个集合）。用双亲表示法（数组）实现。

```c
int fa[N];

void Init(int n){                    // 初始化：每个元素各成一棵树
    for(int i = 0; i < n; i++) fa[i] = i;
}

int Find(int x){                     // 查：找根节点（含路径压缩）
    return fa[x] == x ? x : (fa[x] = Find(fa[x]));
}

void Union(int a, int b){            // 并：合并两棵树
    fa[Find(a)] = Find(b);
}
```

另一种实现：**负数双亲 + 按大小合并**（根的双亲值存负数，绝对值为集合元素数；合并时把元素少的根接到元素多的根下，降低树高）：

```c
// 初始化 S[i] = -1；S[root] < 0 表示 root 是根，|S[root]| 为集合元素数
void Union(int S[], int Root1, int Root2){
    if(S[Root1] > S[Root2]){   // Root1 元素少（负数更大）
        S[Root2] += S[Root1];  // 元素数累加
        S[Root1] = Root2;      // 元素少的根接到元素多的根下
    } else {
        S[Root1] += S[Root2];
        S[Root2] = Root1;
    }
}
```

应用：[Kruskal 算法](<6. 图.md#6-5>)判断边的两端是否已连通。
