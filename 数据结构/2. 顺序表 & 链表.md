# 2. 顺序表 & 链表 <a id="ch2"></a>

[← 返回目录](<数据结构（C语言）.md>)

## 2.1 顺序表 <a id="2-1"></a>

定义：用一组地址连续的存储单元依次存储线性表中的数据元素，支持**随机存取**。

> 💡 C++ STL 对应实现：[vector](<../C++ 篇/C++ STL/1.1 vector（动态数组）.md#1-1>)。

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];  // 存放数据元素
    int length;         // 当前表长
} SqList;
```

1. 插入：平均移动 n/2 个元素，O(n)
2. 删除：平均移动 (n-1)/2 个元素，O(n)
3. 按位查找：O(1)（随机存取）；按值查找：O(n)

## 2.2 单链表 <a id="2-2"></a>

定义：通过指针链接的链式存储，节点 = 数据域 + 指针域。只能**顺序存取**。

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

头插法建表（结果与输入顺序**相反**）：

```c
// 带头节点的头插法：每次插入到表头
void HeadInsert(LinkList &L, int x){
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = x;
    s->next = L->next;
    L->next = s;
}
```

尾插法建表（结果与输入顺序**相同**）：

```c
void TailInsert(LinkList &L, int x){  // 需维护尾指针 r
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = x;
    s->next = NULL;
    r->next = s;
    r = s;
}
```

![单链表建表：头插逆序，尾插保序](<图片和附件/单链表头插与尾插.png>)

删除第 i 个节点（先找到前驱 p，即第 i-1 个节点）：

```c
LNode *q = p->next;
p->next = q->next;
free(q);
```

按位查找、按值查找均为 O(n)。带头节点的好处：插入/删除操作统一，无需特殊处理首元素。

## 2.3 双链表 <a id="2-3"></a>

> 💡 C++ STL 对应实现：[list](<../C++ 篇/C++ STL/1.2 list（双向链表）.md#1-2>)；MySQL 的 B+Tree 索引叶子节点也用双向链表串联，见 [MySQL 2.2.2](<../MySQL/2.2 索引.md#222-索引结构>)。

```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

在 p 之后插入节点 s（假设 p 不是表尾节点）：

```c
s->next = p->next;
p->next->prior = s;
s->prior = p;
p->next = s;
```

删除 p 的后继节点 q（假设 q 不是表尾节点）：

```c
DNode *q = p->next;
p->next = q->next;
q->next->prior = p;
free(q);
```

## 2.4 循环链表 <a id="2-4"></a>

1. 循环单链表：表尾节点的 next 指向头节点。判空：L->next == L
2. 循环双链表：头节点的 prior 指向表尾。判空：L->next == L 且 L->prior == L

![循环链表](<图片和附件/循环链表.png>)

## 2.5 静态链表 <a id="2-5"></a>

用数组实现的链表，节点的指针域存放数组下标（游标），结束标志为 -1。适用于不支持指针的语言（如早期 Basic/Fortran）。

## 2.6 顺序表 vs 链表 <a id="2-6"></a>

| 对比项 | 顺序表 | 链表 |
|---|---|---|
| 存取方式 | 随机存取 O(1) | 顺序存取 O(n) |
| 插入/删除 | 需移动元素 O(n) | 只需修改指针 O(1)（已知位置时） |
| 空间 | 静态分配，可能浪费 | 按需分配，但有指针开销 |
| 适用场景 | 表长固定、查多改少 | 表长变化大、改多查少 |
