# 8. 内部排序 <a id="ch8"></a>

[← 返回目录](<数据结构（C语言）.md>)

数据都在内存中，考察时间、空间复杂度（外部排序见[第 9 章](<9. 外部排序.md#ch9>)）。

> 💡 C++ STL 的排序与二分函数见 [algorithm](<../C++ 篇/C++ STL/3. algorithm：对数据操作.md#algorithm>)。

## 8.1 插入排序 ⭐⭐⭐⭐ <a id="8-1"></a>

```c
void insertSort(int a[], int n){
    for(int i = 1; i < n; i++)
        for(int j = i; j > 0 && a[j] < a[j - 1]; j--)
            swap(&a[j], &a[j - 1]);
}
```

时间复杂度最好 O(n)（基本有序时）、最坏 O(n²)。可用二分优化：内层查找插入位置改为[折半查找](<7. 查找.md#7-3>)（折半插入排序），比较次数降为 O(nlog₂n)，但移动元素次数不变，总复杂度仍为 O(n²)。

## 8.2 希尔排序（增量排序）⭐⭐⭐ <a id="8-2"></a>

先追求表中元素部分有序，再逐渐逼近全局有序。

```c
void shellSort(int a[], int n){
    for(int d = n / 2; d > 0; d /= 2){        // d 为增量，逐次减半
        for(int i = d; i < n; i++){
            for(int j = i; j >= d; j -= d){
                if(a[j - d] > a[j]){
                    swap(&a[j - d], &a[j]);
                }else{
                    break;
                }
            }
        }
    }
}
```

时间复杂度最坏 O(n²)（取决于增量序列，目前无统一最优结论）。只适用于顺序表，不适于链表。不稳定。

## 8.3 冒泡排序 ⭐⭐⭐⭐ <a id="8-3"></a>

```c
void bubbleSort(int a[], int n){
    for(int i = 0; i < n - 1; i++){
        bool flag = false;                    // 本轮是否发生交换
        for(int j = 0; j < n - i - 1; j++)
            if(a[j] > a[j + 1]){
                swap(&a[j], &a[j + 1]);
                flag = true;
            }
        if(!flag) break;                      // 未发生交换则已有序
    }
}
```

时间复杂度最坏 O(n²)，最好 O(n)（加 flag 优化后）；空间复杂度 O(1)。适用于链表、顺序表。稳定。

## 8.4 快速排序 ⭐⭐⭐⭐⭐ <a id="8-4"></a>

```c
void quickSort(int a[], int left, int right){
    if(left >= right) return;

    int i = left, j = right;
    int pivot = a[left];                      // 基准元素取第一个

    while(i < j){
        while(i < j && a[j] >= pivot) j--;    // 从右往左找比基准小的
        while(i < j && a[i] <= pivot) i++;    // 从左往右找比基准大的
        if(i < j) swap(&a[i], &a[j]);         // 交换不满足前两个 while 循环的元素
    }

    swap(&a[left], &a[i]);                    // 基准元素归位

    quickSort(a, left, i - 1);
    quickSort(a, i + 1, right);
}
```

时间复杂度最坏 O(n²)（基本有序时取第一个元素为基准会退化）、最好 O(nlog₂n)；空间复杂度最坏 O(n)、最好 O(log₂n)（递归栈深度）。不稳定。优化：随机选基准或取中值。

## 8.5 选择排序 ⭐⭐⭐ <a id="8-5"></a>

```c
void selectionSort(int a[], int n){
    for(int i = 0; i < n - 1; i++){
        int min_index = i;
        for(int j = i + 1; j < n; j++){
            if(a[j] < a[min_index]){
                min_index = j;
            }
        }
        swap(&a[i], &a[min_index]);
    }
}
```

时间复杂度 O(n²)（与初始序列无关）；空间复杂度 O(1)。适用于链表、顺序表。不稳定。

## 8.6 堆排序 ⭐⭐⭐⭐⭐ <a id="8-6"></a>

堆（Heap）：一种数据结构，可以理解为[完全二叉树](<5. 树.md#5-2>)。数组从下标 1 开始存放。

> 💡 C++ STL 对应实现：[priority_queue](<../C++ 篇/C++ STL/1.9 priority_queue（优先队列）.md#1-9>)。

1. 若满足：L[i] ≥ L[2i] 且 L[i] ≥ L[2i + 1]（1 ≤ i ≤ n / 2）——大根堆（大顶堆），用于递增排序。完全二叉树理解：根 ≥ 左、右孩子
2. 若满足：L[i] ≤ L[2i] 且 L[i] ≤ L[2i + 1]（1 ≤ i ≤ n / 2）——小根堆（小顶堆），用于递减排序。完全二叉树理解：根 ≤ 左、右孩子

![堆：数组与完全二叉树](<图片和附件/堆的数组与完全二叉树.png>)

堆排序思路：每一趟把**堆顶元素**和**待排序的堆底元素**进行互换，再调整剩余部分，直到全部有序。

```c
// 建立大根堆（a[0] 作为暂存单元，数据从 a[1] 开始）
void buildMaxHeap(int a[], int len){
    for(int i = len / 2; i > 0; i--)    // 从最后一个非终端节点开始向上调整
        headAdjust(a, i, len);
}

// 将以 k 为根的子树调整为大根堆
void headAdjust(int a[], int k, int len){
    a[0] = a[k];
    for(int i = 2 * k; i <= len; i *= 2){
        if(i < len && a[i] < a[i + 1])
            i++;                        // i 指向更大的孩子
        if(a[0] >= a[i]){
            break;
        }else{
            a[k] = a[i];                // 孩子上移
            k = i;
        }
    }
    a[k] = a[0];
}

// 堆排序
void heapSort(int a[], int len){
    buildMaxHeap(a, len);
    for(int i = len; i > 1; i--){
        swap(&a[i], &a[1]);             // 堆顶元素换到堆底
        headAdjust(a, 1, i - 1);
    }
}
```

建堆时间复杂度 O(n)，排序时间复杂度 O(nlog₂n)，空间复杂度 O(1)。不稳定。

堆的插入、删除（最终构建好大/小根堆）：

1. 插入：
   - ① 对于小根堆，新元素放到表尾，与父节点对比，比父节点小则交换位置，直到不能上升为止
   - ② 对于大根堆，新元素放到表尾，与父节点对比，比父节点大则交换位置，直到不能上升为止
2. 删除：
   - ① 对于小根堆，表尾元素放到删除元素位置，对比子节点，与最小的互换，直到不能下坠为止
   - ② 对于大根堆，表尾元素放到删除元素位置，对比子节点，与最大的互换，直到不能下坠为止

## 8.7 归并排序 ⭐⭐⭐⭐⭐ <a id="8-7"></a>

定义：把多个有序数组合并成一个有序数组。一般用二路归并。

```c
int *b = (int*)malloc(n * sizeof(int));  // 辅助数组

void Merge(int a[], int low, int mid, int high){
    int i, j, k;
    for(k = low; k <= high; k++)
        b[k] = a[k];  // a 数组复制到 b 数组
    // 归并 ↓
    for(i = low, j = mid + 1, k = i; i <= mid && j <= high; k++){
        if(b[i] <= b[j])
            a[k] = b[i++];
        else
            a[k] = b[j++];
    }
    while(i <= mid) a[k++] = b[i++];
    while(j <= high) a[k++] = b[j++];
}

void MergeSort(int a[], int low, int high){
    if(low < high){
        int mid = (low + high) / 2;  // 从中间划分
        MergeSort(a, low, mid);      // 对左半部分归并排序
        MergeSort(a, mid + 1, high); // 对右半部分归并排序
        Merge(a, low, mid, high);    // 归并
    }
}
```

每次归并时间复杂度 O(n)，算法时间复杂度 O(nlog₂n)（与初始序列无关）；空间复杂度 O(n)，来源于辅助数组 b。稳定。

## 8.8 基数排序 ⭐⭐⭐ <a id="8-8"></a>

1. **步骤：**
   1. 设置 r 个空队列，r 为基数
   2. 按照各个关键字位权重递增的次序（个、十、百...），对 d 个关键字位分别做"分配"和"收集"
      1. 分配：顺序扫描各个元素，若当前处理的关键字位为 x，则插入 Q[x] 队尾
      2. 收集：把所有队列中的节点依次出队并连接

空间复杂度 O(r)，时间复杂度 O(d(n + r))。稳定。不基于比较。

2. **适用情况：**
   1. 数据元素的关键字可以方便地拆分为 d 组，且 d 较小
   2. 每组关键字的取值范围不大，即 r 较小
   3. 数据元素个数 n 较大

## 8.9 计数排序 ⭐⭐ <a id="8-9"></a>

统计每个关键字出现的次数，再按关键字顺序依次填回数组。适用于关键字取值范围不大（如成绩 0~100）的整数排序。

```c
void countSort(int a[], int n){
    int count[RANGE + 1] = {0};    // RANGE 为关键字最大值
    for(int i = 0; i < n; i++)
        count[a[i]]++;             // 统计每个关键字出现次数
    int k = 0;
    for(int i = 0; i <= RANGE; i++)
        while(count[i]--)          // 按序填回
            a[k++] = i;
}
```

时间复杂度 O(n + RANGE)，空间复杂度 O(RANGE)。稳定。

## 8.10 内部排序总结 <a id="8-10"></a>

| 排序算法 | 最好时间 | 最坏时间 | 空间复杂度 | 稳定性 | 适用场景 |
|---|---|---|---|---|---|
| 插入排序 | O(n) | O(n²) | O(1) | 稳定 | 基本有序、n 较小 |
| 希尔排序 | — | O(n²) | O(1) | 不稳定 | 仅顺序表 |
| 冒泡排序 | O(n) | O(n²) | O(1) | 稳定 | 链表、顺序表 |
| 快速排序 | O(nlog₂n) | O(n²) | O(log₂n)~O(n) | 不稳定 | 平均性能最好 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 | n 较小 |
| 堆排序 | O(nlog₂n) | O(nlog₂n) | O(1) | 不稳定 | 内存紧张、选最大/最小 |
| 归并排序 | O(nlog₂n) | O(nlog₂n) | O(n) | 稳定 | 要求稳定且 n 较大 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 | 关键字可拆分 |
