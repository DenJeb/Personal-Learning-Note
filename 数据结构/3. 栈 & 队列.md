## 3.1 栈 <a id="3-1"></a>

定义：只允许在**一端**（栈顶）进行插入和删除的线性表。**后进先出（LIFO）**。

> 💡 C++ STL 对应实现：[stack](<../C++ 篇/C++ STL/1.3 stack（栈）.md#1-3>)。

### 3.1.1 顺序栈

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;  // 栈顶指针
} SqStack;
```

1. 初始：top = -1
2. 判空：top == -1；判满：top == MaxSize - 1
3. 入栈：data[++top] = x；出栈：x = data[top--]

![顺序栈：top 指向栈顶元素](<图片和附件/栈顶指针.png>)

### 3.1.2 链栈

用单链表实现，栈顶在表头。入栈 = 头插法，出栈 = 删除第一个节点。不存在栈满问题。

### 3.1.3 栈在递归中的应用

递归调用的本质是函数调用栈：每层递归的局部变量、参数、返回地址保存在栈帧中。递归过深可能导致**栈溢出**（stack overflow）。

![递归调用：每层压一个栈帧](<图片和附件/递归栈帧.png>)

### 3.1.4 练习：括号匹配

```c
bool check(char str[]){
    char stack[MaxSize];
    int top = -1;
    for(int i = 0; str[i] != '\0'; i++){
        char c = str[i];
        if(c == '(' || c == '[' || c == '{')
            stack[++top] = c;                       // 左括号入栈
        else {
            if(top == -1) return false;             // 右括号多了
            char t = stack[top--];
            if((c == ')' && t != '(') ||
               (c == ']' && t != '[') ||
               (c == '}' && t != '{'))
                return false;                       // 不匹配
        }
    }
    return top == -1;                               // 左括号多了则栈非空
}
```

## 3.2 队列 <a id="3-2"></a>

定义：只允许在**队尾**插入、**队头**删除的线性表。**先进先出（FIFO）**。

> 💡 C++ STL 对应实现：[queue](<../C++ 篇/C++ STL/1.4 queue（队列）.md#1-4>)。

应用：[树的层次遍历](<5. 树.md#5-5-4>)、[图的 BFS](<6. 图.md#6-3>)、操作系统缓冲区。

### 3.2.1 顺序队列（循环队列）

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;  // 队头指针、队尾指针
} SqQueue;
```

1. 初始：front = rear = 0
2. 判空：front == rear
3. 判满：(rear + 1) % MaxSize == front（**牺牲一个存储单元**）
4. 入队：data[rear] = x; rear = (rear + 1) % MaxSize
5. 出队：x = data[front]; front = (front + 1) % MaxSize
6. 元素个数：(rear - front + MaxSize) % MaxSize

![循环队列：牺牲一个单元区分队空与队满](<图片和附件/循环队列.png>)

### 3.2.2 链式队列

带头节点的单链表 + 队头、队尾两个指针。入队尾插，出队头删。

### 3.2.3 双端队列 <a id="3-2-3"></a>

两端都可以入队和出队。

> 💡 C++ STL 对应实现：[deque](<../C++ 篇/C++ STL/1.5 deque（双向队列）.md#1-5>)。

1. 输出受限的双端队列：一端可入可出，另一端只可入
2. 输入受限的双端队列：一端可入可出，另一端只可出
